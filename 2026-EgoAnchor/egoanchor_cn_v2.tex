\title{EgoAnchor：面向消费级混合现实的动态真实物体锚定系统}
\author{作者待定}
\authorfooter{}

\abstract{%
动态真实物体锚定使虚拟内容能够随日常物体的拿取、移动和遮挡持续保持空间附着，是对象中心混合现实应用的基础能力。现有方案通常依赖物理标记、专用追踪设备或受限的平台对象集合。零样本6DoF位姿估计扩大了可被视觉定位的物体范围，但其输出是异步、低频且质量波动的相机系位姿观测，无法直接作为混合现实应用的对象锚点。本文提出EgoAnchor，一套面向消费级混合现实的零样本动态物体锚定系统。给定目标物体的三维模型，EgoAnchor无需物理标记或逐物体训练，通过开放词表初始化、时序分割、双目深度估计和模型驱动的6DoF位姿估计构建对象感知后端。系统进一步采用基于可视度、颜色和深度一致性的VCD机制验证位姿观测，并通过采集时刻世界配准、运动状态感知的时序合成、静止锚定和生命周期管理，将异步观测持续转化为稳定、世界一致且可恢复的对象锚点。我们在Meta Quest 3与外部GPU工作站上实现EgoAnchor，并通过受控系统基准、组件消融和24名参与者的日常物体被试内评价进行验证。结果表明，采集时刻对齐将头动相关误差降低2.69倍，静止锚定将中心化静止平移误差降低17.06倍；用户评价在静止稳定、恢复一致、依赖意愿、稳定--响应平衡、位置正确以及多项已发表量表结局上支持EgoAnchor，动态结果同时揭示了稳定性收益与起动转换、有效时延和当前时刻误差之间的代价。
}

\firstsection{引言}\label{sec:introduction}
\maketitle

% ===== 第一段：问题动机 =====
透视混合现实（Passthrough Mixed Reality, PMR）正在将虚拟内容附着到用户身边的真实物体上，用于物体说明、操作引导、状态可视化与近物交互界面。这些应用不仅需要识别物体，还需要一个能够随物体移动而持续更新的对象级空间参考：当用户转头、拿起、旋转、放下或短暂遮挡物体时，虚拟内容应保持与物体一致的六自由度（6DoF）关系。传统空间锚点适合静态环境，却不能表达物体自身的运动，因此动态真实物体锚定是以物体为中心的消费级混合现实应用的基础系统能力。

% ===== 第二段：现有方案局限 =====
现有方案在不同层面提供部分支持。平台原生对象追踪通常具有良好系统集成，但其对象范围、模型准备与运行时行为由平台定义~\cite{appleObjectAnchor,azureObjectAnchors,metaDynamicObjectTracker}；物理标记和专用追踪器能够提供稳定位置，却要求改造或装备目标物体；近年来的开放词表分割、双目重建与零样本6DoF位姿估计使给定三维模型的更多刚性物体能够被视觉定位~\cite{foundationpose2023,megapose2022}。然而，这些视觉方法主要输出某一图像时刻下相机坐标系中的物体位姿，尚未定义该位姿如何成为混合现实应用可持续使用的对象锚点。

% ===== 第三段：核心问题——三个缺口 =====
从视觉位姿到对象锚点之间存在三个运行时缺口。\textbf{时间语义缺口（G1）}：异步推理结果在到达应用时已经滞后，其相机系位姿属于历史图像采集时刻；若直接与到达时刻的头显位姿复合，用户头动会被错误地写入物体的世界位置。\textbf{观测准入缺口（G2）}：形式合法的位姿候选仍可能因遮挡、深度噪声或几何错配而不适合更新锚点，错误接纳会直接表现为可见跳变。\textbf{速率与连续性缺口（G3）}：即使观测正确，低频、时序不规则且含噪的位姿流也不能直接满足逐帧渲染；运行时必须同时定义静止稳定性、运动连续性、起停转换、短时失效与重新获取的行为。换言之，\emph{pose estimate is not yet an application-ready MR anchor}。

% ===== 第四段：EgoAnchor解决方案 =====
本文提出EgoAnchor，一套面向消费级混合现实的端到端动态真实物体锚定系统，其感知与锚定两层解耦部署：对象锚定运行时运行于头显，感知后端运行于外部GPU工作站。感知后端从头显双目图像、目标语义与可用三维模型中持续生成相机系6DoF位姿及其可靠性评分；锚定运行时利用帧标识恢复采集时刻的相机世界变换，在统一观测边界上执行候选接纳，并通过运动估计、延迟插值、显式静止锚定和生命周期管理定义逐帧输出行为，合成应用可直接绑定虚拟内容的世界系对象锚点。系统构建于成熟组件之上（开放词表分割、双目深度估计与模型驱动的零样本6DoF位姿估计），本文的贡献在于将这些异步视觉能力组织为面向PMR的观测到锚点契约。

% ===== 第五段：贡献 =====
本文的主要贡献如下：

\begin{enumerate}
  \item \textbf{零样本动态物体锚定系统：}EgoAnchor给定目标物体的三维模型，无需物理标记或逐物体训练，将异步、低频的视觉位姿观测持续转化为稳定、世界一致且可恢复的对象锚点，支持刚性物体在拿取、移动和遮挡期间的虚实配准。

  \item \textbf{VCD位姿验证与运动状态感知锚定运行时：}基于可视度、颜色和深度一致性的VCD机制验证位姿观测可靠性；采集时刻世界配准恢复异步观测的时间语义；运动状态感知的静止锚定在静止期采用死区门控的低增益更新抑制残余波动，时序合成在运动期维持连续跟随，分级生命周期管理短时失效与恢复。

  \item \textbf{系统实现与分层评价：}在Meta Quest 3上的完整实现，以及具有平台参考的受控系统基准、关键组件消融和24名参与者的日常物体被试内评价；评价同时量化运行时机制的收益与代价，并检验这些差异在稳定、恢复、依赖和信任判断中的感知结果。
\end{enumerate}

\section{相关工作}\label{sec:related-work}

\subsection{平台级真实物体锚定}

真实物体锚定为物理对象建立稳定的对象级空间参考，使虚拟内容能够持续附着于真实物体。早期系统主要采用基于物理标记的方法，通过AprilTag、ArUco等人工标记获得稳定位姿估计~\cite{kato1999artoolkit,olson2011apriltag,garridojurado2014aruco}。这类方法实现简单、鲁棒性较高，但需要在物体表面贴附标记，难以适用于开放场景中的多类日常物体。

近年来，消费级混合现实平台开始提供免标记对象追踪能力。HoloLens 2的Azure Object Anchors利用设备感知与对象数字模型完成对象匹配，但主要面向较大尺寸的静态对象；Apple Vision Pro提供对象追踪能力，但依赖基于三维模型构建的参考对象及离线训练流程；Vuforia Model Targets基于对象形状与三维模型实现真实物体识别与跟踪，但受约束的初始化与准备流程使其常见于工业场景；Meta Quest近年来也开始支持动态对象追踪，但仍属于受系统支持对象集合与用户设置约束的受控能力~\cite{appleObjectAnchor,azureObjectAnchors,vuforiaModelTargets,metaDynamicObjectTracker}。

总体而言，现有平台提供的对象追踪能力通常依赖专用硬件、受限的平台接口或对象级离线流程，难以直接支持开放场景中的多类日常物体，也较少向开发者开放底层视觉感知结果。

\subsection{6DoF物体位姿估计与跟踪}

6DoF物体位姿估计旨在从图像中恢复刚性物体相对于相机的空间位姿，是动态真实物体锚定的感知基础。早期方法通常依赖局部几何特征与PnP求解，在弱纹理、遮挡以及复杂光照条件下鲁棒性有限。随后，大量深度学习方法针对特定物体学习位姿估计网络；CosyPose、MegaPose等方法结合渲染匹配提升了未知物体的泛化能力~\cite{cosypose2020,megapose2022}，FoundationPose则实现了无需逐物体训练的零样本6DoF位姿估计~\cite{foundationpose2023}。开放词表目标检测、视频对象分割与立体匹配等视觉基础模型进一步提升了开放场景中的对象感知能力。

然而，上述工作的目标始终是提升相机坐标系下6DoF位姿估计的准确性，而非混合现实中的对象锚定。视觉推理产生的异步时延、估计噪声与跟踪波动，使高精度位姿流仍难以直接驱动稳定的虚实配准。如何把这些独立视觉模块组织为统一的感知流水线，并把异步位姿流转换为世界坐标系下稳定、连续且可恢复的对象锚点，仍然缺乏系统性研究。

\subsection{XR时延补偿与时间一致性}

配准误差与端到端时延自增强现实诞生以来便被认为是影响用户体验的核心问题~\cite{azuma1994improving,diluca2010latency}。对于依赖异步视觉感知的混合现实系统，图像采集、网络传输与模型推理通常引入数十毫秒乃至更高的端到端时延；当物体或用户快速运动时，这种异步时延表现为虚拟内容相对于真实物体的明显漂移与打滑。

围绕时延补偿，学界与工业界发展出两类互补思路。其一是预测式跟踪：头部位姿外推可以降低动态配准误差，双指数平滑等方法提供更轻量的预测替代。在交互输入侧，One Euro滤波器以速度自适应的方式权衡抖动与延迟，是三维用户界面处理含噪输入的常用基线。其二是后渲染对齐：异步时间扭曲（ATW）在扫描输出前用最新头显位姿重投影画面，已成为消费级头显的标准时延补偿手段~\cite{vanwaveren2016atw}。

上述工作主要围绕头部运动预测、渲染重投影以及交互输入滤波展开，其目标是降低显示链路中的时延影响。相比之下，由异步视觉模块输出的对象位姿对应于历史采集时刻，其世界坐标关系需要结合设备历史位姿进行恢复。OpenXR及各类平台运行时提供的时空同步能力面向设备自身位姿管理，由第三方异步视觉感知驱动的动态真实物体锚定则需要在应用层重新建立这一契约。

\section{EgoAnchor系统}\label{sec:system}

\subsection{系统概览}

EgoAnchor将动态物体锚定解耦为对象感知与对象锚定两层架构。感知后端从头显双目图像$I_f$、目标文本描述$\mathcal{T}$与目标物体的三维模型$\mathcal{M}$中，持续生成相机坐标系下的6DoF位姿观测$T_o^{c_f}$与即时可靠性评分$R_f$；锚定运行时将异步、低频的观测流$\{o_f\}$转化为稳定、世界一致且可恢复的对象锚点。贯穿两层的是三条不同的时间线：图像采集时刻$t_f$、观测到达时刻$t_a$与渲染时刻$t_r$。系统设计的核心是始终按$t_f$解释观测的空间语义，同时为每个$t_r$给出明确定义的输出，而不把目标状态由$t_f$外推至$t_r$。在此前提下，系统要求给定三维模型即可接入新的刚性目标而无需逐物体训练，并在坏观测、短时遮挡与重新获取期间给出可预测的保持、退化与恢复行为。图~\ref{fig:arch}展示了两层架构与运行时各阶段的数据流。

\subsection{感知后端}\label{sec:perception}

本文约定$T_a^b$将坐标从坐标系$a$映射至坐标系$b$。感知后端从头显双目图像$I_f = (I_f^L, I_f^R)$、目标文本描述$\mathcal{T}$与目标物体的三维模型$\mathcal{M}$中，持续恢复观测元组
\begin{equation}
o_f = (f, t_f, T_o^{c_f}, R_f)
\label{eq:observation}
\end{equation}
其中$f$为头显端分配的帧标识，$t_f$为图像采集时刻，$T_o^{c_f} \in \mathrm{SE}(3)$为相机系目标位姿，$R_f \in [0,1]$为即时可靠性评分。全文以$c_f$表示帧$f$经极线校正后的\emph{左目光学坐标系}，深度图、掩膜与位姿均定义于该坐标系，因此单一$T_o^{c_f}$足以描述双目输入下的目标位姿。观测序列$\{o_f\}$构成异步位姿流，是连接感知后端与锚定运行时的数据桥梁。系统采用最新帧优先策略，记$f^-$为最近一个已处理帧。

\subsubsection{零样本视觉流水线}

为支持不受预定义类别限制的刚性物体并保持米制尺度一致性，感知流水线解耦为四个串行阶段：

\textbf{语义初始化与时序分割。}开放词表检测器~\cite{yoloe2025}从首个左目图像$I_0^L$与文本描述$\mathcal{T}$生成初始掩膜$M_0$；视频对象分割器~\cite{cutie2024}随后维护时序记忆，并在每个已处理帧$f$上输出目标掩膜$M_f$。

\textbf{立体几何重建。}对于经过极线校正的双目图像，立体匹配器预测视差$\mathcal{D}_f$，并根据标定焦距$f_x$与双目基线$b$恢复米制深度图
\begin{equation}
Z_f = \frac{b f_x}{\mathcal{D}_f}
\label{eq:depth}
\end{equation}

\textbf{零样本位姿估计。}模型驱动位姿估计器~\cite{foundationpose2023}接收$M_f$、$Z_f$与目标模型$\mathcal{M}$，输出
\begin{equation}
T_o^{c_f} = \Phi_{\mathrm{pose}}(M_f, Z_f, \mathcal{M}, T_o^{c_{f^-}})
\label{eq:pose}
\end{equation}
初始化阶段执行全局注册（$T_o^{c_{f^-}}$缺失），追踪阶段以历史位姿为运动先验进行局部迭代优化。

\subsubsection{VCD可靠性评分}

零样本位姿估计的几何优化可能收敛至局部最优，产生形式合法但物理错误的位姿。感知后端需要为每个位姿候选提供可靠性评分$R_f$，供锚定运行时判别观测准入。

VCD（Visibility-gated Color-Depth）评分将候选位姿下的三维模型渲染回图像空间，通过比较渲染结果与实际观测的多模态一致性验证位姿质量。记$M_{\mathrm{rnd}}$为渲染投影掩膜，$\Omega_f = M_f \cap M_{\mathrm{rnd}}$为可见交集。可视度因子
\begin{equation}
V_f = |\Omega_f| / |M_{\mathrm{rnd}}|
\label{eq:visibility}
\end{equation}
衡量渲染投影被观测掩膜解释的比例，因而对遮挡和投影错位同时敏感。颜色与深度一致性$S_f^C, S_f^D \in [0,1]$均只在$\Omega_f$经形态学腐蚀得到的核心区上计算，以排除掩膜边界像素：$S_f^C$取渲染与观测图像在LAB空间的零均值归一化互相关并映射至$[0,1]$，其中亮度通道降权以抑制光照差异；$S_f^D$融合绝对与结构两类深度证据，
\begin{equation}
S_f^D = (1-\alpha_f)\,D_f^{\mathrm{abs}} + \alpha_f\,D_f^{\mathrm{str}},
\label{eq:depth-score}
\end{equation}
其中$D^{\mathrm{abs}}$由距离自适应阈值下的深度内点率与归一化残差中位数加权得到，$D^{\mathrm{str}}$为归一化深度的互相关，权重$\alpha_f$随渲染深度的四分位距增大——平坦目标主要依据绝对残差，深度起伏明显时才引入结构约束。

单帧未必两路证据都可用：无纹理或纯色目标的核心区颜色方差为零，掩膜内有效深度覆盖率过低时深度证据同样失效。记$\mathcal{V}_f \subseteq \{C, D\}$为本帧有效模态集合，VCD评分定义为对有效证据的加权几何平均
\begin{equation}
R_f = V_f \exp\!\left(\frac{\sum_{m \in \mathcal{V}_f} w_m \ln \max(S_f^{m}, \epsilon)}{\sum_{m \in \mathcal{V}_f} w_m}\right)
\label{eq:vcd}
\end{equation}
其中$\epsilon$为几何下限，避免有效低分退化为硬零。几何平均确保所有\emph{可用}证据须同时支持当前位姿评分才接近1；无效模态被剔除而非计低分，因此无外观信息的三维模型使评分退化为$R_f = V_f S_f^D$。这一取舍是有意的：错误位姿仍会被深度对齐与可视度拦截，而正确位姿不因目标缺少纹理被误拒。锚定运行时通过阈值$R_{\min}$实施观测准入。权重、下限与覆盖率门槛见第\ref{sec:implementation}节。

\subsection{锚定运行时}\label{sec:anchoring}

锚定运行时接收带采集时刻与可靠性评分的相机系位姿观测，并在每个渲染时刻输出世界系对象锚点，其处理分为三个阶段。首先，运行时以帧标识回查图像采集时刻的相机世界位姿，将候选恢复至统一世界坐标系，并依据VCD评分执行观测准入（第\ref{sec:alignment}节，对应G1与G2）。随后，被接纳观测写入时间索引轨迹，运行时在自适应历史时刻插值该轨迹，从而在不外推目标运动的前提下提供渲染频率输出（第\ref{sec:smoothing}节）。最后，系统按估计运动状态在连续跟踪与静止保持之间切换，并在观测中断期间管理缓冲、保持、丢失与重新获取（第\ref{sec:staticlock}节）；两者共同定义G3所要求的逐帧输出行为。

\subsubsection{采集时刻配准与观测准入}\label{sec:alignment}

由于视觉观测$o_f$在图像采集时刻$t_f$生成，却在较晚的时刻$t_a$返回，直接使用到达时刻的相机位姿进行坐标复合会引入由相机自运动造成的配准误差。为此，时空对齐分为时间对齐和空间对齐两个步骤。

在图像采集时，运行时以帧标识$f$为键记录对应的相机--世界变换。当观测返回后，首先根据$f$回查其采集时刻的相机位姿：
\begin{equation}
T_{c,f}^{w}
=
\mathcal{H}_c(f)
\equiv
T_c^w(t_f),
\label{eq:temporal-alignment}
\end{equation}
其中$\mathcal{H}_c$表示由帧标识索引的历史相机位姿缓存。

随后，将相机坐标系下的目标位姿复合到世界坐标系：
\begin{equation}
T_o^w(f)
=
T_{c,f}^{w}
\circ
\Psi\!\left(T_o^{c_f}\right),
\label{eq:spatial-alignment}
\end{equation}
其中$\Psi(\cdot)$表示视觉坐标约定到渲染坐标约定的确定性转换。

这里的时间对齐仅恢复观测与采集时刻相机位姿之间的对应关系，并不将目标状态从$t_f$外推至观测到达时刻或当前显示时刻。

形式合法的位姿仍可能在几何上错误，因此世界系候选须通过准入门控才可更新运行时状态：
\begin{equation}
\mathcal{O}^{+} = \left\{\, o_f \;\middle|\; t_f > t_{f^-} \wedge R_f \geq R_{\min} \,\right\}.
\label{eq:admission}
\end{equation}
非单调采集时刻的候选被判为非法并直接丢弃，避免乱序控制点进入状态估计；$R_f < R_{\min}$的候选被拒绝但仍计入生命周期的新鲜度统计，使运行时能够区分"拒绝坏观测"与"长时间无观测"两种情形。被拒候选不写入轨迹，因而不污染后续插值。

\subsubsection{时间索引轨迹合成}\label{sec:smoothing}

经准入的世界系观测$\{T_o^w(f)\}$仍是低频、时序不规则且含噪的离散序列，而渲染需要为每一帧提供明确定义的锚点位姿。运行时通过状态估计与历史时刻查询弥合观测速率与渲染速率之间的落差。

\textbf{状态估计。}位置与旋转通道分别维护常速度状态估计。位置通道估计位置与速度$(\mathbf{p}, \mathbf{v})$；旋转通道维护名义姿态四元数$\mathbf{q}$，并在其局部切空间中估计误差旋转与角速度$(\boldsymbol{\delta}, \boldsymbol{\omega})$。每次量测更新生成一个带时间戳的平滑控制点$(t_i, \widehat{T}_i)$。VCD评分仅用于候选准入，不参与滤波器噪声参数的在线调节。

\textbf{延迟插值。}运行时在线估计采集至渲染的端到端时延$\widehat{\tau}(t_r)$（通过最近候选时延的滑动中位数），并在渲染时刻$t_r$查询一个历史目标时刻：
\begin{equation}
t_q = t_r - \Delta(t_r), \quad \Delta(t_r) = \max\!\left(\Delta_{\min}, s\widehat{\tau}(t_r)\right)
\label{eq:target-time}
\end{equation}
其中$s$为安全系数，$\Delta_{\min}$为最小缓冲时延。逐帧跟踪输出为
\begin{equation}
\widehat{T}^w(t_q) = \begin{cases}
\operatorname{Interp}\!\left(\widehat{T}_i, \widehat{T}_{i+1}; \frac{t_q - t_i}{t_{i+1} - t_i}\right), & t_i \leq t_q \leq t_{i+1} \\
\widehat{T}_{\mathrm{latest}}, & t_q > t_{\mathrm{latest}} \\
\widehat{T}_1, & t_q < t_1
\end{cases}
\label{eq:delayed-interp}
\end{equation}
$\operatorname{Interp}$对位置执行线性插值，对旋转执行SLERP。查询历史时刻而非预测当前时刻是一项有意的设计选择：外推能够降低当前渲染时刻的相位误差，但其误差在目标速度突变与观测间隔抖动时按外推跨度放大，表现为可见的过冲与回拉；插值的误差上界由缓冲时延本身给出，因而以可预测的滞后换取有界的逐帧误差。运行时因此仅在已经到达的控制点之间插值：当$t_q$晚于最新控制点时保持最后输出，启动阶段（$t_q < t_1$）保持首个控制点，不进行基于速度模型的运动外推。该取舍在第\ref{sec:evaluation}节以有效时延与对齐残差成对量化。参数$s$和$\Delta_{\min}$见第\ref{sec:implementation}节。

\subsubsection{运动感知输出与生命周期}\label{sec:staticlock}

统一参数的时序平滑必须在静止稳定性与运动响应性之间连续折中。One-Euro滤波器~\cite{casiez2012oneeuro}通过速度自适应参数缓解这一权衡，但在观测持续含噪时通常仍保留非零的静止波动。EgoAnchor因此在运动跟踪与静止锚定（StaticLock）两种输出模式之间按估计运动状态显式切换。

下文以$t_r$表示渲染时刻，以$j$表示被接纳观测的到达次序；模式切换在渲染轴上提交，锁定位姿在观测轴上维护。运行时输出为
\begin{equation}
\widetilde{T}_o^w(t_r) = \begin{cases}
T_{\mathrm{lock}}^w, & m(t_r) = \mathsf{Locked} \\
\widehat{T}^w(t_q), & m(t_r) = \mathsf{Tracking}
\end{cases}
\label{eq:staticlock}
\end{equation}
其中$m(t_r)$为该渲染时刻的输出模式，$T_{\mathrm{lock}}^w$为最近一次锁内更新后的锁定位姿。

\textbf{进入锁定。}运动状态由相邻被接纳观测的差分速度经指数平滑得到，记为$\bar{v}_j$与$\bar{\omega}_j$；使用观测差分而非滤波器状态，可避免平滑本身把真实运动衰减为静止。当最近$t_{\mathrm{dwell}}$内持续满足$\bar{v}_j \leq v_{\mathrm{th}}$、$\bar{\omega}_j \leq \omega_{\mathrm{th}}$且$R_j \geq R_{\mathrm{lock}}$时，系统在下一渲染帧进入锁定：锁定位姿初始化为该帧的合成输出$T_{\mathrm{lock}}^w \leftarrow \widehat{T}^w(t_q)$，因此模式切换保持$C^0$连续、不产生跳变；同时记录锚定原点$T_{\mathrm{org}}^w$为当前观测共识，即被接纳观测经低增益指数平滑、与死区无关的估计。后者独立于锁定位姿，使解锁判据能够度量真实漂移。

\textbf{锁内微调。}锁定期间，系统采用小残差门控的低增益微调。记$\widehat{T}_j$为第$j$个被接纳观测对应的控制点，$d_{p,j}$与$d_{\theta,j}$为其相对当前锁定位姿的平移与旋转距离，则
\begin{equation}
T_{\mathrm{lock},j}^w = \begin{cases}
\operatorname{Interp}\!\left(T_{\mathrm{lock},j-1}^w, \widehat{T}_j; g_j\right), & d_{p,j} < d_{\mathrm{db}} \wedge d_{\theta,j} < \theta_{\mathrm{db}} \\
T_{\mathrm{lock},j-1}^w, & \text{否则}
\end{cases}
\label{eq:lock-creep}
\end{equation}
其中$g_j \in [0,1]$为低增益更新率，随观测可靠性提高而增大、随用户头动增强而减小。死区内的残差被视为噪声并以极低增益吸收，使锚点长期跟随观测共识而不逐帧抖动；超出死区的残差不改变锁定位姿，而是作为解锁证据累积。

\textbf{解锁。}锁定由四类互补证据共同释放：
\begin{equation}
\begin{aligned}
\mathsf{Locked} \to \mathsf{Tracking} \iff{}
& E_{p,j} > E_p^{\max} \,\vee\, E_{\theta,j} > E_\theta^{\max} \\
\vee{}\;\; & \lVert \Delta_{\mathrm{org},j} \rVert > d_{\mathrm{teth}} \,\vee\, \mathcal{T}_j^{\mathrm{mov}} > \mathcal{T}^{\max}
\end{aligned}
\label{eq:unlock}
\end{equation}
其中$E$为可靠性加权、按半衰期$h_E$泄漏的累积和（CUSUM），
\begin{equation}
E_{p,j} = 2^{-\Delta t_j / h_E} E_{p,j-1} + \kappa_j R_j \max\!\left(0,\, d_{p,j} - d_{\mathrm{db}}\right),
\label{eq:cusum}
\end{equation}
旋转通道同理；$\kappa_j$按参考观测间隔归一化，使证据累积速率与观测帧率无关。泄漏项使孤立噪声尖峰被遗忘，而持续的死区外偏移最终触顶解锁。$\Delta_{\mathrm{org},j}$为观测共识相对锚定原点的总偏移，构成绝对漂移租绳，使缓慢真实位移不会被永久锁定；$\mathcal{T}^{\mathrm{mov}}$为观测速度明确超过入锁门槛的持续时长，提供比位移更早的运动信号。低可靠性持续时同样强制释放，避免锚点冻结在错误位姿上。所有阈值随头动强度自适应放大，使头动引起的观测滑移被吸收而非误判为物体运动。解锁后输出沿几何衰减的接缝过渡收敛至跟踪轨迹，因此切换不产生可见跳变；该过渡与驻留时间共同构成起停转换代价。该设计以起停转换延迟为代价，换取静止期显著降低的输出波动；收益与代价在第\ref{sec:evaluation}节中并列量化。

\textbf{生命周期管理。}轻量状态机管理初始化、追踪、缓冲保持、不确定保持与丢失状态。可靠观测暂时中断时，运行时先在已有控制点上继续输出而不外推；超时后保持最后可信位姿并向应用标记其不确定性；持续失效则进入丢失并触发重新获取。可靠候选恢复后，锚点自动重新关联并返回追踪状态。各状态的时间阈值见第\ref{sec:implementation}节。

\textbf{逐帧流程。}运行时在两条时间轴上工作。每个被接纳观测触发：（1）按式~\eqref{eq:temporal-alignment}与式~\eqref{eq:spatial-alignment}恢复世界系位姿并按式~\eqref{eq:admission}判定准入；（2）更新位置与旋转通道的常速度状态并追加控制点；（3）更新运动状态与静止锚定证据（式~\eqref{eq:cusum}）。每个渲染帧触发：（4）按式~\eqref{eq:target-time}求目标时刻并在已有控制点间插值，或在锁定模式下输出锁定位姿（式~\eqref{eq:staticlock}）；（5）由生命周期状态标注该输出的可信度。

\section{系统实现}\label{sec:implementation}

EgoAnchor采用头显端与工作站分层部署：对象锚定运行时运行于Meta Quest 3，感知后端运行于外部GPU工作站。实验工作站配备Intel Core i9-14900K、32~GB内存与NVIDIA GeForce RTX 3090（24~GB显存）；头显与工作站通过Wi-Fi 6局域网连接。感知后端基于Python 3.14.6、PyTorch 2.12.1、CUDA 13.2与TensorRT 11.1实现。Quest 3端采用Unity 6与Meta XR SDK 203.0.0，负责双目图像采集、设备位姿记录、对象锚定与渲染。

感知后端以YOLOE-26完成开放词表目标分割，并以Cutie传播帧间目标掩膜；双目几何由Fast-FoundationStereo重建，其TensorRT推理采用FP16精度与四次迭代；FoundationPose根据目标三维模型执行零样本6DoF注册与追踪，注册和追踪分别采用五次与两次细化。VCD可靠性评分借助nvdiffrast渲染目标模型，并比较颜色、深度与掩膜一致性。当前v4批次的追踪阶段服务器处理时间中位数为77.36~ms（P95为88.16~ms），有效候选发布时间间隔中位数为106.74~ms（约9.37~Hz）。

对象锚定运行时以C\#实现，并通过Meta Passthrough Camera API获取双目图像及相机标定。运行时在有界历史中记录图像采集附近的设备轨迹，再以帧标识恢复对应时刻的相机世界变换。运动估计采用常速度卡尔曼滤波，位置与旋转通道分别维护独立滤波器。观测准入阈值$R_{\min} = 0.2$；时延估计安全系数$s = 1.15$，最小缓冲时延$\Delta_{\min} = 250$~ms。

静止锚定参数配置如下。入锁条件：速度门槛$v_{\mathrm{th}} = 50$~mm/s、$\omega_{\mathrm{th}} = 22$°/s，可靠性门槛$R_{\mathrm{lock}} = 0.25$，驻留时间$t_{\mathrm{dwell}} = 350$~ms。锁内微调：死区$d_{\mathrm{db}} = 8$~mm、$\theta_{\mathrm{db}} = 3$°，增益按$g_j = (1 - 2^{-\Delta t_j / h_{\mathrm{creep}}}) R_j (1 - \rho_j^{\mathrm{head}})$计算，其中$\Delta t_j$为相邻锁内观测的时间间隔，$h_{\mathrm{creep}} = 2.7$~s为微调半衰期，$\rho_j^{\mathrm{head}} \in [0,1]$由头部线速度与角速度的归一化强度计算。解锁条件：CUSUM上限$E_p^{\max} = 80$~mm、$E_\theta^{\max} = 20$°，证据半衰期$h_E = 0.27$~s；漂移租绳$d_{\mathrm{teth}}$在平移与旋转通道分别为15~mm与12°；速度逃逸取入锁门槛的2.5倍并持续$\mathcal{T}^{\max} = 400$~ms；可靠性低于0.3持续600~ms同样强制释放。解锁后1.0~s内抑制重新锁定，接缝过渡按逐帧系数0.85几何衰减。头部静止后设置600~ms沉降窗口，其间冻结解锁判据，避免头动滑移尚未褪去时误解锁。

生命周期时间阈值为：无可靠观测450~ms后进入缓冲保持，1.0~s后判定丢失并触发重新获取。VCD可靠性评分中，颜色与深度权重分别为$w_C = 0.2$、$w_D = 0.8$，几何下限$\epsilon = 0.05$，掩膜内有效深度覆盖率门槛为0.10，结构项权重上限为0.35。

系统将高带宽图像流与低带宽结果、状态和控制消息分离。数据面采用ZeroMQ发布-订阅模式传输Protobuf编码的双目JPEG图像与相机标定，并实行最新帧优先；消息面采用NATS Core与Protobuf传输位姿观测、状态事件和请求-应答控制命令。

\section{系统评估}\label{sec:evaluation}

我们的评价遵循"完整系统行为--组件归因--感知效用"的三层结构。实验一回答EgoAnchor作为应用侧对象锚点在头动、物体运动、起停转换与遮挡期间表现为何；实验二在相同候选流上关闭单一组件，解释这些行为由何种运行时机制产生；实验三在日常刚性物体上以被试内研究检验系统差异能否被用户感知，并影响其信任与依赖意愿。实验一和实验二均使用同一Meta Quest 3、同一视觉候选流、同一渲染时间线和同一平台参考轨迹，从而避免将感知输入差异误写为运行时差异。

\subsection{实验设计与系统配置}

受控定量评价以Quest Touch Plus控制器作为视觉追踪目标，并以平台SDK输出的控制器六自由度位姿作为同步参考。该参考与头显共享平台世界坐标系，适合在同一时间线内进行配对比较，但仍包含平台内部预测、滤波和共同漂移，因此本文报告的是\emph{平台参考下的相对系统行为}，而非外部光学系统给出的物理真值。v4由五个场景专用连续session构成，九种运行时配置在同一数据流上同步执行。各指标先在预定义的重复动作片段或遮挡过程内计算，再汇总片段间的median [Q1, Q3]。

所有配置消费相同的相机系位姿候选、采集时间戳、候选到达时间、相机标定、渲染时间线和平台参考轨迹。\textbf{Arrival}表示直接消费异步视觉位姿的朴素方案：候选到达后以当前头显位姿完成世界坐标复合，并保持结果直至下一候选。\textbf{Capture}仅将复合时刻改为图像采集时刻，以隔离时间语义的作用。\textbf{One-Euro}使用采集时刻对齐、VCD接纳、One-Euro滤波、自适应历史目标时刻和Linear/SLERP合成，与完整系统采用相同的生命周期和逐渲染帧输出，但不使用显式静止锚定。\textbf{EgoAnchor}使用VCD接纳、卡尔曼状态估计、Linear/SLERP时序合成、显式静止锚定和分级生命周期管理。

实验二包含三个单组件消融，分别关闭采集时刻对齐、VCD和StaticLock。时序策略比较Smoothed KF Extrapolation与Linear/SLERP；两者共享采集时刻对齐、VCD、卡尔曼滤波、生命周期和关闭StaticLock的设置，只替换逐帧输出策略。

\subsection{评价指标}

实验一围绕五项应用可感知属性组织评价指标：

\textbf{世界一致性。}中心化平移泄漏通过移除观测序列的均值偏移，隔离头动期间由坐标系错配引入的相对波动（表~\ref{tab:exp1-performance}中记为头动泄漏）。绝对注册误差直接度量锚点输出与平台参考之间的欧氏距离。

\textbf{静止稳定性。}静止期平移与旋转的帧间增量P95衡量逐帧显示抖动；计算窗口限定在速度低于阈值的静止片段内。表中只列出平移通道，旋转通道的片段分布见图~\ref{fig:exp1-final}(b)。

\textbf{动态保真度。}有效时延通过在$[-500, 0]$~ms搜索区间内寻找使RMSE最小的时间偏移量估计；lag-aligned RMSE为该最优偏移下的轨迹残差，反映移除相位差后的形状保真度；current-time RMSE在零偏移下计算，反映当前渲染时刻的配准误差。residual jitter对lag-aligned残差轨迹求帧间增量P95。

\textbf{遮挡鲁棒性。}遮挡期平移误差P95在遮挡开始至完全恢复的时间窗口内计算。

\textbf{转换代价。}Start-transition定义为静止锁定解锁至输出首次响应物体运动的时间间隔，反映稳定优先策略的起动延迟。

所有片段级指标先在预定义的重复动作片段内计算，再汇总片段间的median [Q1, Q3]。

\subsection{实验三：日常物体上的用户感知评价}

实验一和实验二在具有平台参考的受控目标上刻画系统行为；实验三进一步考察这些差异在日常物体上的感知结果。既有研究表明，在其测试的0/1/2度离散偏移与抖动水平内，误差水平升高伴随用户信任下降~\cite{gottsacker2024artrust}。本实验据此把测量集中在静止稳定、运动附着、遮挡恢复、空间正确性和对锚点的信任与依赖上。

\subsubsection{实验设计}

研究采用$2 \times 3$完全被试内设计，因素为锚定方法与物体。方法只包含One-Euro与完整EgoAnchor。两者共享采集时刻对齐、VCD接纳、自适应历史目标时刻、位置Linear/旋转SLERP合成、生命周期管理和逐渲染帧输出；One-Euro使用OneEuroModel且不启用StaticLock，EgoAnchor使用卡尔曼状态估计并启用StaticLock。三个正式物体为无线鼠标、机械固定为闭合状态的订书机和游戏手柄，覆盖不同尺寸、几何、纹理与抓握方式；游戏手柄统一由单手握持一侧搬移。耳机盒只用于训练，不进入正式分析。

物体是执行顺序的外层区块，每个物体内相邻比较两种方法。每个物体区块只启动一次对应的Python感知后端，同一感知会话服务该物体的两个方法条件。三种物体的六个全排列与两种互补方法序列、两种A/B标签映射组合成24个平衡单元；匿名标签在单个参与者内始终绑定同一方法。该安排使物体位置、先行方法和标签映射在24名参与者之间平衡。

每个方法--物体条件按固定顺序完成三项操作。\emph{静止观察}中物体固定在桌面，参与者依次从正面、左右侧和略微靠近的位置观察。\emph{拿起、移动与放置}中参与者将物体平移约25--30~cm、自然旋转约30--45°，在空中保持约2~s后放到目标区域，并继续观察约5~s。\emph{遮挡与恢复}中物体保持静止，实验员用统一挡板完全遮挡0.6--0.9~s；该时长经预实验固定，使锚点进入\texttt{FrozenUncertain}而不进入\texttt{Lost}，移除挡板后继续观察5--7~s。三项操作连续完成后统一评分，避免在同一条件内反复打断体验。

\subsubsection{测量与统计分析}

每个方法--物体条件结束后，参与者在头显内完成十三项七点评分。其中七项为研究定制条目：静止稳定、运动附着、姿态一致、恢复一致、位置正确、依赖意愿和稳定--响应平衡；七项逐项分析，不合并总分。其余六项来自Augmentation Quality的Embedding Quality与Interaction Quality两个完整子量表~\cite{schein2025aq}，只对指代对象作最小替换，并以adapted量表署名。现有量表没有直接覆盖虚拟内容相对真实物体的对象级配准质量，因此已发表量表与研究定制条目共同构成区块级测量。

全部六个区块完成后，参与者按平衡顺序分别评价两种方法：adapted TiA的可靠性/能力与理解/可预测性两个分量表~\cite{koerber2019tia}，以及adapted S-TIAS三项~\cite{mcgrath2025stias}。TiA使用五点评分，S-TIAS使用七点评分。中文条目由量表原文译出并逐条核对语义，预实验以认知访谈确认理解。最终问卷记录总体偏好、信任选择、偏好强度、区分信心、两道开放题和不适情况；这些项目作描述性报告。

区块级的七项定制条目与AQ两个子量表先在每位参与者内对三个物体取均值；TiA两个分量表和S-TIAS使用每种方法一次的方法级得分。TiA的四个反向项按$6-\mathrm{raw}$换向。多重比较预先分为两个家族：主证实家族包含七项定制条目，已发表量表家族包含AQ-EQ、AQ-IQ、TiA两个分量表和S-TIAS；两组分别作Holm校正。方法比较使用含并列中秩的双侧条件精确Wilcoxon符号置换：配对差规范到12位小数后删除零差，同绝对差赋中秩，再枚举非零差的符号分配。该检验要求零假设下非零配对差的符号可交换，通常对应配对差分布关于零对称的条件。效应量报告匹配秩双列相关及参与者级自举区间。

\subsubsection{结果}

24名参与者签署知情同意并完成全部六个条件，均纳入分析，共得到144个有效方法--物体区块（每种方法72个）。参与者中女性12名、男性12名，年龄$M=27.08$岁（$\mathrm{SD}=4.45$）；22名惯用右手，2名惯用左手，15名视力正常，9名矫正后正常。

\section{讨论}\label{sec:discussion}

\subsection{设计启示}

EgoAnchor将异步视觉观测转换为对象锚点时，需要区分相机运动造成的坐标变换错配与目标物体在观测到达前继续运动造成的轨迹滞后。基于帧标识的采集时刻对齐处理前者；运动估计与时序平滑在观测之间维持连续输出，而采集后的目标运动滞后仍然存在。两类误差具有不同的时间语义，须分别测量与报告。

\textbf{时间一致性的作用域。}帧对齐的作用域是相机运动：它把历史相机系观测复合到该观测自身的采集时刻，从而消除头动写入物体世界位置的误差。采集之后的目标运动属于另一类误差，由感知处理时间、观测更新率和平滑策略引入的插值延迟共同决定，需要独立测量。本文因此将有效时延与lag-aligned residual成对报告：前者描述响应滞后，后者描述移除相位差后的轨迹保真度。两者均不等价于零时延的当前时刻配准误差，帧对齐也不是对物体运动时延的补偿。

\textbf{稳定性与响应性的权衡。}StaticLock、历史时序合成与Smoothed KF Extrapolation共同决定静止波动、轨迹残差和起停响应，本文将这三者作为联合权衡报告。稳定优先的输出策略以更长的起动转换换取静止期的稳定保持，其应用侧含义取决于任务如何消费锚点：在拿起--放置--读取这类先运动后交互的模式中，沉降后的稳定性主导体验；在需要持续跟随快速运动的场景中，当前时刻的相位误差是主要限制。实验三据此区分静止、运动与恢复阶段，并设置稳定--响应平衡条目。

\subsection{局限与未来工作}

EgoAnchor面向具有可用三维模型的刚性物体，其对象类别不由预定义标签集限制，新的刚性目标可在无需逐物体训练的情况下接入同一系统。实际锚定质量取决于物体在头显图像与双目深度中的可观测性：严重遮挡、极弱纹理、透明或镜面材质以及超出有效深度量程都会削弱分割、几何重建和位姿验证。非刚性物体需要可变形表示与非刚体跟踪，超出本文采用的刚体位姿模型。缺少现成三维模型时，Image-to-3D重建可以补充模型来源，但重建误差会传递至锚定结果。

受控定量评价以Quest控制器的平台位姿为参考，文中误差因此是平台参考下的相对误差，而非外部光学系统给出的物理真值：参考与头显共享同一追踪系统，两者共同的世界系漂移不可观测，参考轨迹自身的预测、平滑与动态时延也包含在残差中。日常物体没有同类平台参考位姿，其绝对配准精度需要外部测量手段才能确立。实验三报告主观感知评价与无需真值的自参考稳定性日志，不报告任务完成时间、成功率或绝对配准误差。系统当前依赖外部GPU工作站，部署成本与网络条件构成进一步的应用约束。

未来工作将探索更广的物体覆盖、对非刚性物体的支持，以及与生成式三维重建的更紧密结合。

\section{结论}\label{sec:conclusion}

本文提出EgoAnchor，一套面向消费级混合现实的端到端动态真实物体锚定系统。系统以头戴显示器双目图像和目标物体的可用三维模型为输入，通过感知后端与对象锚定运行时的分层架构，将历史采集时刻、低频且质量不均的相机系位姿观测转换为应用可持续消费的世界系对象锚点。EgoAnchor通过采集时刻世界对齐恢复异步观测的时间语义，通过VCD观测接纳限制有害更新，并以连续时序合成、显式静止锚定和生命周期管理定义静止、运动、短时失效与恢复期间的输出行为。本文据此把零样本对象感知与混合现实应用之间的接口问题明确为一项系统设计任务，并通过具有平台参考的端到端系统表征、关键组件消融和日常物体上的24名参与者被试内评价刻画其能力、代价与感知效用。
