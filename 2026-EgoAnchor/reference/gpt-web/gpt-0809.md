## 你问的三个统计指标，分别需要这样处理

### 1. `\Delta Mdn`：数值可以保留，但这个标题不够严谨

这里存在一个非常实际的问题。

以“静止稳定”为例：

[
\mathrm{Mdn}*{Ego}=5.00,
\qquad
\mathrm{Mdn}*{OneEuro}=4.33.
]

两个条件中位数相减是：

[
5.00-4.33=0.67.
]

但是你分析文件中的**参与者内配对差中位数**是：

[
\mathrm{Mdn}(Ego_i-OneEuro_i)=1.00.
]

因此写：

```latex
$\Delta$Mdn
```

读者完全可能以为它是：

[
\mathrm{Mdn}*{Ego}-\mathrm{Mdn}*{OneEuro}.
]

实际上不是。

所以我在新版表里改成了明确的：

> **配对差**

caption再定义：

> 配对差定义为EgoAnchor减One-Euro；两种方法及配对差均报告Mdn [Q1,Q3]。

这是比`\Delta Mdn`严谨很多的写法。

---

### 2. `p_{\mathrm{Holm}}`：没错，但我更推荐 `p_{\mathrm{adj}}`

`p_Holm`能够理解，但它把校正算法塞进了统计量符号。

更常见、更清爽的写法是：

```latex
$p_{\mathrm{adj}}$
```

然后caption：

> (p_{\mathrm{adj}})为对应检验家族内Holm校正后的双侧Wilcoxon符号秩检验(p)值。

于是论文里统一写：

```latex
$p_{\mathrm{adj}}=.267$
```

而不是：

```latex
$p_{\mathrm{Holm}}=.267$
```

Holm属于分析procedure，不需要成为变量名字。

---

### 3. `r_{rb}`：它是正规的，而且我建议保留

你说之前很少见，这是正常的。

这里正确的名称是：

> **matched-pairs rank-biserial correlation**
>
> 匹配样本秩双列相关

记作：

[
r_{\mathrm{rb}}.
]

它是Wilcoxon signed-rank test可以使用的效应量。Kerby专门讨论了如何从Wilcoxon符号秩中的正、负rank evidence构造这种rank-biserial effect size。([Sage Journals][1]) 统计软件文档中也明确提供了paired Wilcoxon的matched-pairs rank-biserial correlation，同时指出另一种常见选择是基于(Z/\sqrt N)的(r)。([R Project Search][2])

所以它的问题不是“不正规”，而是：

> **比(r=Z/\sqrt N)少见一些，因此第一次必须定义。**

我不建议现在改成(Z/\sqrt N)。你的分析采用了带ties处理的exact Wilcoxon，而(Z/\sqrt N)通常又依赖正态近似产生的(Z)。继续使用与signed ranks直接对应的(r_{\mathrm{rb}})反而更一致。

我已经把第5章统计分析同步改为：

```latex
效应量报告匹配样本秩双列相关
（matched-pairs rank-biserial correlation，$r_{\mathrm{rb}}$）
及参与者级自举95\%置信区间。
```

表中则用：

```latex
$r_{\mathrm{rb}}$ [95\% CI]
```

并说明：

> 正值表示EgoAnchor评分更高。

这样就没有理解障碍。
