我把这版 `.tex` 的注释逐条看了一遍。相比上一版，现在的问题已经从“整体结构需要重做”收敛到了几个**会直接影响审稿人理解的定义与表述问题**。下一轮不建议继续大面积润色，而应该先把这些概念钉死，再统一全文术语。

我建议按下面顺序修改。

1. **先解决 2.3 的时延术语，这是目前最需要优先处理的一处。** 你在第 105–107 行的质疑是对的：**ATW 与你的历史轨迹插值不是同一类方法，不应该把它暗示成与你的方法相对应的另一种轨迹策略。** 我查了相关文献后，`predictive tracking` 这个术语本身是成立的，Azuma 的经典工作就直接使用 *Predictive Tracking for Augmented Reality* 和 *head-motion prediction* 来描述通过预测未来头部状态降低动态配准误差的方法。([Ronald Azuma][1]) 与之不同，post-rendering 3D warping / time warping 是在**已经完成渲染之后**，利用更新的视点/头部位姿重新映射图像；ATW 是这一 post-rendering reprojection 思路的异步实现，它根据最新 head tracking information 对已经渲染的立体图像进行变换，而不是在过去两个对象 pose 之间做插值。([数字对象标识符][2])

   因此，我建议 2.3 不再写成“预测式追踪 vs 后渲染对齐”然后试图让第二类对应 EgoAnchor。应该写成三个层次：**状态预测/外推（pose prediction / extrapolation）**、**输入状态平滑（例如 One-Euro）**、**后渲染重投影（post-rendering reprojection / time warping）**。然后明确指出 EgoAnchor 面对的是另一类问题——异步、低频的**对象观测**；你们在实验二真正比较的是两种对象状态的时序生成方式：**前向外推（forward extrapolation）**和**延迟插值（delayed interpolation）**。我不建议把后者硬称为 `fixed-lag smoothing`，因为你现在实现的核心是缓冲后在两个已到达控制点间 interpolation，并没有实现一般意义上的 fixed-lag smoother。

   这一段我建议最终改成类似：

   > 围绕XR中的时延误差，已有方法主要从状态估计与显示生成两个层面进行补偿。状态层面上，预测式追踪通过历史运动估计将头部或交互设备位姿外推至预期显示时刻，以降低动态配准误差；速度自适应滤波则在抖动与响应滞后之间进行权衡。显示层面上，post-rendering reprojection / time warping在场景渲染完成后利用更新的头部位姿重新映射已渲染图像，ATW即属于此类。上述方法主要处理设备追踪或显示流水线中的时延，而异步对象观测具有不同的时间语义：观测本身对应过去的图像采集时刻，且到达频率低而不规则。对于这种对象状态流，运行时既可以向当前渲染时刻前向外推，也可以引入显式滞后、在已到达观测之间进行延迟插值；本文在实验二中直接比较两种选择的响应—轨迹保真度权衡。
   >

   这样 Related Work、Method 和 Experiment 2 会真正闭环。

   > 受控结果显示，EgoAnchor在静态配准、遮挡恢复及时延对齐后的动态轨迹残差上取得更低误差，但承担更长的起动响应；用户研究进一步显示更高的主观稳定性、依赖意愿与方法级信任。
   >

   Introduction 第 71 行现在逻辑已经对了，但仍然略密。不要再增加技术细节。贡献 2 则确实仍然太长，我会进一步压成：

   > **锚定感知与运行时：**以逐观测VCD评分约束候选可靠性，并结合采集时刻对齐、可靠准入、延迟轨迹插值与静止锚定，将异步相机系观测转换为逐渲染帧世界系对象锚点。

3. **System Overview 的三个注释都应该改，而且可以同时降低阅读负担。** 第 115–127 行目前最大的问题不是数学，而是“解释得太用力”。关于 3D model 那句“模型获取本身不再是主要门槛”我建议直接删掉。这是一个很强的泛化判断，而且并不是 EgoAnchor 论文需要证明的事情。这里只写事实：

   > EgoAnchor面向具有可用三维模型的刚性物体，以简短文本描述指定待锚定目标，无需物理标记或逐物体训练。

   > 全文以 (T_a^b\in SE(3)) 表示从坐标系 (a) 到坐标系 (b) 的刚体变换。例如，(T_{o,f}^{c}) 表示第 (f) 帧对象坐标系到左目相机坐标系的观测位姿，(\widehat{T}_{o,j}^{w}) 表示第 (j) 个接纳观测更新后的世界系状态估计，(\widetilde{T}_o^w) 表示提交给应用的对象锚点；连续时间上的状态写作 (\widehat{T}_o^w(t))。

4. **“立体几何重建 / 米制几何 / 双目几何 / 米制深度”目前确实不统一，我建议统一成“**双目深度恢复**”。** 你实际计算的是 disparity (d_f) 和 metric depth (Z_f)，没有在这里显式构造一般意义上的 3D reconstruction，所以“立体几何重建”略显过重。具体统一为：流水线“依次建立目标身份、米制深度和相机系位姿”；小标题“**双目深度恢复**”；Implementation 中 Fast-FoundationStereo“恢复米制深度”；图中也尽量用 Stereo Depth / 双目深度。这样最准确。

   第 355 行的“零阶保持”直接删术语。它对信号处理的人很标准，但这里没有任何收益。改成：

   > Arrival与Capture直接使用每个返回候选，并保持该位姿直至下一候选到达；二者均不启用VCD准入或静止锚定，仅在世界系复合所采用的时间语义上不同。

6. **“轨迹输出策略”这个旧词建议彻底消失。** 它现在在 Evaluation、Experiment 2、Results 和 Discussion 多次出现，但方法正文真正描述的是“query time + interpolation/extrapolation”。我建议全文统一为 **“时序取值策略”**，而具体两个条件统一叫：

   * `延迟插值（delayed interpolation）`

   因此 Experiment 2 小标题改为“**时序取值**”；Figure 5(d) caption 改成“前向外推与延迟插值的时延–残差关系”；Discussion 中“静止锚定与轨迹输出策略”改为“静止锚定与时序取值”。方法 3.3.2 第一句最好也第一次正式引入“延迟插值”这个名称。这样 2.3 → 3.3.2 → 5.2 → 6.2 → Discussion 全部能对上。
7. **用户研究目前有一个比措辞更重要的设计表述问题：不要再称它为“2×3 两因素设计”，除非你准备分析 object main effect / interaction。** 你现在统计分析是先把三个物体平均，再比较两个方法，所以物体实际上承担的是**重复的异质 exemplar**，而不是你要做推断的实验因素。如果继续写“两个因素分别为方法和物体”，审稿人很容易问：“既然是 2×3 factorial，为什么没有 method × object analysis？”

   我建议改成：

   > 研究采用完全被试内的方法比较设计。每位参与者在三个日常物体上分别体验One-Euro与EgoAnchor，共形成六个方法–物体条件；主要推断对象为锚定方法，三个物体作为异质对象实例用于提高评价覆盖度，并在参与者内取均值。
   >

   这和你真正的统计分析完全一致。

   第 391 行也不要说“任务量与公平性的权衡”，学术上这里是 **object coverage 与 participant burden 的权衡**。四个属性要先解释为什么影响视觉锚定，再说明怎么选三个物体，例如：

   > 为在对象多样性与参与者负担之间取得平衡，我们围绕四个直接影响视觉锚定难度的属性选择对象：尺度影响图像支持区域与深度精度，几何形态影响位姿可辨识性，表面纹理影响外观证据，而自然抓握造成的手部遮挡影响目标可见度。我们据此选择无线鼠标、订书机和游戏手柄，使三个对象覆盖这些属性的不同组合，而非将对象本身作为独立实验因素。
   >

   然后再介绍三个物体的具体特点。这样逻辑就顺了。

除了你已经写出的注释，我还发现三处值得这一轮一起修。

第一，**VCD 的 AURC 论证稍微有点过头。** 现在写“AURC 4.79 低于全覆盖平均误差 7.25，因此证明排序一致性”，这个比较可以做描述，但不是很强的 ranking baseline。最理想是补一个 random-ranking AURC 或 permutation baseline；如果不准备重新分析，就把语言收敛成“高分候选区域具有较低风险，随着覆盖率提高、较低分候选被纳入，风险上升；AURC概括了该趋势”，不要说得像严格证明。

第二，**Cronbach's (\alpha) 的解释要一致。** 现在你对 TiA 的 `.565 < .70` 明确提醒谨慎，又对 AQ-IQ 的 `.504` 做了同样提醒，但 S-TIAS 的 `.672/.697` 也不高，却马上用它强化“总体信任”。我建议不要机械使用 `.70` 作为二元阈值，而是统一描述：AQ-IQ 在 One-Euro 下内部一致性较低；TiA U/P 在 One-Euro 下较低；S-TIAS 在两个条件下均为中等/相对有限。这样不会给 reviewer 留“选择性解释 reliability”的口子。
