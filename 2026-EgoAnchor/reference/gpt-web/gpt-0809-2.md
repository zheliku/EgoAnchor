## 1. VRGA为什么报告 (F)，我们为什么不需要

这个区别很重要。

VRGA的用户实验做的是一个真正的**多因素推断问题**。他们采用ART的two-way repeated-measures ANOVA，因为实验中同时有：

* avatar type：self / other；
* reconstruction method：Ours / video / image；

而且作者明确关心：

* avatar type主效应；
* method主效应；
* 两者interaction。

因此结果自然报告：

[
F,\quad p,\quad \eta_p^2,
]

例如VBO、Agency、Change都会分别报告main effect和interaction。

你们现在的主分析问题不同。

当前第5章明确把三个物体先在参与者内取均值，随后比较：

[
\text{EgoAnchor}
\quad\text{vs.}\quad
\text{One-Euro},
]

即一个**参与者内的两条件配对比较**。

因此：

[
\text{Wilcoxon signed-rank}
]

本身就是与你当前分析问题一致的检验。

如果现在为了“看起来像VRGA”强行加 (F)，就意味着要把分析问题改成：

[
2;(\text{method})
\times
3;(\text{object})
]

的factorial model，并正式检验：

[
\text{Method},\quad
\text{Object},\quad
\text{Method}\times\text{Object}.
]

这不是换一种汇报格式，而是**换统计模型和研究问题**。

所以我的建议很明确：

> **不要增加 (F)。**

除非你们真的想回答“EgoAnchor的效果是否依赖具体物体”，那才值得额外做ART或者mixed-effects analysis。否则现在的Wilcoxon更直接。

## 2. (\alpha)需要吗？需要，但不要把(\alpha+\omega)全塞进主文

VRGA确实报告Cronbach's (\alpha)。他们先说明用α检查Likert量表的内部一致性，随后在VEQ、VEQ+、VHPQ结果中报告对应α。

你们也有：

* AQ；
* TiA；
* S-TIAS；

这些都是**多条目已发表量表/子量表**。

因此报告内部一致性是合理的。

但是我不建议目前这种：

[
\alpha=.792/.751
\quad
(\omega=.796/.777)
]

每一个量表把α和ω一起念一遍。

原因很简单：**结果主线根本不需要两个高度重叠的内部一致性指标。**

尤其你们：

[
N=24
]

而AQ/S-TIAS还是3-item subscale，两个可靠性系数全部展开并不会增强论文可信度，只会让第6.3更像psychometrics report。

我建议主文只报告：

> Cronbach's (\alpha)

和VRGA保持一致。

(\omega)留在：

* 分析工作簿；
* supplementary material；
* provenance；

就可以。

### 七个自定义对象锚定条目不要算α

这一点也要保持。

你们明确把这七项作为：

> 七个独立结局，而不是一个潜变量量表。

所以不能因为有七个题就计算一个α。这会暗示它们测量同一latent construct，与你们的设计不一致。

# 3. `n < 24`：我同意你的担忧，主表建议删

Claude关于统计计算本身是对的。

你们实际有：

[
N=24
]

组完整配对。

Wilcoxon在某个结局上如果参与者打分完全相同：

[
d_i = x_{i,Ego}-x_{i,OneEuro}=0,
]

该pair没有正秩或负秩信息，因此不参与signed-rank statistic。

所以：

[
n_{\mathrm{nonzero}}=15\sim23
]

并不是：

> “只有15个人的数据有效”

更不是：

> “9个人被排除了”。

但这正是我认为**不应该把逐项 (n) 放在主表**的原因。

一个审稿人扫到：

```text
N = 15
```

第一反应很可能是：

> Why only 15 participants?

然后必须去读脚注，才知道不是missingness。

统计上正确，视觉表达上却容易误导。

# 4. (W)列我也建议删除

(W)是正规的Wilcoxon test statistic，没有错。

但它有两个问题。

首先，对于普通读者：

[
W=13.5
]

几乎没有直观解释价值。

相比之下：

[
p_{\mathrm{adj}}<.001,
\qquad
r_{\mathrm{rb}}=.90
]

直接告诉读者：

* 是否有统计证据；
* 效应方向与大小。

其次，不同统计实现对“Wilcoxon statistic”究竟报：

* positive rank sum；
* negative rank sum；
* 两者最小值；

存在表示习惯差异。

你们的analysis provenance里留着 (W) 就够了。

所以我建议：

> **主文不报告 (W)，分析附件保留 (W)。**

这不是隐藏统计信息，而是在主论文中选择可解释的信息。

# 5. (r_})反而应该留

你之前觉得这个不常见，这个感觉可以理解，但它与当前检验是匹配的。

你们使用：

[
\text{Wilcoxon signed-rank test}.
]

匹配样本秩双列相关：

[
r_{\mathrm{rb}}
]

就是基于正负signed ranks得到的效应量。

它有非常直接的方向语义：

[
r_{\mathrm{rb}}>0
]

表示EgoAnchor方向占优势；

[
r_{\mathrm{rb}}\rightarrow1
]

表示秩证据越来越一致地指向EgoAnchor。

比如静止稳定：

[
r_{\mathrm{rb}}=.90,
]

恢复一致：

[
r_{\mathrm{rb}}=.95.
]

这比单独给一个(W)有用得多。

因此最终保留：

```latex
$r_{\mathrm{rb}}$ [95\% CI]
```

完全合理。

另外，Claude把：

```latex
r_{rb}
```

改为：

```latex
r_{\mathrm{rb}}
```

也是正确的排版。`rb`是描述性下标，不是变量(r\times b)。
