VRGA的特点非常明确。它在User Study Results中不是一句话概括“VEQ若干维度更好”，而是分别报告VBO、Agency、Change、SL、SA、SS等指标，每个指标都给出统计量、(p)值和效应量；VHPQ、Realism、Naturalness、Synchrony同样逐项展开。

所以EgoAnchor也应该遵循：

> **一个核心指标，一个完整结果段。**

## 这版的粒度

实验一现在不再是三个大段，而是九个结果段：

```text
头动泄漏
绝对注册误差
静止帧间增量
有效时延
时延对齐 RMSE
当前时刻 RMSE
残余抖动
遮挡鲁棒性
起动转换
```

这样尤其解决了原来“动态保真度”一段同时解释4种不同量的问题。比如：

* 有效时延只回答响应快慢；
* lag-aligned RMSE只回答移除相位差后的轨迹误差；
* current-time RMSE单独明确EgoAnchor平移并不优于One-Euro；
* residual jitter再单独报告运动中的高频波动。

这种结构比把四个指标塞进一个长段更接近VRGA的写法。

实验二仍然严格对应图3的四个panel，但恢复了有意义的**效应幅度**，例如：

[
2.69[2.38,3.00]\times
]

和

[
17.06[13.89,27.52]\times.
]

我同意你说的，`12/12个片段方向一致`这一类内容不适合正文，已经全部删掉。

不过这里有一点需要特别注意：**不能把“12个片段”机械改成“多少帧”**。如果一个指标是先在重复动作/时间窗口内计算P95，再对这些P95取中位数，那么统计单位实际上不是单帧。直接写“基于几千帧”会让人误以为这些帧是独立样本，甚至产生pseudoreplication的问题。

更好的做法是：

> 第5章一次性交代数据规模，例如连续序列共包含多少有效帧/候选观测；
> 第6章只报告指标结果，不再强调“12/12”“16/16”之类的内部分析单元。

这比在每个结果段解释segment定义干净得多。

## 用户研究现在也真正模仿VRGA的统计汇报形式

VRGA的：

[
F_{2,46}=49.487,\quad
p<.001,\quad
\eta_p^2=.683
]

对应到你们的paired Wilcoxon，不应该强行变成(F)，而应该使用：

[
W,\quad
p_{\mathrm{adj}},\quad
r_{\mathrm{rb}}.
]

因此新版现在逐指标写，例如：

> **静止稳定。** EgoAnchor的静止稳定评分中位数为5.00 [4.58, 5.67]，高于One-Euro的4.33 [3.92, 4.67]。该差异经Holm校正后仍成立（(W=13.5)，(p_{\mathrm{adj}}<.001)，(r_{\mathrm{rb}}=.90)）。

这与VRGA的汇报结构是一致的：

```text
descriptive result
→ test statistic
→ adjusted p
→ effect size
```

而不是只写：

> “五项显著，p≤.003”。

现在七项自定义条目、AQ两个子量表、TiA两个分量表和S-TIAS都各自获得了独立结果段。

# 关于 (W)：现在我赞成加回表格

结合你现在希望模仿VRGA的形式，我认为：

[
W,\quad p_{\mathrm{adj}},\quad r_{\mathrm{rb}}
]

三者一起报告更完整。

之前建议删(W)，主要是考虑压缩表格；但现在既然Results采用逐指标统计汇报，保留Wilcoxon自己的test statistic更规范。

**逐项的非零差 (n) 仍然不建议放表格。**

理由没有变：

* 总样本明确是(N=24)；
* (n<24)只是零差被signed-rank test忽略；
* 表里出现`15`、`19`、`23`非常容易被审稿人第一眼理解成样本缺失。

一句表注说明：

> 全部结局均有24组完整配对；零差不进入Wilcoxon秩统计量。

已经足够。

## 字体也可以从 `\scriptsize` 提到 `\footnotesize`

新版使用：

```latex
\begin{table}[t]
...
\footnotesize
\setlength{\tabcolsep}{1.5pt}
```

而不是：

```latex
\begin{table*}[t]
...
\scriptsize
```

所以虽然宽度只有单栏，字体反而更大。


这样不会因为标题撑宽整张表。

这里我的建议和实验三不同。

**实验一表：暂时建议保留双栏。**

这反而会损害可读性。

实验一的Table更接近VRGA的Quantitative Table：它承担完整系统横向比较，本身值得宽一些。VRGA的Table 1/2也承担非常直接的多条件定量对照。

这样比“所有表都table*”更有节奏。
