### 实验一

我删除了正文中那段“平台内部预测与共同漂移，因此只能称相对行为”的解释，以及`-16 mm`外参补偿细节。它们不是实验设计主线，而且这些限制在Discussion的limitations里已经有完整说明，没有必要在第5章重复。

五个实验场景现在独立列出，并说明每个场景实际测什么：

* 静止目标 + 主动头动 → 世界一致性和静止抖动；

### 实验二

这里我没有继续称为“三个消融 + 一个额外比较”，而是统一成**四组组件归因**：

这个结构与结果图的四个panel正好一一对应。

其中第四项现在把两个方法真正讲清楚了：

> **Smoothed KF Extrapolation**：从最新的卡尔曼平滑状态出发，按常速度模型外推到当前渲染时刻。“Smoothed”指外推的起点是KF平滑状态，而不是原始候选。

> **历史插值（Linear/SLERP）**：按照§3.3.2已经定义的历史查询时刻，在已经到达的控制点之间执行位置Linear和旋转SLERP，不做速度外推。

因此保留`Linear/SLERP`作为实验标签没有问题，同时它现在和第3章的“时间索引轨迹取值”建立了明确联系。

`event`已经从全文相关位置清掉，统一使用：

> 遮挡过程

AURC也不再突然出现，而是第一次完整定义：

> 候选按VCD降序排列 → 保留前一定比例定义coverage → 保留候选平均平移误差定义risk → 对risk–coverage curve积分得到AURC。

并明确：

> AURC越低越好；100% coverage时的平均risk作为无筛选参考。

这样读者看到第6章的4.79 mm与7.25 mm时，已经知道它们是什么。

### 七项定制条目现在成为真正的重点

这一点你的批注尤其重要。

原稿只列：

> 静止稳定、运动附着、姿态一致……

却完全没说为什么是这七项。

现在先交代设计来源：

> 结合实验一的应用侧评价维度，并参考AR配准误差与用户信任之间的已有研究，针对动态对象锚定的静止、运动、遮挡恢复和持续使用阶段设计七项条目。

然后逐项解释它们测什么：

```text
静止稳定       → 静止时是否稳定
运动附着       → 平移时是否持续跟随
姿态一致       → 旋转时朝向是否一致
恢复一致       → 遮挡后是否恢复到原有相对关系
位置正确       → 虚实空间位置是否匹配
依赖意愿       → 是否愿意依赖锚点执行后续任务
稳定--响应平衡 → 两种系统属性的总体折衷
```

同时仍明确：

> 七项分别分析，不合并总分。

这样不会把研究自定义条目包装成一个未经验证的新量表。

AQ、TiA和S-TIAS也各自补了一句用途，而不是只丢出量表名字：

* AQ补充空间嵌入和交互质量；
* TiA/S-TIAS补充方法级可靠性、可预测性和信任。
