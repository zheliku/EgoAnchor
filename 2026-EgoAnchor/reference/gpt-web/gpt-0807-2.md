# 2. 把 (T_o^) 改成 (T_^)

这一点我认为比简单删除 `\mathcal` 更重要。

原来的

[
T_o^{c_f}
]

把“坐标系”和“帧索引”都塞进右上角，阅读起来不够自然。

现在统一成：

[
T_{o,f}^{c}.
]

含义很直接：

* (o)：object；
* (c)：camera；
* (f)：frame。

相应地：

[
T_{c,f}^{w},
\qquad
T_{o,f}^{w}.
]

于是采集时刻对齐变成：

[
T_^
===

T_{c,f}^{w}
S T_{o,f}^{c}S^{-1},
\qquad
S=\operatorname{diag}(1,-1,1,1).
]

这一形式比当前稿件的 (T_o^w(t_f),T_c^w(t_f),T_o^{c_f}) 三种索引风格混用干净很多。当前版本确实同时使用函数式时间索引和frame-in-superscript写法。

在轨迹阶段则使用：

[
\widehat T_{o,i}^{w},
]

而连续查询结果才写：

[
\widehat T_o^w(t_q).
]

这样形成非常清晰的层级：

[
T_{o,f}^{c}
\rightarrow
T_{o,f}^{w}
\rightarrow
\widehat T_{o,i}^{w}
\rightarrow
\widehat T_o^w(t_q)
\rightarrow
\widetilde T_o^w(t_r).
]

这是我建议最终冻结的位姿符号链。

# 4. 删除突然出现的 (\mathcal H_f)

新版改成：

[
M_f
===

\operatorname{Seg}(I_f^{L};M_{f_0}),

并只说明：

> (M_{f_0}) 用于初始化分割器的内部时序状态。

也就是说，我们承认视频分割器是stateful的，但**不把它的内部memory提升为EgoAnchor方法变量**。

这与VRGA处理off-the-shelf IK solver的方式一致：它描述solver的输入输出和约束，却没有把solver内部每一个状态都形式化。
