## 这次第6章怎么改

VRGA值得参考的不是“它报告很多 (F)、(p)、(\alpha)”本身。它的用户研究是一个真正的多因素设计，因此围绕每个dependent variable报告main effect、interaction及对应统计量；随后定量实验又直接用表格给出核心指标，正文只总结主要结果。

EgoAnchor也应该采用这种**结果围绕研究问题展开，而不是围绕分析脚本展开**的写法。

### 实验一：从五个“小报告段”改成三条连续结果主线

原来的结果章节按“世界一致性 / 静止 / 动态 / 遮挡 / 转换”逐项念数字，和第5章的指标定义重复。

现在变成三段：

1. **世界一致性与静止表现**
   从Arrival → Capture直接看到采集时刻对齐的作用，再落到One-Euro和完整EgoAnchor的稳定性。
2. **持续运动**
   只比较真正重要的EgoAnchor与One-Euro：

   * effective lag；
   * lag-aligned RMSE；
   * residual jitter；
   * current-time RMSE的代价。
3. **遮挡与起动响应**
   直接形成稳定性–响应性trade-off。

删除了：

* “12次遮挡过程中”；
* `>40 mm`灾难次数；
* “两种保持基线的时延范围……”这种分析式铺陈；
* 对两个RMSE为什么不同的大段解释。

原稿这些信息使正文不断产生新的问题，而不是回答结果。你标出的这几处正是主要问题。

# 实验一的表格我建议重做

你批注：

> 6.49°表中没有，是不是要补？
> 静止和遮挡为什么有的只有平移？
> 要不要按平移和旋转两类组织？

这里我的结论是：

**要补旋转结果，但不要把整张表按“平移/旋转”拆成两大块。**

原因是第5章已经把评价体系定义成：

[
\text{世界一致性}
\rightarrow
\text{静止稳定性}
\rightarrow
\text{动态保真度}
\rightarrow
\text{遮挡鲁棒性}
\rightarrow
\text{转换代价}.
]

表格最好继续保持这五个概念层级，否则第5章和第6章又会换一套阅读逻辑。

我做的新表是：

```text
评价维度              指标                         Arrival  Capture  One-Euro  EgoAnchor

世界一致性            头动泄漏 P95 (mm/°)
                      绝对注册误差 P95 (mm/°)

静止稳定性            帧间增量 P95 (mm/°)

动态保真度            有效时延 (ms, 平移/旋转)
                      时延对齐 RMSE (mm/°)
                      当前时刻 RMSE (mm/°)
                      残余抖动 P95 (mm/°)

遮挡鲁棒性            遮挡期平移误差 P95 (mm)

转换代价              起动转换时延 (ms)
```

凡是同时评价translation/rotation的指标，都在同一单元格中按：

[
\text{translation}/\text{rotation}
]

报告。

例如：

```text
Arrival:   43.67 / 6.49
Capture:   13.03 / 5.40
One-Euro:  10.65 / 3.29
EgoAnchor:  0.82 / 0.33
```

这样6.49°自然进入表中，也不会为了translation/rotation复制整套评价体系。
