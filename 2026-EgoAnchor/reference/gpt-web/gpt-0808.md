## 这版主要改了什么

**第一，删除“三层结构”这种元叙事。** 原来的“评价遵循完整系统行为—组件归因—感知效用的三层结构”有点像在解释论文结构。现在直接说三个实验分别回答什么问题，信息更直接。

新版开头是：

```latex
我们通过三个互补实验评价EgoAnchor。实验一在具有平台参考的受控条件下
比较完整系统与代表性基线，刻画世界一致性、静止稳定性、动态保真度、
遮挡鲁棒性和起停响应；实验二在相同输入上进行组件消融与时序策略比较，
分析关键机制对系统行为的贡献；实验三在日常刚性物体上开展被试内研究，
考察这些差异是否能够被用户感知，并影响其对对象锚点的信任与依赖。
```

这段之后直接进入实验一。

**第二，把平台参考的防御性说明压缩了。** 原稿关于平台预测、滤波、共同漂移、物理真值等内容连续占了很大篇幅。 这个validity scope需要保留，但没有必要在设计章节进行长篇辩护。

现在压成：

```latex
受控评价以Quest Touch Plus控制器作为视觉追踪目标，并以平台SDK输出的
控制器6DoF位姿作为同步参考。该参考与头显共享平台世界坐标系，因此本文
将其作为\emph{平台参考}而非外部物理真值。
```

固定的 (-16) mm 和模型旋转补偿继续保留，因为这是实验坐标配准的一部分，而不是无关实现细节。

**第三，四个系统条件全部放回实验一。** Arrival、Capture、One-Euro、EgoAnchor现在不再漂在一个通用的“系统配置”章节中，而明确是实验一的四个comparison conditions。

尤其补上了One-Euro为什么是主要baseline：

```latex
选择One-Euro作为主要平滑基线，是因为其面向含噪交互输入，
以速度自适应方式权衡抖动与响应延迟，与本文关注的稳定性--响应性
权衡直接对应。
```

这比把它称为“权威算法”更合适。它的价值不是“权威”，而是**它正好代表传统实时自适应平滑在 jitter–lag tradeoff 上的处理方式**。因此实验三只选择One-Euro与完整EgoAnchor比较，也有了自然依据。

**第四，实验一的五类指标直接跟在实验一后面。** 你当前稿件的问题之一正是“评价指标”作为独立subsection只服务实验一、二，却放在实验三前面，读者容易认为它是全文三实验的统一指标。

现在指标明确属于实验一：

* 世界一致性；
* 静止稳定性；
* 动态保真度；
* 遮挡鲁棒性；
* 转换代价。

而且去掉“表里只放什么、图里放什么”这种结果章节才需要的信息。
