# EgoAnchor 提交前全稿一致性审查（Draft 1）

## 本轮冻结建议

### 1. 评价侧三级术语
建议全文统一为：
- **静态配准**：头动泄漏、绝对配准误差、静止抖动；
- **动态跟随**：有效时延、LA-RMSE、CT-RMSE、残余抖动；
- **转换响应**：遮挡误差、起动转换时延。

理由：`静态/动态保真度`都使用“保真度”会弱化两组指标在系统行为上的差异；其中有效时延和起动响应本身也不是“保真度”。“静态配准 / 动态跟随 / 转换响应”分别对应目标静止、持续运动和状态转换，短且语义直接。

### 2. 不再把“世界一致性”作为评价一级术语
保留“世界系”“世界坐标语义”等坐标系技术术语；删除“世界一致性”作为系统属性或评价类别。主动头动下的相关行为统一归入“静态配准”，由头动泄漏和绝对配准误差具体定义。

### 3. 运行时术语
全文统一：
- 采集时刻对齐
- 观测准入
- 时间索引轨迹取值 / 历史轨迹取值（实验条件）
- 静止锚定（StaticLock）
- 有效性

已删除“质量准入”“历史插值”等漂移用词。

## 主要逻辑修订

1. 摘要不再声称“任意具备三维模型的日常物体”，改为“更多具备三维模型的日常刚性物体”。
2. 贡献 2 中 VCD 的作用限定为观测失效判定与观测准入的可靠性依据，不把“重新获取”直接归因于 VCD。
3. 实验一与结果章节使用同一套“静态配准—动态跟随—转换响应”组织。
4. 实验二 StaticLock 方法定义改为平移波动，与当前归因结果一致；VCD AURC 明确以平移误差定义风险。
5. 实验三补充 One-Euro 与 EgoAnchor 的共享机制和差异，避免用户研究比较对象在结果/讨论中才出现。
6. 连续定性回放从“静态配准”小节内部移到实验一三类结果之后，作为完整系统行为的定性补充。
7. Discussion 降低“AI/VR 能力升华”的抽象程度，改为围绕“零样本视觉观测如何经运行时成为可用对象锚点”展开。
8. 跨平台比较讨论改为评价参考问题：不同平台对象局部坐标系与模型原点不统一，二维投影又不能充分刻画 6DoF 误差；Quest Touch Plus 用于提供同平台世界系下的同步参考，不作为竞争算法。
9. Conclusion 收紧为两段：系统与证据；更一般的系统含义与后续方向。
