\title{EgoAnchor：透视混合现实中日常物体的稳定零样本动态锚定}
\author{作者待定}
\authorfooter{}

\abstract{%

零样本6DoF位姿估计正在把视觉定位扩展到更多具备三维模型的日常刚性物体，但其异步、低频且质量波动的输出难以直接作为稳定对象锚点。本文提出EgoAnchor，一套面向透视混合现实的零样本动态真实物体锚定系统，将该问题解耦为感知后端与锚定运行时两层：前者以持续感知流水线产生带可靠性评分的位姿观测；后者按采集时刻恢复观测的世界坐标语义，并由时间索引轨迹取值与静止锚定合成逐渲染帧锚点。我们以Meta Quest 3为头显实现该系统，并以平台参考基准、设计归因与24名参与者的被试内研究进行评价。结果显示，EgoAnchor在静态配准与遮挡恢复中获得更低误差，并降低时延对齐后的动态轨迹残差；用户研究进一步显示更高的主观稳定性、依赖意愿与方法级信任。其主要代价是更长的起动响应以及持续平移时较高的当前时刻误差。代码实现将随论文发表开源。
}

\firstsection{引言}\label{sec:introduction}
\maketitle

% ===== 第一段：问题动机 =====
透视混合现实（Passthrough Mixed Reality, PMR）正在将虚拟内容附着到用户身边的真实物体上，用于物体说明、操作引导、状态可视化与近物交互界面。这些应用不仅需要识别物体，还需要一个能够随物体移动而持续更新的对象级空间参考：当用户转头、拿起、旋转、放下或短暂遮挡物体时，虚拟内容应保持与物体一致的六自由度（6DoF）关系。传统空间锚点适合静态环境，却不能表达物体自身的运动，因此动态真实物体锚定是以物体为中心的消费级混合现实应用的基础系统能力。

% ===== 第二段：现有方案局限 =====
现有方案在不同层面提供部分支持。平台原生对象追踪通常具有良好系统集成，但其对象范围、模型准备与运行时行为由平台定义~\cite{appleObjectAnchor,appleObjectTracking2026,azureObjectAnchors,metaDynamicObjectTracker}；物理标记和专用追踪器能够提供稳定位置，却要求改造或装备目标物体；近年来的开放词表检测与分割、立体匹配与模型驱动的零样本6DoF位姿估计使给定三维模型的更多刚性物体能够被视觉定位~\cite{foundationpose2023,megapose2022}。然而，这些视觉方法主要输出某一图像时刻下相机坐标系中的物体位姿，尚未定义该位姿如何成为混合现实应用可持续使用的对象锚点。

% ===== 第三段：核心问题 =====
把这类视觉位姿直接当作对象锚点使用，会在运行时暴露一系列困难。异步推理结果返回应用时已经滞后，其相机系位姿描述的是历史图像采集时刻的几何关系；若与到达时刻的头显位姿复合，用户自身的头动会被错误地写入物体的世界位置。即使时间语义得到恢复，形式合法的位姿候选仍可能因遮挡、深度噪声或几何错配而在物理上错误，接纳这类候选会直接表现为可见跳变。此外，低频、时序不规则且含噪的位姿流不足以支撑逐帧渲染所需的连续性：运行时还须分别定义静止期的稳定性、运动期的跟随、起停转换以及短时失效与重新获取的行为。这些困难共同说明，位姿估计精度的提升本身并不足以定义可供应用绑定的对象锚点。

% ===== 第四段：EgoAnchor解决方案 =====
本文提出EgoAnchor，一套面向透视混合现实的零样本动态真实物体锚定系统。系统由感知后端与锚定运行时构成：感知后端从头显双目图像、目标语义和三维模型中持续恢复零样本6DoF位姿，并通过逐观测VCD评分衡量候选与当前图像证据的一致性；锚定运行时恢复异步观测的采集时刻世界语义，并由接纳观测生成逐渲染帧的世界系对象锚点。时间索引轨迹与静止锚定分别处理观测间的连续输出和静止期的残余波动，短时观测中断则由锚点的有效性标注管理。给定三维模型即可接入新的刚性目标，无需物理标记或逐物体训练。

% ===== 第五段：贡献 =====
本文的主要贡献如下：

\begin{enumerate}
  \item \textbf{EgoAnchor系统：}一套面向透视混合现实的零样本动态真实物体锚定系统，将异步、低频且质量波动的相机系位姿观测转化为稳定、连续且可恢复的世界系对象锚点。

  \item \textbf{锚定感知与运行时：}感知后端把独立视觉基础模型组织为面向锚定的持续感知流水线，并以逐观测VCD评分量化候选与当前图像证据的一致性，为观测失效判定与运行时观测准入提供可靠性依据；锚定运行时通过采集时刻对齐与观测准入校正异步观测，再以时间索引轨迹取值与静止锚定合成逐渲染帧对象锚点。

  \item \textbf{系统评价：}通过具有平台参考的受控基准、关键设计归因和24名参与者的日常物体研究，量化系统性能、关键设计、响应代价及其感知效用。
\end{enumerate}

\section{相关工作}\label{sec:related-work}

\subsection{平台级真实物体锚定}

真实物体锚定为物理对象建立稳定的对象级空间参考，使虚拟内容能够持续附着于真实物体。早期系统主要采用基于物理标记的方法，通过AprilTag、ArUco等人工标记获得稳定位姿估计~\cite{kato1999artoolkit,olson2011apriltag,garridojurado2014aruco}。这类方法实现简单、鲁棒性较高，但需要在物体表面贴附标记，难以适用于开放场景中的多类日常物体。

近年来，消费级混合现实平台开始提供免标记对象追踪能力。HoloLens 2的Azure Object Anchors利用设备感知与对象数字模型完成对象匹配，但主要面向较大尺寸的静态对象；Vuforia Model Targets基于对象形状与三维模型实现真实物体识别与跟踪，但依赖对象模型与离线Target准备流程；Apple Vision Pro的对象追踪已在visionOS 27中扩展至运动中与手持物体，但仍要求由目标三维模型生成平台参考对象；Meta Quest生态中的对象与场景能力同样由平台接口及其支持范围定义~\cite{appleObjectAnchor,appleObjectTracking2026,azureObjectAnchors,vuforiaModelTargets,metaDynamicObjectTracker}。

总体而言，现有平台提供的对象追踪能力通常依赖专用硬件、受限的平台接口或对象级离线流程，难以直接支持开放场景中的多类日常物体，也较少向开发者开放底层视觉感知结果。

\subsection{6DoF物体位姿估计与跟踪}

6DoF物体位姿估计旨在从图像中恢复刚性物体相对于相机的空间位姿，是动态真实物体锚定的感知基础。早期方法通常依赖局部几何特征与PnP求解，在弱纹理、遮挡以及复杂光照条件下鲁棒性有限。随后，大量深度学习方法针对特定物体学习位姿估计网络；CosyPose、MegaPose等方法结合渲染匹配提升了未知物体的泛化能力~\cite{cosypose2020,megapose2022}，FoundationPose则实现了无需逐物体训练的零样本6DoF位姿估计~\cite{foundationpose2023}。开放词表目标检测、视频对象分割与立体匹配等视觉基础模型进一步提升了开放场景中的对象感知能力。

然而，上述工作主要关注相机坐标系下6DoF位姿估计的准确性，对混合现实中的持续对象锚定涉及较少。视觉推理产生的异步时延、估计噪声与跟踪波动，使高精度位姿流仍难以直接驱动稳定的虚实配准。如何把这些独立视觉模块组织为面向锚定的感知流水线，并把异步位姿流转换为世界坐标系下稳定、连续且可恢复的对象锚点，则较少被作为系统问题处理。

\subsection{XR时延补偿与时间一致性}

配准误差与端到端时延自增强现实诞生以来便被认为是影响用户体验的核心问题~\cite{azuma1994improving,diluca2010latency}。对于依赖异步视觉感知的混合现实系统，图像采集、网络传输与模型推理通常引入数十毫秒乃至更高的端到端时延；当物体或用户快速运动时，这种异步时延表现为虚拟内容相对于真实物体的明显漂移与打滑。

围绕时延补偿，学界与工业界发展出两类互补思路。其一是预测式跟踪：头部位姿外推可以降低动态配准误差，双指数平滑等方法提供更轻量的预测替代。在交互输入侧，One Euro滤波器~\cite{casiez2012oneeuro}以速度自适应的方式权衡抖动与延迟，是三维用户界面处理含噪输入的常用基线。其二是后渲染对齐：异步时间扭曲（ATW）在扫描输出前用最新头显位姿重投影画面，已成为消费级头显的标准时延补偿手段~\cite{vanwaveren2016atw}。

现有研究主要关注设备位姿预测、显示重投影和交互输入平滑，而异步对象观测具有不同的时间语义：相机系位姿属于历史图像采集时刻，其世界系解释随相机运动而变化。由此产生的世界坐标错配、观测可靠性和逐帧锚点生成问题，尚未在零样本动态物体锚定系统中得到统一处理。

\section{EgoAnchor系统}\label{sec:system}

\subsection{系统概览}

EgoAnchor面向具有可用三维模型的刚性日常物体：新目标由文本提示与三维模型指定，不受预定义类别集合限定，也无需物理标记或逐物体训练。系统由感知后端与锚定运行时构成：前者从头显双目图像中持续形成带可靠性评分的相机系6DoF位姿观测；后者恢复这些异步、低频且质量波动观测的世界坐标语义，并生成稳定、连续且可恢复的逐渲染帧世界系对象锚点。

一个观测从成立到被应用消费，将经过三个不同的时刻：
\begin{itemize}[leftmargin=1.6em,itemsep=1pt,topsep=2pt]
  \item $t_f$：图像采集时刻，观测的相机系位姿在此刻成立；
  \item $t_a$：候选到达时刻，观测在此刻才对运行时可用；
  \item $t_r$：渲染时刻，应用在此刻需要一个锚点。
\end{itemize}
三者通常并不重合，锚定运行时须显式区分它们。全文以$T_a^b \in \mathrm{SE}(3)$记坐标系$a$到$b$的刚体变换，$w$、$c$、$o$分别指世界系、左目相机系与对象；对象位姿按加工阶段区分为单次观测换基所得的$T_o^w$、状态估计平滑后的$\widehat{T}_o^w$与提交给应用的锚点$\widetilde{T}_o^w$。离散取样以感知帧号$f$或接纳观测序号$j$作为对象下标的后缀，如$T_{o,f}^{c}$与$\widehat{T}_{o,j}^{w}$；连续时刻上的取值写作$\widehat{T}_o^w(t)$。运行时门槛与参数取值统一见附录~\ref{sec:appendix}。图~\ref{fig:arch}展示两层职责与数据流。

\subsection{感知后端}\label{sec:perception}

\textbf{输入与目标。}给定头显双目图像$I_f = (I_f^L, I_f^R)$、目标文本提示$Q_o$与三维模型$G_o$，感知后端为每个处理帧形成观测
\begin{equation}
o_f = (f, t_f, T_{o,f}^{c}, R_f),
\label{eq:observation}
\end{equation}
其中$f$为头显端分配的帧标识，$T_{o,f}^{c}$为目标在该帧极线校正后左目光学坐标系中的位姿，$R_f \in [0,1]$为逐观测可靠性评分。序列$\{o_f\}$构成连接两层的异步位姿流。

\subsubsection{面向锚定的感知流水线}

流水线依次建立目标身份、米制几何与相机系位姿。记$f_0$为当前跟踪段的\emph{初始化帧}，即取得可用掩膜与充分深度覆盖的首帧；重新获取时流水线回到该状态并重新指定$f_0$。

\textbf{语义初始化。}开放词表检测器~\cite{yoloe2025}在$f_0$由左目图像与文本提示得到初始掩膜
\begin{equation}
M_{f_0} = \operatorname{Detect}(I_{f_0}^{L}, Q_o),
\label{eq:detect}
\end{equation}
文本条件使检测不受预定义类别集合约束，接纳新对象无须针对目标的重新训练。

\textbf{时序分割。}初始掩膜$M_{f_0}$用于初始化视频对象分割器~\cite{cutie2024}的时序记忆；此后分割器逐帧传播掩膜并同步更新该记忆$H_f$：
\begin{equation}
(M_f, H_f) = \operatorname{Seg}(I_f^{L}, H_{f-1}), \qquad f > f_0,
\label{eq:seg}
\end{equation}
其中$H_f$为分割器聚合已处理帧所得的目标表观记忆。该记忆使目标身份在视角变化与部分遮挡下得以保持，位姿估计因而始终作用于同一目标，而非每帧独立检测的结果。

\textbf{立体几何重建。}立体匹配器由校正后图像对预测视差$d_f$，再按基线$b$与像素焦距$f_x$恢复米制深度：
\begin{equation}
d_f = \operatorname{Stereo}(I_f^{L}, I_f^{R}), \qquad Z_f = \frac{b f_x}{d_f}.
\label{eq:depth}
\end{equation}
米制深度使锚点具有与真实场景一致的物理尺度，虚拟内容的位置与朝向因而可直接以米制单位表达。

\textbf{零样本位姿估计。}模型驱动位姿估计器~\cite{foundationpose2023}由掩膜、深度与目标模型恢复相机系位姿：
\begin{equation}
T_{o,f}^{c} =
\begin{cases}
\operatorname{Reg}(M_f, Z_f, G_o), & \text{注册}, \\
\operatorname{Track}(M_f, Z_f, G_o, T_{o,f^-}^{c}), & \text{追踪},
\end{cases}
\label{eq:pose}
\end{equation}
其中$f^-$为最近一个已处理帧。注册在$f_0$与重新获取时执行全局位姿搜索，追踪则以前一位姿为初值局部细化，因而观测流在时间上连续演化而非逐帧独立求解。

\subsubsection{逐观测VCD评分}

零样本位姿估计的几何优化可能收敛至局部最优，产生形式合法但物理错误的位姿，因此候选仍需得到当前图像证据的支持。VCD（Visibility-gated Color-Depth）沿用渲染匹配范式~\cite{cosypose2020,megapose2022}，把候选位姿下的模型渲染与同帧观测比较，为每个候选给出运行时可靠性评分。

\textbf{可视度门控。}记$M_f^{\mathrm{rnd}}$为候选位姿下的渲染掩膜，$\operatorname{Erode}$为形态学腐蚀，则共同支撑区、核心区与可视度依次为
\begin{equation}
\Omega_f = M_f \cap M_f^{\mathrm{rnd}}, \quad \Omega_f^{\circ} = \operatorname{Erode}(\Omega_f), \quad V_f = \frac{|\Omega_f|}{|M_f^{\mathrm{rnd}}|},
\label{eq:visibility}
\end{equation}
其中$V_f$为渲染投影中获得观测掩膜支持的比例，遮挡与投影错位均使其下降；腐蚀则收缩支撑区边界，使颜色与深度一致性只在$\Omega_f^{\circ}$内计算，排除掩膜边缘的混合像素。

\textbf{外观与几何一致性。}颜色一致性$S_f^C$取两幅图像在LAB空间的零均值归一化互相关，亮度通道降权，使评分由色度结构而非光照强度决定。深度一致性含互补两项：绝对项$S_f^{D,\mathrm{abs}}$由距离自适应容差下的内点率与归一化残差凸组合而成，容差随目标距离按比例放大以匹配立体深度的不确定度；结构项$S_f^{D,\mathrm{str}}$在中位数--四分位距归一化后取互相关，只比较形状起伏而对整体深度偏置不敏感。两者融合为
\begin{equation}
S_f^D = (1-\alpha_f)\,S_f^{D,\mathrm{abs}} + \alpha_f\,S_f^{D,\mathrm{str}},
\label{eq:depth-score}
\end{equation}
权重$\alpha_f$随渲染深度的四分位距增大并设有上限：平坦目标主要依据绝对残差，深度起伏明显时才引入结构约束。

\textbf{证据聚合。}单帧未必两路证据都可用：纯色目标的核心区颜色方差趋零，有效深度覆盖率过低时深度证据同样失效。记$K_f \subseteq \{C, D\}$为本帧有效模态集合，则
\begin{equation}
R_f = V_f \cdot
\begin{cases}
\exp\!\left(\dfrac{\sum_{k \in K_f} w_k \ln \max(S_f^{k}, \epsilon)}{\sum_{k \in K_f} w_k}\right), & K_f \neq \varnothing, \\[6pt]
1, & K_f = \varnothing,
\end{cases}
\label{eq:vcd}
\end{equation}
其中$w_k$为模态权重，$\epsilon$为对数下限。几何平均要求所有\emph{可用}证据同时支持候选，评分才接近1；无效模态被整体剔除而非计入低分，因而目标缺少纹理不等同于证据不支持。可视度以乘性方式门控整个评分：遮挡通过该项压低总评分，运行时因而将其判为观测失效而非接纳一个错误位姿，并据此决定后续的重新获取。锚定运行时以阈值$R_{\min}$实施准入；权重、下限与覆盖率门槛见附录~\ref{sec:appendix}。

\subsection{锚定运行时}\label{sec:anchoring}

锚定运行时包含观测校正与锚点合成两项过程。观测校正在候选到达时把相机系位姿恢复为正确的世界坐标语义，并经准入形成时间索引轨迹（第\ref{sec:obs-update}节）；锚点合成在每个渲染帧从该轨迹取值，并按运动状态在跟踪与锁定之间选择输出（第\ref{sec:frame-output}、\ref{sec:staticlock}节）。

\subsubsection{观测校正}\label{sec:obs-update}

感知后端输出的是绑定于采集帧的相机系位姿候选，其世界坐标表示尚未恢复，且候选的可靠性与时间顺序并不总能满足锚点更新要求。运行时因此先按采集时刻恢复候选的世界系位姿，再依据可靠性与时序执行准入，并由接纳观测更新状态估计与时间索引轨迹。

\textbf{采集时刻对齐。}视觉位姿$T_{o,f}^{c}$描述的是目标与\emph{采集时刻}相机之间的几何关系，而观测在$t_f$成立却在较晚的$t_a$返回，$[t_f, t_a]$区间内的头动会把相机位移错误地写入物体的世界位置。运行时因此在采集时以帧标识$f$为键记录当时的相机--世界变换，候选返回后按$f$回查$T_{c,f}^{w}$并换基至世界坐标系：
\begin{equation}
T_{o,f}^{w} = T_{c,f}^{w}\, S\, T_{o,f}^{c}\, S^{-1}, \qquad S = \operatorname{diag}(1,-1,1,1),
\label{eq:capture-alignment}
\end{equation}
其中$S$为视觉约定（$y$下）与渲染约定（$y$上）之间沿$y$轴的固定镜像，故$S^{-1}=S$；其共轭形式在改变坐标约定的同时保持刚体位姿的几何含义。以帧标识配对使候选与其采集时刻的相机--世界位姿直接对应，式~\eqref{eq:capture-alignment}因而给出与图像采集时刻一致的世界系观测。

\textbf{准入。}形式合法的位姿仍可能在几何上错误。接纳观测按采集时刻递增编号，第$j$个接纳观测的采集时刻、世界系位姿与可靠性记为$t_j$、$T_{o,j}^{w}$与$R_j$。首个候选满足可靠性门槛即可建立轨迹；已有$j$个接纳观测时，新候选还须晚于$t_j$：
\begin{equation}
R_f \geq R_{\min}, \qquad t_f > t_j \quad (j \geq 1),
\label{eq:admission}
\end{equation}
两项条件分别拦截低一致性候选与乱序候选。被拒候选既不写入轨迹也不更新状态，因而不污染后续插值。

\textbf{状态更新。}每个接纳观测触发一次量测更新，平移与旋转分通道以常速度模型估计，旋转在名义姿态的局部切空间中处理以避免四元数的直接线性化，输出平滑控制点$\widehat{T}_{o,j}^{w}$。控制点与接纳观测一一对应，故截至第$j$个接纳观测的轨迹按采集时刻索引为
\begin{equation}
B_j = \{(t_i, \widehat{T}_{o,i}^{w})\}_{i=1}^{j}.
\label{eq:trajectory}
\end{equation}
同一更新还刷新静止锚定所需的运动与可靠性证据。

\subsubsection{锚点合成}\label{sec:frame-output}

轨迹$B_j$是低频且时序不规则的离散采样，而渲染需要为每一帧提供明确定义的锚点。锚点合成因此先查询一个历史时刻而非预测当前时刻，再按运动状态决定该帧的输出模式。轨迹本身按采集时间索引，帧标识仅用于式~\eqref{eq:capture-alignment}中的采集帧配对。

\textbf{查询时刻。}末端控制点$t_j$总对应一个已经过去的采集时刻，其年龄$\ell_r$随处理耗时与候选间隔变化，故$t_r$通常尚无控制点覆盖。运行时因此把取值时刻回溯一段自适应时延：
\begin{equation}
\ell_r = t_r - t_j, \qquad \Delta_r = \max(\Delta_{\min},\, s\,\bar{\ell}_r), \qquad t_q = t_r - \Delta_r,
\label{eq:target-time}
\end{equation}
其中$\bar{\ell}_r$为$\ell_r$的非对称指数估计，快升慢降使偶发长时延不被迅速遗忘；$s>1$为安全系数，$\Delta_{\min}$为最小缓冲时延。回溯量因而随控制点年龄自适应，使查询时刻尽可能落在相邻的两个已到达控制点之间。

\textbf{轨迹取值。}设$t_i \leq t_q \leq t_{i+1}$，则逐帧跟踪位姿为
\begin{equation}
\lambda_q = \frac{t_q - t_i}{t_{i+1} - t_i}, \qquad \widehat{T}_o^w(t_q) = \operatorname{Interp}(\widehat{T}_{o,i}^{w}, \widehat{T}_{o,i+1}^{w}; \lambda_q),
\label{eq:delayed-interp}
\end{equation}
其中$\operatorname{Interp}$对位置执行线性插值、对旋转执行SLERP；查询落在轨迹两端之外时保持最近端点，不按速度模型外推。该策略只使用已经到达的观测，以显式的历史滞后避免对尚未观测的目标状态进行外推；相应的时延--残差权衡在第\ref{sec:results}节量化。

\textbf{输出模式。}轨迹取值仍保留观测噪声在静止期引起的残余波动。EgoAnchor因此按运动状态在跟踪与锁定之间显式切换：
\begin{equation}
\widetilde{T}_o^w(t_r) = \begin{cases}
\widehat{T}_o^w(t_q), & \text{跟踪}, \\
T_{o,\mathrm{lock}}^w, & \text{锁定},
\end{cases}
\label{eq:staticlock}
\end{equation}
其中锁定位姿$T_{o,\mathrm{lock}}^w$与释放证据一同在观测校正中维护，模式转换则在渲染帧边界提交。

输出另附\emph{有效性}标注，说明该锚点是否仍受观测支持：短时缺少可靠观测时继续在已有控制点上取值，控制点耗尽后保持最后可信位姿并标记其不确定，持续失效则判定丢失、停止交付锚点并触发重新获取。

\subsubsection{静止锚定}\label{sec:staticlock}

静止锚定（StaticLock）把静止从连续轨迹中分离为一个独立的输出模式，以抑制静止期的残余波动，并由运动证据触发释放。锁定不足会保留静止期波动，过度锁定则延迟对真实运动的响应，因此进入采用驻留判定，锁内通过死区控制低增益更新，释放则由互补的运动与可靠性证据触发。

\textbf{进入。}相邻接纳观测的位姿差分经指数平滑得到平移与旋转速率$\bar{v}_j$与$\bar{\omega}_j$；二者按各自门槛归一化为无量纲运动统计量，再与入锁可靠性门槛$R_{\mathrm{lock}}$共同定义进入条件：
\begin{equation}
\sigma_j = \max\left(\frac{\bar{v}_j}{v_{\mathrm{th}}},\ \frac{\bar{\omega}_j}{\omega_{\mathrm{th}}}\right), \qquad \sigma_j \leq 1, \qquad R_j \geq R_{\mathrm{lock}},
\label{eq:lock-entry}
\end{equation}

归一化使平移与旋转在同一尺度上比较；取观测差分而非滤波器状态，可避免平滑本身把真实运动衰减为静止。上述条件持续$\tau_{\mathrm{dwell}}$后，系统在下一渲染帧以当前跟踪位姿$\widehat{T}_o^w(t_q)$初始化锁定位姿$T_{o,\mathrm{lock}}^w$，故模式切换保持$C^0$连续。运行时另维护一个持续跟随接纳观测的低通\emph{观测共识}，并在入锁时冻结其当前值为\emph{锚定参考}$T_{o,\mathrm{ref}}^w$，此后累计漂移即由观测共识相对该参考的偏移度量。锚定参考与锁定位姿相互独立，使锁内允许的位姿微调不会吸收目标自入锁以来的缓慢真实运动。

\textbf{锁内更新。}
记$d_{p,j}$与$d_{\theta,j}$为接纳观测$T_{o,j}^{w}$相对当前锁定位姿的平移与旋转残差，$d_{\mathrm{db}}$与$\theta_{\mathrm{db}}$为对应的死区半径，则锁定位姿按
\begin{equation}
T_{o,\mathrm{lock},j}^w =
\begin{cases}
\operatorname{Interp}
\left(
T_{o,\mathrm{lock},j-1}^w,
T_{o,j}^{w};
g_j
\right),
&
\begin{aligned}[t]
&d_{p,j} \leq d_{\mathrm{db}},\\
&d_{\theta,j} \leq \theta_{\mathrm{db}},
\end{aligned}
\\[2pt]
T_{o,\mathrm{lock},j-1}^w,
&
\text{否则}.
\end{cases}
\label{eq:lock-update}
\end{equation}
更新。死区构成低增益更新与运动证据累积之间的分流边界：区内残差以增益$g_j$缓慢吸收，使锚点能够跟随长期观测变化而不响应逐帧波动；任一通道越界后，锁定位姿停止更新，残差转而进入释放证据。增益$g_j$根据观测可靠性与头动强度调节，具体形式见附录~\ref{sec:appendix}。

\textbf{释放。}死区外残差按可靠性加权累积为带泄漏的累积和（CUSUM），平移通道为
\begin{equation}
E_{p,j} = 2^{-\Delta t_j / h_E} E_{p,j-1} + \frac{\Delta t_j}{t_{\mathrm{ref}}} R_j \max\!\left(0,\, d_{p,j} - d_{\mathrm{db}}\right),
\label{eq:cusum}
\end{equation}
旋转通道同理；$h_E$为证据半衰期，$\Delta t_j$为相邻锁内观测的间隔，除以参考间隔$t_{\mathrm{ref}}$使累积速率与候选到达率无关。泄漏项使孤立噪声尖峰被遗忘，持续的死区外偏移最终触顶。

四类互补证据中任一成立即在下一渲染帧退回跟踪模式：

\begin{itemize}
  \item \emph{持续残差}：$E_{p,j}$或$E_{\theta,j}$触顶，表明接纳观测持续偏离锁定位姿；
  \item \emph{累计漂移}：观测共识相对锚定参考$T_{o,\mathrm{ref}}^w$的绝对偏移越界，使缓慢的真实位移不被永久锁定；
  \item \emph{明确运动}：$\sigma_j$超过释放倍率的持续时长越界，比位移更早给出运动信号；
  \item \emph{可靠性下降}：可靠性持续低于释放阈值，避免锚点冻结在错误位姿上。
\end{itemize}

前两类基于位姿偏移，后两类分别补充运动速率与观测可靠性。运动类门槛随头动强度自适应放大，以降低视角变化引起的观测滑移被误判为物体运动的风险。释放后，锚点经短暂接缝过渡回到跟踪轨迹。该设计以起停转换延迟换取静止期显著降低的输出波动，收益与代价在第\ref{sec:results}节并列量化；重锁抑制与完整阈值见附录~\ref{sec:appendix}。

\subsection{运行流程}\label{sec:runtime-alg}

综合上述方法，EgoAnchor的在线过程可概括为：
\begin{enumerate}
  \item 由双目图像形成对象掩膜、米制深度与零样本位姿，并计算逐观测VCD评分；
  \item 按采集帧回查相机位姿，将候选恢复为世界系观测，并依据可靠性与时间顺序执行准入；
  \item 由接纳观测更新状态估计、追加轨迹控制点，并刷新运动与释放证据；
  \item 在每个渲染时刻确定历史查询时刻，在已有控制点之间取值得到跟踪位姿；
  \item 提交待决的模式转换，按跟踪或锁定输出锚点，并附加有效性标注。
\end{enumerate}

\section{系统实现}\label{sec:implementation}

EgoAnchor的感知后端与锚定运行时通过局域网通信。感知后端执行于配备NVIDIA GeForce RTX 5090的GPU工作站，基于Python 3.14.6、PyTorch 2.12.1、CUDA 13.2与TensorRT 11.1实现。运行时基于Unity 6000.3.11f1与Meta XR SDK 203.0.0开发，实验中经Meta Quest Link执行于一台配备Intel Core i9-14900K CPU与32~GB内存的主机；Meta Quest 3作为头显，承担双目图像采集、设备位姿追踪与显示。

\textbf{感知后端。}
YOLOE-26用于开放词表初始化，Cutie用于传播帧间目标掩膜，Fast-FoundationStereo恢复双目几何，其TensorRT推理采用FP16精度与四次迭代。FoundationPose根据目标三维模型执行零样本6DoF注册与追踪，注册和追踪分别采用五次与两次细化。VCD评分借助nvdiffrast渲染目标模型，并比较颜色、深度与掩膜一致性。追踪阶段的服务器处理时间中位数为75.44~ms，P95为88.47~ms。我们也测试了EgoAnchor在RTX 3090、RTX 4090和RTX 5080 Laptop上的开发配置，开发过程中观察到的处理时间约为70--130~ms；本文报告的全部定量结果均取自上述RTX 5090配置。

\textbf{锚定运行时。}
运行时以C\#实现，并通过Meta Passthrough Camera API获取双目图像及相机标定。帧索引的相机位姿历史采用有界缓存，状态更新使用常速度卡尔曼滤波，平移与旋转分别维护独立通道。观测准入阈值$R_{\min}=0.2$，追踪状态的可靠性下限为0.5，重新注册阈值为0.45。三者分别控制候选是否进入轨迹、当前输出是否仍具有可靠观测支持，以及何时启动重新获取。历史查询时刻使用安全系数$s=1.15$和最小缓冲时延$\Delta_{\min}=250$~ms。静止锚定、有效性规则与VCD评分的其余参数见附录~\ref{sec:appendix}，全部参数在所有实验中预先固定。

\textbf{通信。}
系统将高带宽图像流与低带宽结果、状态和控制消息分离。数据面采用ZeroMQ发布--订阅模式传输Protobuf编码的双目JPEG图像与相机标定，并实行最新帧优先；消息面采用NATS Core与Protobuf传输位姿观测、状态事件和请求--应答控制命令。图像与返回观测保留一致的帧标识，用于运行时恢复观测对应的采集时刻相机位姿。

\section{评估设计}\label{sec:evaluation}

我们通过三个互补实验评价EgoAnchor。实验一在受控条件下表征完整系统的应用侧锚点行为，并与三种代表性对照比较；实验二以针对性归因检验采集时刻对齐、VCD、静止锚定与轨迹输出策略各自的作用；实验三在日常刚性物体上开展被试内用户研究，评价这些系统差异的感知效用及其对信任与依赖的影响。

\subsection{实验一：应用侧锚点行为}\label{sec:exp1-design}

\textbf{参考与场景。}
评价以Quest Touch Plus控制器为视觉追踪目标，以平台SDK输出的控制器六自由度位姿为同步参考。五组连续采集序列归纳为四类典型行为：
\begin{enumerate}
  \item \textbf{静止与头动：}目标保持静止而观察位姿主动改变，考察主动观察者运动下的静态配准与静止期稳定性；
  \item \textbf{起停运动：}目标在静止与6DoF运动之间反复切换，考察静止锚定的进入、释放与起动响应；
  \item \textbf{持续运动：}分别采集连续平移与连续旋转序列，考察运动过程中的响应滞后、轨迹保真度与残余抖动；
  \item \textbf{遮挡恢复：}目标完全遮挡后重新显露，考察短时观测失效与重新获取期间的锚点行为。
\end{enumerate}

\textbf{比较条件。}
实验一比较四种运行时配置。\textbf{Arrival}代表直接消费异步视觉位姿的朴素方案，按候选到达时刻解释其世界位姿；\textbf{Capture}将同一候选恢复到其图像采集时刻，用于表征时间语义对齐带来的变化；\textbf{One-Euro}以One-Euro滤波~\cite{casiez2012oneeuro}作为主要平滑基线；\textbf{EgoAnchor}为本文完整系统。前两者构成时间语义上的基础对照，划出不作专门处理时的行为边界。One-Euro则是一种成熟、轻量且在三维用户界面中广泛用于含噪实时输入的速度自适应低通滤波方法，其设计目标正是在抑制抖动的同时维持运动响应，因此构成稳定性--响应性权衡上的主要基线。


\textbf{评价指标。}
对象锚点在应用中需同时应对观察者运动、目标静止、目标运动、遮挡与起停转换。我们据此将九项指标归入三个评价方面。\textbf{静态配准}刻画目标静止时锚点与真实对象之间的空间关系：头动泄漏反映观察者运动引入的相对位姿变化，绝对配准误差反映锚点相对平台参考的空间偏差，静止抖动以帧间增量衡量逐帧可见波动。\textbf{动态跟随}刻画目标运动时锚点对真实运动的跟随行为：有效时延描述响应滞后，时延对齐均方根误差（lag-aligned RMSE，LA-RMSE）给出补偿主要响应时延后的轨迹残差，当前时刻均方根误差（current-time RMSE，CT-RMSE）给出当前渲染时刻的实际配准误差，残余抖动描述对齐残差中的高频波动。\textbf{转换响应}刻画观测中断与运动状态切换时的锚点表现：遮挡误差取遮挡开始至稳定恢复期间的误差，起动转换时延（start-transition latency）为静止锚定释放后锚点开始响应真实运动所需的时间。除起动转换为跨通道标量外，各指标均分平移与旋转两个通道报告。头动泄漏、绝对配准误差、静止抖动、残余抖动与遮挡误差以P95汇总，LA-RMSE与CT-RMSE按均方根误差计算。

\subsection{实验二：设计归因}\label{sec:exp2-design}

实验二针对四项关键设计进行配对比较，以相应场景中的锚点行为变化量化其作用。

\textbf{采集时刻对齐。}
同一相机系候选分别按图像采集时刻与候选到达时刻恢复世界位姿，比较主动头动条件下的位姿泄漏，评价时间语义恢复对静态配准的影响。

\textbf{静止锚定。}
在完整EgoAnchor上关闭静止锚定，比较静止阶段的平移波动，评价其对静止期残余抖动的抑制作用。

\textbf{VCD。}
候选按VCD评分排序，并以风险--覆盖率曲线下面积（AURC）概括评分与平移误差之间的排序关系；AURC越低，表示较高VCD评分越集中于较低误差的候选。

\textbf{轨迹输出策略。}
预测外推可用于降低实时跟踪的响应滞后，而EgoAnchor采用基于已到达控制点的历史轨迹取值。我们比较平滑卡尔曼外推（Smoothed KF Extrapolation）与历史轨迹取值（Linear/SLERP）：前者从最新卡尔曼平滑状态按常速度模型外推至当前渲染时刻，后者按第~\ref{sec:frame-output}节定义的历史查询时刻在已到达控制点之间取值。

\subsection{实验三：用户研究}\label{sec:exp3-design}

实验一与实验二测量的系统差异是否对使用者感知的锚点质量产生影响，须由用户研究回答。因此，实验三在日常刚性物体上比较One-Euro与完整EgoAnchor，重点考察静止稳定性、运动附着、遮挡恢复以及用户对锚点使用的信任与依赖。

\subsubsection{实验设计}

研究采用$2 \times 3$完全被试内设计，两个因素分别为锚定方法（One-Euro、EgoAnchor）与物体（无线鼠标、订书机、游戏手柄）。两个方法条件共享采集时刻对齐、VCD驱动的观测准入、历史轨迹取值与有效性规则；One-Euro采用One-Euro滤波且不启用静止锚定，EgoAnchor采用本文完整的状态估计与静止锚定。

物体选择围绕四个与视觉锚定直接相关的属性展开：尺度、几何形态、表面纹理和抓握遮挡。无线鼠标尺寸较小、曲面连续且纹理较弱；订书机细长、多平面且方向性明确；游戏手柄尺寸较大、几何与纹理更丰富，并在自然抓握时产生更明显的手部遮挡。三者由此构成跨上述属性的异质物体集合，用于考察不同视觉与交互条件下的主观锚定体验。物体顺序与方法顺序在参与者间平衡，两种方法以匿名A/B标签呈现。

\subsubsection{任务}

每个方法--物体条件依次包含三项操作：
\begin{enumerate}[leftmargin=1.8em,label=(\arabic*),itemsep=1pt,topsep=2pt]
  \item \textbf{静止观察：}物体固定于桌面，参与者从正面、左右侧及略近视角观察虚拟内容的附着与稳定性；
  \item \textbf{移动与放置：}参与者拿起物体，完成约25--30~cm的平移与约30--45°的自然旋转，在空中短暂停留后放置到目标区域并继续观察；
  \item \textbf{遮挡与恢复：}物体保持静止，以统一挡板完全遮挡约1~s，随后移除挡板并观察锚点恢复。该时长经预实验固定，使锚点在遮挡期间保持最后可信位姿并在挡板移除后重新获取观测。
\end{enumerate}

三项任务连续完成后统一评分，静止、运动与恢复因而共同构成一次完整的对象锚定体验。

\subsubsection{主观测量}

主观测量分为两部分。本文的\textbf{对象锚定条目}直接测量参与者感知到的锚点行为；三个\textbf{已发表量表}测量该行为最终形成的增强质量与参与者对方法的信任，依次为Augmentation Quality（AQ）、Trust in Automation（TiA）与S-TIAS。

\textbf{增强质量（Augmentation Quality, AQ）。}
AQ是面向XR增强质量的专用量表~\cite{schein2025aq}。我们采用其嵌入质量（Embedding Quality，EQ）与交互质量（Interaction Quality，IQ）两个完整的三条目子量表：前者评价虚拟内容与真实物体及环境的融合、嵌入可信度与尺度协调，后者评价经真实物体操作时的交互直观性、实时响应与运动平滑性。对象锚定条目考察锚点行为本身，AQ则考察该行为最终形成的增强质量。两个子量表均采用七点同意度评分，本文仅对条目的指代对象作情境化适配。

\textbf{自动化信任（Trust in Automation, TiA）。}
锚点能否被采纳取决于使用者是否信任它，因此我们采用面向自动化信任的TiA量表~\cite{koerber2019tia}，选取可靠性/能力（Reliability/Competence）六项与可理解性/可预测性（Understanding/Predictability）四项。前者对应「锚点是否可靠」，后者对应「锚点的行为是否可预期」，二者共同覆盖信任的能力维度与透明性维度。TiA采用五点同意度评分。

\textbf{短版信任量表（Short Trust in Automation Scale, S-TIAS）。}
TiA的两个分量表给出分维度的信任判断，S-TIAS则以三个条目给出一个总体信任分~\cite{mcgrath2025stias}，以最低的施测负担记录参与者对该方法的整体信心、可靠性与信任。S-TIAS采用七点评分，本文同样仅对条目的指代对象作情境化适配。全部中文条目由英文原文翻译并逐条核对语义，预实验通过认知访谈检查情境化措辞的可理解性。

最终问卷另记录总体方法偏好、信任选择、偏好强度、方法区分信心、两项开放反馈以及实验后不适情况，作描述性分析。

\subsubsection{实验流程}

研究经作者所属机构的伦理审查批准，全部参与者在实验前签署知情同意书，并被告知可随时退出。参与者首先完成背景问卷并调整头显，随后通过一次练习熟悉三项标准化操作与头显内评分界面。正式阶段依次体验六个方法--物体条件，每个条件结束后完成对象锚定条目与AQ评分。全部条件结束后，参与者分别对两种方法完成TiA与S-TIAS评价，并填写最终问卷。单次实验约持续60分钟，其间可按需休息。

\subsubsection{参与者}

我们通过实验室平台招募24名参与者，全部完成实验并纳入分析。参与者年龄20--36岁（$M=27.08$，$\mathrm{SD}=4.45$），女性12名、男性12名；22名惯用右手、2名惯用左手，15名视力正常、9名矫正后正常。VR/MR使用经验分布较广：6名此前从未使用，10名使用过1--5次，其余8名至少有6次使用经历。对于需要操作真实物体的AR/MR应用，12名无相关经验，6名有1--2次经验，其余6名有数次或经常使用的经历。该分布同时包含首次接触者与有经验使用者的判断。

\subsubsection{统计分析}

七项对象锚定条目与AQ两个子量表先在每位参与者内对三个物体取均值，TiA两个分量表与S-TIAS使用方法级得分，共形成12项主观结局。TiA中的反向条目按原量表计分规则完成反向计分后再计算分量表得分。各结局以中位数及第一、第三四分位数（Mdn [Q1, Q3]）描述。全部结局均有24组完整配对；方法间比较采用双侧条件精确Wilcoxon符号秩检验，零差不进入秩统计量。效应量采用与该检验配套的匹配秩双列相关$r_{\mathrm{rb}}$，并给出参与者级自举95\%置信区间。多重比较按测量来源预先划分为两个家族：七项对象锚定条目构成第一家族，其内部的两组划分只用于组织报告，不再细分校正范围；AQ-EQ、AQ-IQ、TiA两个分量表与S-TIAS构成第二家族。两个家族分别采用Holm校正。已发表量表的条目内部一致性在本样本内按方法计算并报告Cronbach's $\alpha$。

图~\ref{fig:exp2-final}(a,b)分别隔离了世界系复合所使用的时间语义与静止锚定。主动头动条件下，同一批相机系候选按图像采集时刻复合时，位姿泄漏P95的中位数为15.38~mm；若改用候选到达时刻的相机位姿，该值升至43.75~mm，配对倍率为2.69 [2.38, 3.00]倍，表明采集时刻对齐本身即可大幅缩小由头动引入的空间错配。在完整EgoAnchor上仅关闭静止锚定后，静止条件下的静止平移波动P95由0.82~mm升至13.73~mm，对应17.06 [13.89, 27.52]倍的配对差异。该结果表明，静止锚定是静止期低波动输出的主要来源。

图~\ref{fig:exp2-final}(c)以风险--覆盖率曲线评估VCD评分与候选误差的排序一致性。按VCD评分从高到低保留候选时，遮挡条件下的AURC为4.79 [4.20, 5.13]~mm；若忽略排序并保留全部候选，对应的平均风险为7.25 [5.15, 7.95]~mm。随覆盖率下降，低评分候选被优先移除，保留观测的平均平移误差随之降低。该关系表明VCD评分与候选几何误差具有一致的排序关系，支持其作为逐观测可靠性量参与运行时观测准入。

图~\ref{fig:exp2-final}(d)比较平滑卡尔曼外推与历史轨迹取值的响应时延和轨迹残差。平滑卡尔曼外推的有效时延为305.00/250.00~ms，低于历史轨迹取值的360.00/345.00~ms；但其时延对齐RMSE升至45.64~mm/12.21°，而历史轨迹取值仅为8.93~mm/4.70°。按配对比值计算，外推的平移与旋转轨迹残差分别为历史轨迹取值的5.46 [4.02, 5.73]倍和2.63 [2.44, 2.78]倍。向当前时刻外推能够缩短响应滞后，但同时放大未观测运动带来的轨迹误差；EgoAnchor采用的历史轨迹取值因此处于更偏向轨迹稳定与保真的工作点。

\subsubsection{对象锚定体验}

\textbf{静止与恢复阶段。}
七项条目中效应最强的两项都出现在这两个阶段。静止条件下，EgoAnchor的评分中位数为5.00 [4.58, 5.67]，高于One-Euro的4.33 [3.92, 4.67]，差异经Holm校正后成立（$W=13.5$，$p_{\mathrm{adj}}<.001$，$r_{\mathrm{rb}}=.90$）。遮挡移除后，EgoAnchor的恢复一致评分为5.00 [4.33, 5.42]，One-Euro为4.17 [3.92, 4.33]，对应七项条目中最大的效应量（$W=6$，$p_{\mathrm{adj}}<.001$，$r_{\mathrm{rb}}=.95$）。

\textbf{持续运动阶段。}
物体处于持续运动时，两种方法的主观差异明显减弱。运动附着评分为5.17 [4.58, 5.33]与5.00 [4.33, 5.08]，姿态一致评分为5.00 [4.67, 5.33]与4.67 [4.67, 5.00]，两项均未检测到Holm校正后的差异（附着：$W=67.5$，$p_{\mathrm{adj}}=.267$，$r_{\mathrm{rb}}=.29$；一致：$W=81$，$p_{\mathrm{adj}}=.162$，$r_{\mathrm{rb}}=.41$）。

\textbf{整体锚定判断。}
不限定阶段的三项整体评价一致偏向EgoAnchor。位置正确评分为5.00 [4.67, 5.75]与4.67 [4.00, 5.00]（$W=16$，$p_{\mathrm{adj}}=.001$，$r_{\mathrm{rb}}=.85$），依赖意愿为5.00 [4.33, 5.33]与4.00 [4.00, 4.33]（$W=16.5$，$p_{\mathrm{adj}}<.001$，$r_{\mathrm{rb}}=.87$）。稳定--响应平衡评分为4.83 [4.58, 5.33]与4.50 [4.25, 4.75]（$W=6$，$p_{\mathrm{adj}}=.003$，$r_{\mathrm{rb}}=.90$），三项均呈现较大的正向效应量（$r_{\mathrm{rb}}=.85$--.90），参与者在空间正确性、依赖意愿与稳定--响应平衡上均更偏向EgoAnchor。

\subsubsection{增强质量与信任}

\textbf{增强质量。}
AQ的两个子量表把方法差异定位在嵌入而非交互。EgoAnchor的嵌入质量评分为5.17 [4.50, 5.47]，One-Euro为4.78 [4.50, 5.03]，差异经Holm校正后成立（$W=32$，$p_{\mathrm{adj}}=.004$，$r_{\mathrm{rb}}=.75$）；该子量表在One-Euro与EgoAnchor条件下的Cronbach's $\alpha$分别为.768和.769，内部一致性相近。交互质量评分则彼此接近：EgoAnchor为5.06 [4.50, 5.33]，One-Euro为4.89 [4.64, 5.14]，未检测到校正后的显著差异（$W=102.5$，$p_{\mathrm{adj}}=.446$，$r_{\mathrm{rb}}=.19$）。

\textbf{用户信任。}
三项信任结局方向一致。TiA可靠性/能力呈现最大的效应量（$W=0$，$p_{\mathrm{adj}}<.001$，$r_{\mathrm{rb}}=1.00$），EgoAnchor为4.58 [4.29, 4.83]，One-Euro为4.17 [3.83, 4.50]；理解/可预测性上，EgoAnchor为4.38 [4.00, 5.00]，One-Euro为4.00 [3.94, 4.25]（$W=32$，$p_{\mathrm{adj}}=.004$，$r_{\mathrm{rb}}=.75$）；两个TiA分量表在One-Euro与EgoAnchor条件下的$\alpha$分别为.792/.751和.565/.769。S-TIAS总体信任上，EgoAnchor为5.67 [5.33, 6.00]，One-Euro为5.33 [4.92, 5.67]（$W=22.5$，$p_{\mathrm{adj}}=.004$，$r_{\mathrm{rb}}=.79$，$\alpha$=.672/.697）。参与者因此不仅把EgoAnchor评为更可靠，也评为行为更易理解和预期，而由独立量表测得的方法级总体信任与之同向。

\textbf{总体选择。}
最终偏好进一步呈现相同方向。24名参与者中，15名（62.5\%）总体偏好EgoAnchor，4名（16.7\%）偏好One-Euro，5名（20.8\%）无明显偏好；在直接信任选择中，18名（75.0\%）选择EgoAnchor，1名（4.2\%）选择One-Euro，另有5名无明显偏好。

\section{讨论}\label{sec:discussion}

\subsection{技术启示}

EgoAnchor的结果表明，将零样本视觉感知用于混合现实对象锚定时，系统问题并不止于提高单帧位姿精度。开放词表检测、视频分割、双目几何和零样本位姿估计能够扩大可感知对象的范围，但其输出仍带有采集时刻、相机坐标系、异步时延和质量波动。要形成可供应用持续绑定虚拟内容的动态对象锚点，运行时还需要恢复观测的时间语义、控制低质量观测进入状态估计，并在低频观测之间定义连续的逐帧输出。

EgoAnchor通过感知后端与锚定运行时的分工处理这一转换。感知后端组织开放视觉模型形成带可靠性评分的对象观测，锚定运行时进一步通过采集时刻对齐、观测准入、时间索引轨迹取值与静止锚定生成世界系对象锚点。实验二显示，这些处理分别影响不同的系统行为：采集时刻对齐减少观察者运动引入的空间错配，VCD评分约束进入轨迹的观测质量，静止锚定显著降低静止期波动，而轨迹输出策略决定响应时延与轨迹残差之间的取舍。这说明视觉感知与混合现实运行时具有互补职责：前者扩展系统能够定位的对象，后者决定这些视觉观测如何转化为可持续使用的对象级空间状态。

实验结果同时表明，动态对象锚定的输出策略需要结合应用任务选择。EgoAnchor在静态配准、遮挡恢复和时延对齐后的轨迹误差上取得更低数值，但其起动响应更长，持续平移时的当前时刻误差也更高。用户研究中，参与者在静止稳定、恢复一致、位置正确、依赖意愿与稳定--响应平衡上更偏向EgoAnchor，而运动附着与姿态一致未检测到方法差异。对于以放置后读取、对象说明和近物交互为主的应用，稳定的对象级空间关系可能更重要；需要持续跟随快速运动的任务则更依赖低时延输出。因此，锚点运行时应根据应用对稳定性与实时响应的需求选择工作点，而不能仅以单一位姿误差概括输出质量。

\subsection{局限与未来工作}

\textbf{对象与三维模型。}
EgoAnchor目前面向具有可用三维模型的刚性物体，其性能仍受目标可观测性与模型质量约束。严重遮挡、极弱纹理、透明或镜面材质以及双目深度失效都会削弱分割、几何恢复和位姿验证；非刚性对象则超出了本文的刚体位姿模型。三维模型同时参与位姿估计与VCD验证，因此尺度、几何形状和对象坐标系中的误差会继续传递到最终锚点。生成式Image-to-3D方法可以降低新对象的模型准备成本，但其几何精度、尺度一致性与对象坐标系稳定性也会成为锚定误差来源。未来可进一步研究面向锚定的三维重建与模型校准，并评估模型不确定性对位姿与锚点质量的影响。

\textbf{跨平台比较与评价参考。}
跨平台6DoF对象锚定尚缺少可直接共享的评价参考。不同商业运行时输出的对象位姿可能采用不同的对象局部坐标系、模型原点和内部空间变换；若没有到统一对象坐标系的标定关系，即使多个系统都输出6DoF位姿，其平移与旋转误差也不能直接比较。将结果投影到二维图像后比较轮廓或关键点可以绕开部分坐标系差异，但会弱化深度方向和平面外旋转误差，并受到视角、遮挡和相机投影的共同影响，因此不足以替代对象级6DoF评价。

本文的受控实验选择Quest Touch Plus作为目标，是因为控制器平台位姿与头显位姿位于同一平台世界坐标系，且目标几何与追踪原点之间可以建立固定对应，从而为视觉锚点提供同步的平台参考。该设置支持对采集时刻对齐、静态配准、动态跟随与转换响应进行统一测量，但平台参考仍不是独立的物理真值，也不能用于推断EgoAnchor相对于其他商业对象追踪系统的绝对优劣。未来可引入外部光学动作捕捉或机器人运动平台，并标定各系统对象局部坐标系到统一参考系的刚体变换，以支持跨平台的直接6DoF比较。

\textbf{部署与评价方法。}
当前实现依赖外部GPU工作站，感知处理与通信产生的时延仍限制快速运动场景中的当前时刻配准质量。进一步降低感知时延、提高有效观测频率以及向头显侧部署，将扩大动态锚定对快速交互的适用范围。另一方面，本文的受控结果也显示，动态对象锚定难以由单一平均位姿误差完整描述：静态配准、动态跟随和转换响应分别刻画目标静止、持续运动以及遮挡与起停转换下的不同系统行为。未来可在统一对象坐标系和外部6DoF参考下进一步完善跨设备、跨对象的评价协议，同时报告静止抖动、配准误差、动态轨迹误差、有效时延、遮挡恢复和起停响应，以提高不同对象锚定系统之间的可比性。


\section{结论}\label{sec:conclusion}

本文提出EgoAnchor，一套面向透视混合现实的零样本动态真实物体锚定系统。系统将面向锚定的零样本感知产生的异步相机系物体观测，经逐观测VCD评分、采集时刻对齐、观测准入、时间索引轨迹取值与静止锚定，转换为应用能够逐渲染帧消费的世界系对象锚点。受控评价表明，EgoAnchor在静态配准、时延对齐后的动态轨迹误差和遮挡恢复上取得更低误差，同时承担更长的起动响应以及持续平移时更高的当前时刻误差；24名参与者的用户研究进一步显示，这些系统行为差异反映在更高的静止稳定、恢复一致、位置正确、依赖意愿与方法级信任评价中。

这项工作说明，开放词表与零样本视觉模型为混合现实扩展可感知对象范围提供了基础，但形成可用的动态对象锚点仍需要运行时显式处理观测的时间语义、可靠性与持续输出行为。EgoAnchor提供了一个将这些视觉观测组织为对象级空间状态的具体系统实例，并为进一步研究更低时延的运行时策略、生成式三维模型接入以及跨平台对象锚定评价提供基础。
