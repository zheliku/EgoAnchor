# 四、VCD不要画成三个完全并列的普通分数

你目前右上角：

> 可视性 V
> 颜色 C
> 深度 D
> VCD评分

视觉上容易让人理解成：

[
R = f(V,C,D)
]

三个普通模态并列。

但你真正的方法结构其实是：

[
R_f =
\underbrace{V_f}*{\text{visibility gating}}
\times
\underbrace{\operatorname{Aggregate}(S_f^C,S_f^D)}*{\text{appearance/geometric consistency}}
]

也就是说 **V 是 gate，而 C/D 是 evidence**。

这在算法概念上是不同层级。

所以图中最好明确表现成：

```text
Rendered Candidate
       +
Same-frame Observation
        ↓
┌─────────────────────────┐
│ Observation Validation  │
│                         │
│ Visibility Gating       │
│        ↓                │
│ Color + Depth Consistency│
│        ↓                │
│ VCD Reliability Score Rf│
└─────────────────────────┘
```

甚至视觉上可以写：

**Visibility-gated Color–Depth Consistency**

而不是三个并排小图后直接“VCD评分”。

这样你的 **VCD** 这个名字一眼就解释清楚了。
