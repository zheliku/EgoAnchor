# EgoAnchor 论文与实验路线

## 论文定位

EgoAnchor 研究如何把开放视觉后端输出的低频、异步、质量不均的相机系 6DoF 位姿，
转换为混合现实应用可持续使用的世界系对象锚点。平台能力和零样本感知只作为系统背景；
论文主线是 observation-to-anchor runtime。

## 主方法

完整 EgoAnchor 固定使用：

1. 基于 `frame_id` 的采集时刻世界对齐；
2. VCD 接纳；
3. 连续白噪声加速度 Kalman 状态估计；
4. 自适应历史目标时刻上的位置 Linear / 旋转 SLERP；
5. StaticLock；
6. 与重获取协同的生命周期管理。

实验二另比较两种关闭 StaticLock 的逐帧输出策略：

- `Smoothed KF Extrapolation`：有限 180 ms 外推，并以 60 ms 真实时间半衰期平滑
  Kalman 校正残差；
- `Hermite Interpolation`：在相同历史目标时间线上使用 Kalman 速度切线做 6DoF Hermite
  插值，不在最新控制点之后外推。

180/60 ms 与 Hermite 的 `1.15 / 0.25 / 3` 目前是 pilot 初值，正式 v4 采集前冻结。
两路策略共享采集时刻对齐、VCD、Kalman、生命周期、重获取、候选序列、渲染时间线和关闭
StaticLock 的配置，只改变输出策略。这个比较不改变完整 EgoAnchor 的主方法定义。

## 实验组织

### 实验一：端到端系统表征

比较 Arrival-Hold、Capture-Hold、One-Euro Anchor 和 EgoAnchor。五项任务覆盖静止头动、
起停 6DoF、持续平移、持续旋转和遮挡恢复。每个场景分别报告世界一致性、静止稳定性、
lag--fidelity、遮挡稳健性和转换代价，不汇总成全局排名。遮挡稳健性以 episode-level
平移误差 P95 为主指标；40 mm 超限次数与最大值仅保留在完整指标和审计输出中。

### 实验二：系统设计归因与时序策略比较

三个单组件消融为：

- EgoAnchor w/o capture-time alignment；
- EgoAnchor w/o VCD；
- EgoAnchor w/o StaticLock。

图 3(d) 和对应表格比较 `Smoothed KF Extrapolation vs. Hermite Interpolation`。
除 lag--residual 外，还报告候选生效边界步长、静止帧间增量、起动响应、停止前向过冲、
反向回动、settling time、旋转误差和遮挡期平移误差 P95。候选生效边界步长按 `source_frame_id`

### 实验三：日常物体上的跨对象感知评价

**完整设计与执行方案固定在 `2026-EgoAnchor/experiment_3_design_zh.md`，改动前必须先读该文件。**
本节只保留摘要。

**2026-07-25 重大变更：实验三改为纯主观评价，不采集任何客观任务数据。**

`2 条件 x 3 物体 = 6 个区块`，被试内；每区块 = 3 项任务 + 7 个条目，共 42 个评分。
研究问题不是"完整系统是否全面占优"，而是实验一揭示的稳定性--响应性--恢复权衡
在用户侧如何被感知。任务只负责让参与者经历三种运行时状态，问卷负责测量是否感知到差异。

条件只有 `One-Euro Anchor` 与完整 `EgoAnchor`，以 A/B 匿名呈现。前者已共享采集时刻对齐、VCD、
自适应历史目标时刻、Linear/SLERP、生命周期和逐渲染帧输出，差异集中在运动模型与 StaticLock，
是强对照。`Arrival-Hold` 只在训练阶段作演示，不进入推断统计；Capture-Hold 与三个组件消融只留
在实验二。两个 runtime 在后台同时消费同一候选流、只显示当前条件。

交叉核心物体为 `blue_mouse`、`stapler` 与 `gamepad`，在尺寸、纹理强度和几何复杂度三个维度上
互补。手柄强制**单手握持单侧手柄**搬移，使另一手保持握持控制器。`earphone` 作为困难样例只由
操作员采集，并兼作训练物体。每个物体正式采集前必须通过 `replay frame` 像素贴合检查；
降级顺序固定为 `gamepad -> earphone`，`blue_mouse` 与 `stapler` 不可替换。

**区块结构：物体最外层，两个条件嵌套在同一物体内。** 物体外层是工程硬约束
（`--object` 只在服务启动时读取、协议无运行时切换动作），使每位参与者只发生 3 次重启，
且同一物体的两个条件由同一次感知会话服务。条件内层是灵敏度选择：全部证据来自主观评分，
同物体相邻 A/B 给出最紧配对。物体顺序按拉丁方（3 序列）在参与者间平衡，条件顺序在参与者内
固定、在参与者间平衡，平衡组 `3 x 2 = 6`。

三项任务**固定顺序**（对应三个不同运行时状态，非同一构念的三次测量）：
**T1 静止观察**（语音提示脚本：正面/左移/右移/靠近）、**T2 拿起放下**（平移 25--30 cm、
旋转 30--45 度、空中停留后放置）、**T3 遮挡恢复**（滑入固定挡板停留校准时长后移回，
继续观察 5--7 s）。三任务合计约 45--60 s，全部结束后统一评分，不在每任务后中断。

**不采集任何客观数据**：无任务时间、无成功率、无行为探针。两类候选探针（读 4 字符码、
射线选中小目标）均已评估否决：One-Euro 的头动泄漏 1.53 度虽为校准字高的 2.18 倍但属整体游移
（视线可跟随，不影响可读性），真正造成读错的单次注视内抖动只有 0.17 个字高，正确率会撞天花板；
小目标选择同样受追踪补偿影响；两者还要额外花版面解释人为任务。T3 的四按钮面板行为任务
也已删除。运行时自参考日志仍完整记录，但只作操纵检验与数据审计。

**遮挡时长必须使锚点停留在 `FrozenUncertain` 而不进入 `Lost`（0.6--0.9 s 起，预实验校准后冻结）。**
`AnchorStateMachine.cs:105-115` 的实际分支：`<=0.45 s` 为 `Coasting`、`0.45--1.0 s` 为
`FrozenUncertain`、`>=1.0 s` 为 `Lost`。**注意：0.6--0.9 s 落在冻结区间，不是滑行区间**；
旧文档称其为"coasting 区间"与 0.45 s 滑行上限自相矛盾，已于 2026-07-25 修正。
2 s（以及旧文档提议的 2.5 s）遮挡会使两条件都进入 `Lost` 并等待同一次服务器 REGISTER
（中位数 750.26 ms），该共享常数会同时抬高两条件的恢复质量、压缩相对差异，使恢复条目主要
反映感知后端重注册而非锚定运行时差异。0.6--0.9 s 长于滑行上限（构成参与者可觉察的真实失效
事件）、短于丢失上限（恢复经候选流正常完成而非服务器重注册），并避开 0.45 s 边界以免计时
抖动把试次随机分到两种状态。生命周期状态分布与两条件的候选到达率/VCD/接纳率一致性是
必须报告的操纵检验。运行时常数不得为实验三修改。

头动幅度、遮挡时长与观察脚本节奏由 6--8 人预实验校准：确认完整系统条件下三项任务条目均不贴
天花板、One-Euro 条件下不贴地板。预实验数据不并入正式数据。

**测量为单一层级：每个条件--物体区块结束后填 7 个条目**，全部以该区块为评价对象，
不要求跨物体或跨条件回忆。三项任务特异条目（Q1 静止稳定、Q2 运动附着、Q3 恢复一致，
七点同意度）＋两项跨现实一致性条目（Q4 合理可信、Q5 同步性，七点强度，两种尺度单独成页）
＋两项应用侧条目（Q6 依赖意愿、Q7 稳定--响应平衡，七点同意度）。措辞避开"稳定""抖动""滤波"
等直接描述操纵的词。**逐项分析，不合并总分，不报 Cronbach's alpha**，正文明确标注为
非标准量表。最终填强制选择偏好 + 2 道开放题（最明显区别、什么最容易破坏信任）。
SSQ 衍生清单只作安全监测。**不使用 SUS**（两条件共享完全相同的界面与交互）。
**不使用 NASA-TLX**（两条件任务动作与认知要求完全相同，工作负荷非目标构念）。
**不以 CRIQ 之名署名 Q4/Q5**：已核查无法确证存在名为 CRIQ 的已验证量表——SelfBlending 归给
Gottsacker et al. ISMAR 2021，但该文标题不含量表名，缩写与分量表分类系 SelfBlending 自身
表述；联网检索该领域无同名已验证量表（唯一同名 `CRIq` 是无关的 Cognitive Reserve Index）。
论文写"改编自既有跨现实交互提问的两个单项"并说明归属链。

统计：主分析先把每条目在三物体上**取均值**（非中位数——三点中位数会大量结平损失效能）
作参与者在该条件下的汇总值，再对 7 个条目分别做 Wilcoxon 符号秩 + Holm 校正，
报中位数/IQR、配对差、匹配秩双列相关与自举 CI。次级分析用 CLMM（序数结局；固定效应 =
条件 + 物体 + 区块顺序，随机效应 = 参与者截距）。条件 x 物体交互只作探索性报告。
只有两个条件，不使用 ART/ART-C。

样本量 N=24 为目标、N=18 为下限（平衡组为 3 个物体序列 x 2 个条件顺序 = 6 组，N 必须是 6 的
倍数），并由预实验估计任务方差后确认。论文报告达成 N 下的最小可检出效应，不报事后功效。
**不得用实验一的片段级中位数推导 n**：那是单操作员的配对系统比较，不能换算为参与者间的任务层
效应，也不足以支撑感知阈值断言。

诚实边界：日常物体上没有同平台参考位姿，实验三不报告绝对配准误差，只报主观感知评价和
无需真值的自参考日志（候选到达率、VCD 分数、接纳率、输出可用率、显示帧间增量、StaticLock
进出、生命周期状态、重获取次数）。日志与评分的关系按区块级探索性关联报告，**不作中介
效应主张**。**实验三也不提供任务表现证据**：它回答用户能否感知并信任实验一量化的系统差异，
不能替代对完成时间或成功率的测量；这一点必须在讨论/局限中明说，两类结局留待后续工作。

## v4 启动条件（实验一/二已满足，实验三沿用）

正式采集前完成一次不启动 recorder 的 Quest 功能 pilot：

- 72/90/120 Hz 下残差半衰期行为一致；
- 实际外推时域不超过配置上限；
- 平移和旋转起停无异常跳变、持续回动或非有限输出；
- Hermite 不在最新控制点之后外推；
- 遮挡恢复、VCD、生命周期与九路日志正常；
- 正式场景矩阵门禁和 EditMode 测试通过。

pilot 冻结参数后不再根据 v4 正式结果调参。

实验三沿用同一原则但门禁项不同：九路矩阵门禁和外推诊断只属于实验一/二；实验三使用 2 runtime
的独立 `variant_matrix_id` 与独立启动门禁，并额外要求预实验完成任务参数校准
（字号、控件尺寸、遮挡时长、超时阈值），且确认遮挡时长落在 coasting 区间。
运行时参数本身不得为实验三修改，否则破坏与实验一/二的可比性。

## 诚实边界

- 控制器 pose 是同一 Quest 平台参考，不是外部光学真值。
- frame alignment 只修正采集/到达时刻错配，不补偿采集后的物体运动。
- 系统需要目标三维模型；“纯视觉”只修饰物体位姿估计链路。
- 单操作员、多 session 的帧不是独立样本，统计单位是 event 或 segment。
- 正式结论只描述当前对象、设备、参数和任务条件。
