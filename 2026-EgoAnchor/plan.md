# EgoAnchor 论文与实验路线

## 论文定位

EgoAnchor 研究如何把开放视觉后端输出的低频、异步、质量不均的相机系 6DoF 位姿，
转换为混合现实应用可持续使用的世界系对象锚点。平台能力和零样本感知只作为系统背景；
论文主线是 observation-to-anchor runtime。

## 主方法

完整 EgoAnchor 固定使用：

1. 基于 `frame_id` 的采集时刻世界对齐；
2. VCD 接纳；
3. 连续白噪声加速度 Kalman 状态估计；
4. 自适应历史目标时刻上的位置 Linear / 旋转 SLERP；
5. StaticLock；
6. 与重获取协同的生命周期管理。

实验二另比较两种关闭 StaticLock 的逐帧输出策略：

- `Smoothed KF Extrapolation`：有限 180 ms 外推，并以 60 ms 真实时间半衰期平滑
  Kalman 校正残差；
- `Hermite Interpolation`：在相同历史目标时间线上使用 Kalman 速度切线做 6DoF Hermite
  插值，不在最新控制点之后外推。

180/60 ms 与 Hermite 的 `1.15 / 0.25 / 3` 目前是 pilot 初值，正式 v4 采集前冻结。
两路策略共享采集时刻对齐、VCD、Kalman、生命周期、重获取、候选序列、渲染时间线和关闭
StaticLock 的配置，只改变输出策略。这个比较不改变完整 EgoAnchor 的主方法定义。

## 实验组织

### 实验一：端到端系统表征

比较 Arrival-Hold、Capture-Hold、One-Euro Anchor 和 EgoAnchor。五项任务覆盖静止头动、
起停 6DoF、持续平移、持续旋转和遮挡恢复。每个场景分别报告世界一致性、静止稳定性、
lag--fidelity、遮挡稳健性和转换代价，不汇总成全局排名。遮挡稳健性以 episode-level
平移误差 P95 为主指标；40 mm 超限次数与最大值仅保留在完整指标和审计输出中。

### 实验二：系统设计归因与时序策略比较

三个单组件消融为：

- EgoAnchor w/o capture-time alignment；
- EgoAnchor w/o VCD；
- EgoAnchor w/o StaticLock。

图 3(d) 和对应表格比较 `Smoothed KF Extrapolation vs. Hermite Interpolation`。
除 lag--residual 外，还报告候选生效边界步长、静止帧间增量、起动响应、停止前向过冲、
反向回动、settling time、旋转误差和遮挡期平移误差 P95。候选生效边界步长按 `source_frame_id`
改变前后相邻 render pose 的差计算，只作为同一时间线上的配对显示护栏，不称为 Kalman
innovation。

Task 2 每轮使用成对 marker：拿起前记录 `transition_started`，完全停止后记录
`transition_stopped`。QC 要求两者严格交替闭合。

v4 正式批次已在同一冻结代码和参数下完整采完 Task 1--5（见"数据与论文交付"）。更早的 v3 数据
来自旧 Kalman 过程协方差和旧矩阵，仅保留为只读工程诊断，不得混入活动批次或按场景拼接。

### 实验三：日常物体上的任务层用户研究

**完整设计与执行方案固定在 `2026-EgoAnchor/experiment_3_design_zh.md`，改动前必须先读该文件。**
本节只保留摘要。

`2 条件 x 3 物体 x 3 任务 x 2 重复 = 36 试次`，被试内。研究问题不是"完整系统是否全面占优"，
而是实验一揭示的稳定性--响应性--恢复权衡如何影响对象附着型 MR 任务。每个 `条件 x 任务` 单元
有 6 次观测。

条件只有 `One-Euro Anchor` 与完整 `EgoAnchor`，以 A/B 匿名呈现。前者已共享采集时刻对齐、VCD、
自适应历史目标时刻、Linear/SLERP、生命周期和逐渲染帧输出，差异集中在运动模型与 StaticLock，
是强对照。`Arrival-Hold` 只在训练阶段作演示，不进入推断统计；Capture-Hold 与三个组件消融只留
在实验二。两个 runtime 在后台同时消费同一候选流、只显示当前条件。

交叉核心物体为 `blue_mouse`、`stapler` 与 `gamepad`，在尺寸、纹理强度和几何复杂度三个维度上
互补。手柄强制**单手握持单侧手柄**搬移，使另一手保持握持控制器。`earphone` 作为困难样例只由
操作员采集。物体是最外层区块，因为 `--object` 只在服务启动时读取、协议无运行时切换动作。
每个物体正式采集前必须通过 `replay frame` 像素贴合检查；降级顺序固定为 `gamepad -> earphone`，
`blue_mouse` 与 `stapler` 不可替换。

三项任务独立且顺序平衡：**T1 静止观察**（语音提示侧向头动；转换事件为提示起点）、
**T2 拿起放下**（平移 25--30 cm、旋转 30--45 度后放下；转换事件为物体停止）、
**T3 遮挡恢复**（滑入固定挡板后移回，以控制器射线选择四按钮面板中的指定按钮；
转换事件为目标重新可见）。主要因变量统一为 **系统相关状态转换后首次成功操作的时间**。

T1/T2 **不使用任何人为探针任务**，参与者动作统一为"在判断虚拟内容已稳定附着、可以放心用于
指示物体上的具体位置时按扳机"，即 **参与者判据 + 客观时间戳**。读 4 字符码与射线选中小目标
两种探针均已评估并否决：One-Euro 的头动泄漏 1.53 度是校准字高的 2.18 倍但属整体游移
（视线可跟随，不影响可读性），真正造成读错的单次注视内抖动只有 0.17 个字高，故读码正确率会
撞天花板；小目标选择同样受追踪补偿影响，且两者都要额外花版面解释人为任务。T3 例外保留行为
任务，因为四按钮面板本身就是真实用例，并以首次尝试成功率与时间并列，使实验三同时保有参与者
判据与纯行为两类客观证据。**方法 x 任务交互是预设的确认性检验**。

**遮挡时长必须落在 coasting 区间（0.6--0.9 s 起，预实验校准后冻结）。**
`AnchorPolicyHost` 的 `coastTimeoutSeconds=0.45`、`lostTimeoutSeconds=1.0`：2 s 遮挡会使两条件
都进入 Lost 并等待同一次服务器 REGISTER（中位数 750.26 ms），该共享常数会使主要因变量主要反映
感知后端重注册而非锚定运行时差异。生命周期状态分布与两条件的候选到达率/VCD/接纳率一致性是
必须报告的操纵检验。运行时常数不得为实验三修改。

头动幅度、控件尺寸、遮挡时长与超时阈值不预设，由 6--8 人预实验校准：T3 首次选择成功率约
90%--95%，且 T1/T2 的判据时间在两条件下均不贴地板（若都在约 0.5 s 内按下则灵敏度不足，
需加大 T1 头动幅度或提高 T2 观察要求）。按钮以位置与形状区分而非仅用颜色。
预实验数据不并入正式数据。

主观测量是**主要构念而非补充**：抖动与漂移的用户侧后果是不再相信虚拟内容真的属于该物体，
该构念无法由任务时间完整表达。用四个信任/归属单项（附着准确性、依靠其指示具体位置的意愿、
遮挡恢复后位置可信度、整体归属感），陈述句 + 7 点同意度，前三项在对应任务区块结束后即时填写；
措辞避开"稳定""抖动"等直接描述操纵的词。**逐项分析，不合并总分，也不对两三
条目的分量表报 Cronbach's alpha**，论文中明确标注为非标准量表。配合 Raw NASA-TLX（未加权，
正文只报总分）与最终强制选择偏好。SSQ 衍生清单只作安全监测。**不使用 SUS**：两条件共享完全
相同的界面与交互。**不使用 CRIQ**：构念面向 VR<->物理的中断式跨现实转换，与 passthrough MR
对象锚定不匹配；且其归属链无法确证——SelfBlending 归给 Gottsacker et al. ISMAR 2021，
但该文标题不含量表名，缩写与分量表分类系 SelfBlending 自身表述。

统计：主要因变量对数变换后按任务分别建 LMM（固定效应 = 条件 + 物体 + 试次顺序；随机效应 =
参与者截距 + 条件斜率，不收敛则退回随机截距），方法 x 任务交互在合并模型中单独报告。
T3 首次尝试成功率用二项 GLMM，错误计数按参与者汇总后用配对 Wilcoxon（每单元仅 6 试次，
负二项 GLMM 在此规模不稳定且不进正文）；四个单项用 Wilcoxon 符号秩 + Holm。
一律报效应量与 95% CI。只有两个条件，不使用 ART/ART-C。超时是删失数据：不进入时间模型、
单独报超时率、做插补敏感性分析。

样本量 N=24 为目标、N=18 为下限（平衡组为 3 个物体序列 x 2 个条件顺序 = 6 组，N 必须是 6 的
倍数），并由预实验估计任务方差后确认。论文报告达成 N 下的最小可检出效应，不报事后功效。
**不得用实验一的片段级中位数推导 n**：那是单操作员的配对系统比较，不能换算为参与者间的任务层
效应，也不足以支撑感知阈值断言。

诚实边界：日常物体上没有同平台参考位姿，实验三不报告绝对配准误差，只报任务表现、主观评价和
无需真值的自参考日志（候选到达率、VCD 分数、接纳率、输出可用率、显示帧间增量、StaticLock
进出、生命周期状态、重获取次数）。日志与任务表现的关系按试次级探索性关联报告，**不作中介
效应主张**。

## v4 启动条件（实验一/二已满足，实验三沿用）

正式采集前完成一次不启动 recorder 的 Quest 功能 pilot：

- 72/90/120 Hz 下残差半衰期行为一致；
- 实际外推时域不超过配置上限；
- 平移和旋转起停无异常跳变、持续回动或非有限输出；
- Hermite 不在最新控制点之后外推；
- 遮挡恢复、VCD、生命周期与九路日志正常；
- 正式场景矩阵门禁和 EditMode 测试通过。

pilot 冻结参数后不再根据 v4 正式结果调参。

实验三沿用同一原则但门禁项不同：九路矩阵门禁和外推诊断只属于实验一/二；实验三使用 2 runtime
的独立 `variant_matrix_id` 与独立启动门禁，并额外要求预实验完成任务参数校准
（字号、控件尺寸、遮挡时长、超时阈值），且确认遮挡时长落在 coasting 区间。
运行时参数本身不得为实验三修改，否则破坏与实验一/二的可比性。

## 诚实边界

- 控制器 pose 是同一 Quest 平台参考，不是外部光学真值。
- frame alignment 只修正采集/到达时刻错配，不补偿采集后的物体运动。
- 系统需要目标三维模型；“纯视觉”只修饰物体位姿估计链路。
- 单操作员、多 session 的帧不是独立样本，统计单位是 event 或 segment。
- 正式结论只描述当前对象、设备、参数和任务条件。
