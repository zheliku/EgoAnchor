# EgoAnchor 论文框架重构总结

**日期**: 2026-06-24  
**状态**: 已完成主要框架重构

---

## 重构动机

原定位存在的问题：
1. **"pose-to-anchor 问题"作为主线偏浅** — 这更像是问题刻画，而非足够深的技术贡献
2. **"frame-aligned 创新单薄"** — 单一机制难以撑起整篇论文的核心贡献
3. **实际价值与叙事错配** — 系统的真正价值在于"首个五维能力空白的完整端到端系统"

---

## 核心调整

### 从"问题论文" → "系统论文"

**原定位**:
- 提出 "pose-to-anchor" 问题
- 核心机制：frame-aligned anchoring
- 贡献点：问题刻画 + 单一机制

**新定位**:
- **首个同时满足五维能力空白的端到端系统**
- 核心贡献：四层协同架构
- 论文类型：System Paper（类似 ORB-SLAM 的写法）

---

## 新的核心主张

> **EgoAnchor：首个同时满足 [免主动深度 + 任意物体 + 允许运动 + 低成本模型 + 开放硬件] 的端到端 MR 真实物体锚定系统**

## 五维能力空白（最强卖点）

| 方案 | 免主动深度 | 任意物体 | 允许运动 | 低成本模型 | 开放硬件 |
|------|-----------|---------|---------|-----------|---------|
| Azure Object Anchors | ✗ | ✓ | ✓ | ✗ | ✗ |
| Vision Pro Object Tracking | ✗ | ✓ | ✓ | ✗ | ✗ |
| Vuforia Model Targets | ✓ | ✓ | ✗ | ✓ | ✗ |
| Meta Dynamic Object Tracker | ✓ | ✗ | ✓ | — | ✗ |
| **EgoAnchor (本文)** | **✓** | **✓** | **✓** | **✓** | **✓** |

**关键点**：
- Azure Object Anchors 已于 2023 年底停服
- Vision Pro 需要 LiDAR、数小时训练、封闭生态
- Vuforia 明确定位为静态物体
- Meta 仅支持极少数预定义类（如键盘）

## 四层协同架构（核心技术贡献）

不再只强调 frame-aligned，而是完整的分层系统设计：

### 第一层：时间对齐 — 帧对齐锚定
- 按 `frame_id` 回查采集时刻的头显位姿
- 与时间扭曲（ATW）的对偶关系：ATW 对齐到"当前"，frame-aligned 对齐回"采集时刻"
- 精确消除而非预测

### 第二层：质量门控 — 可靠性评分过滤
- 多维可靠性评分（颜色重投影 + 渲染深度有效性）
- 几何对数平均门控，拦截异常观测

### 第三层：时序平滑 — 卡尔曼状态估计与静止锁定
- 恒速卡尔曼：对世界坐标位置、速度、旋转的自适应估计
- 静止锁定：完全抑制微抖（三路解锁：速度逃逸/漂移绳索/CUSUM）
- 接缝消除：平滑过渡回正常滤波

### 第四层：生命周期 — 保持与重获取
- 状态机：Searching → Tracking → Coasting → Lost
- 遮挡时保持卡尔曼预测，长时失效触发重获取
- NATS 命令面实现闭环自愈

**关键点**：每层专注解决一个明确的子问题，层间通过清晰接口解耦

## 重新排序的贡献点

1. **首个填补五维能力空白的完整系统** ← 最强卖点，引言开头就要亮出
2. **针对异步 MR 感知的四层协同架构** ← 系统架构的核心贡献
3. **以锚点为中心的评估方法** ← 从 pose accuracy 转向 anchor quality
4. **开源实现与可复现** ← 消费级硬件、完整代码

## 研究问题重新表述

**原表述（过于强调"问题"）**:
- RQ1: 帧对齐是否降低打滑？
- RQ2: 门控运行时的消融收益？
- ...

**新表述（强调"系统性能"）**:
- **RQ1（系统整体性能）**: EgoAnchor 能否在消费级硬件上将异步外部感知流转化为世界一致、稳定可用的锚点？
- **RQ2（四层架构贡献）**: 四层协同架构在消除打滑、抑制抖动、降低延迟上的消融收益如何？
- **RQ3（鲁棒性与恢复）**: 系统在干扰条件下的恢复成功率与恢复时间如何？
- **RQ4（任务可用性）**: 稳定的锚定能否提升用户任务表现与主观信任？

## 评估设计调整

### 两层次对比

**系统级对齐基线**（回答 RQ1）:
1. Arrival-Time Mapping（无帧对齐）
2. Frame-Aligned Raw（仅帧对齐，无门控/时序处理）
3. EgoAnchor (Default)（完整四层架构）

**模块化消融**（回答 RQ2）:
1. 时序滤波器对比：Low-Pass / One Euro / Kalman（须画 Pareto 前沿）
2. 静止锁定消融：启用/禁用
3. 质量门控消融：有/无可靠性门控

### 测量指标

**主指标（锚点质量）**:
- 世界锚定误差（平移 RMSE、旋转测地 RMSE）
- 静态抖动（标准差，毫米级）
- 头动打滑（打滑随头速曲线）

**辅助指标（系统性能）**:
- 端到端时延（互相关时滞，P50/P90）
- 恢复时间（随阈值变化的曲线）
- 恢复成功率

**支持性指标（感知质量）**:
- 相机坐标系位姿误差（ADD/ADD-S）— 不作为主线

## 与审稿人的对话策略

### 预期质疑 1
> "frame-aligned 不就是 late latching 的应用吗？novelty 在哪？"

**回应**:
- 我们**不 claim frame-aligned 是全新算法**
- 我们 claim 的是**首个同时满足五维能力的完整系统**
- Frame-aligned 是四层架构中的一层，价值在于协同

### 预期质疑 2
> "你的贡献是系统集成，还是有算法创新？"

**回应**:
- 这是一篇 **System Paper**
- 类比 **ORB-SLAM**：每个模块都不新，但整套系统的组合、实时性能、开源实现构成了重要贡献
- 我们证明"在消费级硬件上，用纯双目+无训练，可以达到与平台级方案相当的锚定质量"

### 预期质疑 3
> "为什么不和 Vision Pro 做定量对比？"

**回应**:
- Vision Pro 依赖 LiDAR、封闭生态、不同的 API 语义
- 只能做**定性对照**，不在对齐噪声内作亚厘米级断言
- 重点是证明**开放系统可以达到实用级别的锚定质量**

## 核心要点总结

**旧定位的问题**:
- 过于强调"问题"（pose-to-anchor）
- Frame-aligned 作为单一机制太单薄
- 系统价值被叙事弱化

**新定位的优势**:
- **五维能力空白**是最强的差异化卖点
- **四层协同架构**是完整的系统贡献
- **System Paper** 定位更实、更强、更可辩护

**关键防御策略**:
- 不争算法新颖性，争系统完整性
- 类比 ORB-SLAM 的贡献模式
- 强调"开放系统可以达到平台级质量"

---

**结论**: 新框架将论文从"提出一个问题"转向"提供一套完整的系统解决方案"，更符合系统论文的评审标准，也更能凸显 EgoAnchor 的实际价值。
