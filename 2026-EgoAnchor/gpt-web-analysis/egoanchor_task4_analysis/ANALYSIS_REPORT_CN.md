# EgoAnchor Task 4 分析

本次正式实验为 `continuous_rotation`。前 14.4 秒是准备/静止阶段，
之后的 3 个事件标记区间构成 3 段连续旋转，统计单位是旋转段而非渲染帧。

## 核心结论

- EgoAnchor 相比 One-Euro 的中位旋转误差由
  **14.2°**
  降至 **13.2°**，
  在 **3/3 段**中改善。
- 旋转 P95 由
  **22.8°**
  降至 **22.3°**，
  但只有 **2/3 段**改善，因此尾部精度不应过度宣称。
- 有效旋转滞后由
  **380 ms**
  降至 **340 ms**，
  3/3 段改善。
- 滞后补偿后的旋转残差由
  **2.61°**
  降至 **2.48°**，
  3/3 段改善。
- 时序合成将角跳变 P99 从 **8.02°**
  压至 **2.34°**，降低
  **71%**；代价是约
  **75 ms** 额外有效滞后，
  以及 **2.6°** 更高的原始中位误差。
- 采集时刻对齐将中位旋转误差从
  **17.7°** 降至
  **13.2°**，并减少约
  **145 ms**
  有效滞后。

## 论文叙事

Arrival-Hold 与 Capture-Hold 的原始瞬时误差更低，但它们只有约
7.5 Hz 的离散更新，
角跳变尾部也明显更大。EgoAnchor 的优势应表述为更优的
“旋转滞后—空间残差—连续性”工作点，而不是声称每个原始误差指标都最低。

由于本任务仅有 3 个正式旋转区间，结论属于配对描述性证据，不能宣称总体统计显著。
