# EgoAnchor Task 3 分析

本次连续平移正式实验包含 18 个标记和 17 段配对轨迹，统计单位是轨迹段而非渲染帧。

- EgoAnchor 相比 One-Euro 的中位误差由 **98.8 mm** 降至 **84.9 mm**，P95 由 **139.5 mm** 降至 **111.5 mm**，均在 **17/17 段**改善。
- 有效轨迹滞后由 **380 ms** 降至 **320 ms**。
- 时移补偿后的残差由 **8.1 mm** 降至 **4.5 mm**。
- 时序合成将跳变 P99 降低 **78%**，但增加约 **65 ms** 有效滞后和 **19.0 mm** 原始中位误差。
- Arrival-Hold 原始误差最低源于错误时间语义造成的隐式时间扭曲，不能解释成空间追踪更准确。
