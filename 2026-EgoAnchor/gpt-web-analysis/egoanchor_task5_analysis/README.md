# EgoAnchor Task 5 analysis package

- `figures/`: IEEE-style vector PDF and 300-dpi PNG figures.
- `tables/task5_system_summary.csv`: four main system configurations.
- `tables/task5_event_metrics.csv`: event-level metrics for all eight variants.
- `tables/task5_vcd_ablation_summary.csv`: VCD component attribution.
- `tables/task5_vcd_risk_coverage.csv`: score-induced risk-coverage curve.
- `tables/task5_candidate_diagnostics.csv`: raw candidate error and decisions.
- `generated/`: LaTeX macros, tables, and paper-ready results.
- `egoanchor_task5_analysis.xlsx`: formatted workbook with dashboard.
