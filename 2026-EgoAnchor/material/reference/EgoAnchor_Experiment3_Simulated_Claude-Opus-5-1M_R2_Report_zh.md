## 1. 本轮要回答的问题

Round 1 的共识数据集已被判定为「**共识中心估计的一次实现**」而非「共识总体的一次随机抽样」：
校准把实得 δ̄ 推到目标上、同时吸收了那组固定抽取的衰减，换 24 个新种子重抽后 13 条目平均
δ̄ 由 +0.510 降到 +0.337（z=+2.33）。它给出的是**乐观边界**。

本轮针对该偏置做四处改动：

1. **人物层改为逐人手写**。24 名虚拟参与者的背景、评分风格、逐通道感知灵敏度、信任与怀疑倾向、
   作答速度，以及两道开放题原文与访谈备注，全部由手写设定（`sim_r2_personas.py`）；
   数值生成器只负责把人物参数映射成 108 个评分，不改写任何主观内容。
2. **不做事后校准**。潜在 δ 按实验一/二 v4 实测通道差异一次设定后不再按实得效应回调，
   只取单次抽样结果。因此本轮结论是「一次真实抽样」而非「中心估计的一次实现」。
3. **追加 400 次换种子重抽**。人物参数与潜在效应完全固定，只重抽人内随机成分与区块噪声，
   报告每个结局的 dz 分布与 Holm 后显著占比。**规划正式采集应看显著占比，而不是主种子的单次 p 值。**
4. **工作簿小分全部改为公式实时计算**，Python 只写原始评分（详见第 12 节）。

## 2. 模拟协议

### 2.1 效应量锚定：δ 由实测通道差异推出，允许零效应与负效应

| 条目 | δ（七点潜在刻度） | 实测依据（One-Euro → EgoAnchor） |
| --- | --- | --- |
| Q1 静止稳定 | **+1.06** | 头动泄漏 P95 10.65→0.82 mm（13.0×）；静止帧间增量 0.85→0.06 mm（13.2×）——最强通道 |
| Q3 恢复一致 | **+0.98** | 遮挡平移 P95 10.41→4.85 mm（2.1×）；灾难性失效 >40 mm 1→0 次 |
| Q8 位置正确 | **+0.90** | 绝对配准 P95 14.00→6.60 mm（2.1×） |
| Q6 依赖意愿 | +0.74 | 应用侧结局；灾难性失效 1→0 是依赖意愿的直接依据 |
| Q7 稳定–响应平衡 | +0.70 | 稳定性收益与时延代价的整体权衡 |
| AQ-IQ3 运动平滑 | +0.58 | 显示帧间增量与转换平滑性 |
| AQ-EQ1 融合 / AQ-EQ2 嵌入可信 | +0.44 / +0.40 | 综合配准质量 |
| Q9 姿态一致 | +0.42 | 静止旋转泄漏 3.29→0.33°（10.1×）**但**旋转对齐 RMSE 5.55→4.81°（仅 1.15×），两通道悬殊 |
| AQ-IQ1 交互直观 | +0.22 | 综合；受共享 UI 主导 |
| **Q2 运动附着** | **+0.14** | 平移对齐 RMSE 15.69→9.12 mm **对** Start-transition 334→510 ms（反向）——设计声明的零效应 |
| AQ-EQ3 尺度协调 | +0.05 | 尺度不随方法变化，预期天花板；保留以维持完整子量表 |
| **AQ-IQ2 响应及时** | **−0.16** | 有效时延 380→360 ms 正向，但 Start-transition 反向且更显著——预期轻微负效应 |

方法级：TiA-R/C 六项 +0.26…+0.48（**「正确判断状况」RC1 与「承担复杂任务」RC4 最弱**，
二者对低层锚定语义偏抽象，正是计划书列为认知访谈最高优先项的两条）；
TiA-U/P 四项 +0.22…+0.40；S-TIAS 三项 +0.56…+0.62（七点量程，量级最大）。

**个体化**：实得效应 = δ × 个体总体灵敏度 × 个体该通道灵敏度 × 物体增益 × 对比锐化。
因此同一条目在不同被试上差异很大——新手 P006（灵敏度 0.30）几乎察觉不到差异，
AR 外包经验的 P003（1.45）逐通道都能分辨。

### 2.2 方差成分：与 δ 同等重要

Round 1 的教训是：合成主观数据若缺少方法级共享印象、区块内分量表共享因子或人×条目随机斜率，
会分别产出 r_rb≈1、α 被压到 0.2–0.4、以及配对符号完全由恒正 δ 决定的假象。本轮四者全部显式建模：

| 成分 | SD | 作用 |
| --- | --- | --- |
| 参与者总体宽严 | 0.62 | 跨全部条目共享（叠加人格的默从倾向 acq） |
| 人 × 条目随机斜率 | 0.54 | 同一人对不同条目宽严不同——缺它则配对符号被恒正 δ 独占 |
| **方法级共享印象** | 0.34 | 同一人对同一方法的全局好感——缺它则 r_rb→1.00 |
| 区块级共享因子 | 0.38 | 同一区块 13 条目共享 |
| 子量表共享因子 | 0.24 | 仅作用于 AQ-EQ / AQ-IQ 两个完整子量表（自制单项按计划书不合并总分，故不共享） |
| 区块 × 条目噪声 | 0.44 | 另按人格怀疑度放大（越怀疑判断越不稳定） |
| 个体敏感度离散 | 0.34 | 乘性作用于 δ，产生真实的个体差异异质性 |
| 反向项额外噪声 | 0.30 | 反映反向项的理解成本，也解释其载荷通常更低 |
| 方法级条目噪声 | 0.62 | **按心理计量标定**：目标使 TiA 分量表 α 落在 0.78–0.88 |

疲劳按区块位置线性衰减（−0.055/区块，再乘人格的作答速度与怀疑度）；
同物体内后评方法有 +0.13 的对比锐化。

> **本轮修正的一处生成器伪影**：初版实现只放大 EgoAnchor 的对比锐化，等于把对比效应写成方法效应，
> 凭生成器制造出先行方法差异。现改为**对称**——同物体内后评的一方被放大，无论它是较好还是较差的一方。

### 2.3 人物 → 平衡单元的分层随机化（本轮必须新增的一步）

手写人物是按「专家/新手」交替的叙事节奏排列的，而采集表的平衡单元按参与者序号交替先行方法
（P001 EA 先、P002 OE 先、…）。**直接顺序对应会使感知灵敏度与先行方法共线**：实测手写人物在
EA 先行位的灵敏度均值 1.058、OE 先行位 0.842（相差 26%），足以凭空造出「先行方法效应」。

真实研究里招募顺序与平衡单元无关，因此这里做同样的解耦：在固定种子下枚举 20000 次随机指派，
按四个顺序因子（先行方法、标签映射、标签序列、首个物体）上的灵敏度组均值最大极差打分，取最优。

> **中途踩过的坑**：先按灵敏度降序切成 6 个四人组再逐组配物体排列，会把最高灵敏度的四人全部送进
> 同一个物体排列，等于把先行方法上的共线换成首个物体上的共线（实测 p=0.0056）。四个因子必须同时平衡。

重排后的**角色特征平衡检验**（Mann–Whitney，全部通过）：

| 特征 | 先行方法 EA / OE | p | 标签映射 A=EA / A=OE | p |
| --- | --- | --- | --- | --- |
| 感知灵敏度 sens | 0.963 / 0.937 | .686 | 0.954 / 0.946 | .954 |
| 默从倾向 acq | 0.071 / 0.075 | .908 | 0.100 / 0.046 | .401 |
| 信任倾向 trust | 0.100 / 0.113 | .839 | 0.121 / 0.092 | .685 |
| 量尺使用幅度 ext | 1.012 / 1.033 | .862 | 1.000 / 1.046 | .602 |

平衡单元定义（物体顺序、区块内标签顺序、标签到方法的映射）完全沿用官方采集表的冻结结构，
只改「哪位参与者拿到哪个单元」。

### 2.4 24 名虚拟参与者

年龄 20–45（中位 28），性别 女 9 / 男 13 / 非二元或其他 2，主手 右 20 / 左 2 / 双手均可 2，
视力 正常 16 / 矫正后正常 8。VR/MR 经验覆盖全谱（从未 2 / 1–5 次 6 / 6–20 次 8 / 超过 20 次 4 /
经常使用 4），实物 AR/MR 经验「从未」6 人。感知灵敏度设定跨度 0.30–1.45。

几位对设计有直接诊断价值的角色：

| 参与者 | 角色 | 对设计的意义 |
| --- | --- | --- |
| **P014** | 医学影像技师，职业习惯是「对位」 | 自发说出 Q1/Q8 正交性：「它看着很稳，但稳在错的地方——稳定的错误比抖动更容易骗人」。**这正是 Q1 与 Q8 必须分列的理由** |
| **P004** | 设计专业，左手主导，最在意「跟不跟手」（延迟通道灵敏度 1.35，偏好偏移 −0.15） | **本轮唯一最终选择 One-Euro 的人**（偏好强度 5、信任也选 One-Euro）：「我一动它半天不动，那种慢半拍最让我出戏」 |
| **P016** | 制造业 AR 巡检使用者，延迟通道灵敏度 1.40、偏好偏移 −0.15 | 人物设定同样偏向响应，**但最终仍选了 EgoAnchor（强度 6）**——见下方「人物意图与实得结果的分歧」 |
| **P018** | CV 方向博士生 | 自发表述 TiA-U/P 可预测性构念：「我猜不到下一秒是哪种，这比一直偏一点更让我不敢用」 |
| **P023** | AR 内容开发者，对稳定与延迟同时高度敏感 | 人物设定为「权衡型无偏好 + 高区分信心」，**实得却是偏好强度 7（全样本最高）**——同样属意图与结果的分歧 |
| **P011** | VR 内容开发者 | **自发推断机制**（「做了平滑和某种静止就钉住的处理」）——按协议如实记录为标签泄漏风险信号，未向其确认 |
| **P006 / P010 / P019** | 头显新手，灵敏度 0.30 / 0.45 / 0.50 | 天花板 + 低区分度个体；**P010 区分信心 3 为全样本最低**，P006 与 P010 最终「无明显偏好」，P019 作答最慢 |

> **人物意图与实得结果的分歧（须如实记录）**：手写人物层只设定分布中心，
> 个体最终落点由抽样与判断模型共同决定。本轮有两处分歧值得记入设计教训：
>
> - **P016 与 P023 的人物设定预期是「偏好 One-Euro」与「权衡型无偏好」，实得却都选了 EgoAnchor。**
>   原因在偏好判断的加权：稳定类条目（Q1 2.0 / Q8 1.7 / Q3 1.6 / Q7 1.5）合计权重远高于
>   响应类（AQ-IQ2 0.5），因此只要该被试在稳定通道上确实看到差异，
>   −0.15 的价值取向偏移就不足以翻转符号。**P004 之所以翻转，是因为其总体灵敏度只有 0.55**，
>   稳定通道的实得差异被压缩到与偏好偏移同量级。
> - 这意味着**本模型下「价值取向」很难压过「知觉显著性」**。真实参与者里偏好响应者的比例
>   可能高于本轮的 1/24；若正式数据出现较多 One-Euro 选择者，不应视为异常，
>   而应结合 Q7 与 AQ-IQ2 的逐项结果解释。
>
> 报告一律按**实得结果**陈述，不按人物设定的预期陈述。

### 2.5 预设技术事件与缺失

5 个技术事件（P003 遮挡后服务器重注册、P007 掩膜短暂丢失、P011 放置超区后重放、
P016 头显下滑、P020 挡板移回略慢 0.86 s）按计划书第五节**全部不导致区块作废**——

**三项恰好全部落在 RC1 与 RC4** 上，与计划书标注这两条最抽象、列为认知访谈最高优先项一致。

### 4.1 逐物体方向一致性（探索性，不作未校正的逐物体检验）

主家族 6/7 在三物体上方向一致。**鼠标上效应最大、订书机上最小**，与设计预期吻合：
鼠标几何约束弱、纹理偏弱，静止抖动与绝对偏移更容易暴露；订书机多平面非对称、位姿条件最好，
两方法绝对水平都最高（One-Euro 在订书机上 Q1=4.71 对鼠标 3.96），差异被压缩。
手柄在**恢复通道**上方法差最大（+1.38），对应单手搬移带来的手部遮挡——
该遮挡在两方法间对称且共享同一候选流，是常量不是混淆。

P022 自发给出了这个物体主效应的用户侧解释：「订书机上两个都很好，鼠标上就分得出来了——
鼠标上有一个总在动。」

四轮的稳定共识：**Q1/Q3/Q8/Q6/Q7 可检出；Q2 为零效应；Q9 检出力不足；AQ-IQ 不适合作单一分数。**
本轮效应量最保守，且给出了检出率分布，**后续规划应以本轮的显著占比为基准。**

## 13. 工作簿的公式实时计算（本轮新增）

按要求，**统计表中的问卷小分全部由公式实时计算**。数据流是单向的：

```text
Records（唯一输入，只放原始评分，含 TiA 反向项的原始分）
  → Derived D1  区块 AQ-EQ / AQ-IQ 3 项均值 + §8 两条门禁实时判定
  → Derived D2  TiA 四个反向项按 6−原始分换向 → 三个分量表均值（缺失项自动跳过）
  → Derived D3  每人每方法在三物体上取均值（计划书 6.2；48 行）
  → Derived D4  每人配对差（EgoAnchor − One-Euro）+ 配对一致性自检
  → Analysis    Mdn[IQR]、配对差中位/均值/SD、dz、逐物体均值、TOST 两侧均值、各项计数
```

- **绿底 = 公式**（3640 个），**黄底 = Python 写入数值**——只有 Wilcoxon 的 W、p、Holm 校正 p、
  r_rb 自举 CI 与信度 α/ω 是数值，这些统计量无法用普通单元格函数表达，同行已注明来源。
- 改动 `Records` 里任一原始评分，Derived 与 Analysis 的全部小分、均值、配对差、dz、
  逐物体描述、TOST 两侧均值与最终计数都会立即重算。已实测验证：
  把 P001 三个 EgoAnchor 区块的 Q1 改动后，D3 条目均值 → D4 配对差 → Analysis 的 dz 逐层跟随变化。
- **原始评分不被反向分覆盖**（计划书 9.1 约定）：反向计分只在 Derived D2 派生。
- `Derived!N254:N277` 是配对一致性自检列，全部为 `OK`。

### 13.1 公式正确性的双路交叉验证

`sim_r2_formula_eval.py` 实现了一个**受限求值器**（只支持工作簿实际用到的 13 个函数，
遇到未支持语法立即抛异常，绝不静默跳过），构成两条互不引用的路径：

- 路径 A：公式文本 → 求值器 → 写回 xlsx 的缓存值
- 路径 B：`Records` 原始评分 → `sim_r2_recalc_verify.py` 手写重算 → 与缓存值逐格比对

**3640 个公式全部通过，容差 1e-9**（3 个空值是预期的 TiA「无法回答」项，
`IF(…="","",…)` 正确产出空）。公式若引用错列或错行，两条路径必然不一致。

同时在 `workbook.xml` 写入 `fullCalcOnLoad="1"`：**Excel 打开时必定全量重算**，
因此即使注入值有误也会被 Excel 立刻覆盖并暴露差异，不会固化错误数字——公式始终是真值来源。

> **未能完成的一项交叉验证**：原计划用本机 Excel 再重算一遍作第三条路径。
> 工作簿位于网络盘 `P:\`，Excel 以受保护视图打开，COM 调用被 `RPC_E_CALL_REJECTED` 持续拒绝
> （复制到本地临时盘可打开，但该路径下的重算未纳入流水线）。因此**缓存值来自本仓库的求值器，
> 不是 Excel 的计算结果**；两者在本工作簿用到的函数子集上语义一致，
> 但这一点只由上述双路比对保证，未经 Excel 独立确认。

### 13.2 §8 门禁在表内实时可见

`Derived!H` 列判定「时长 >150 s」，`Derived!I` 列用 9 个滑动窗口展开判定「≥5 项连续同分」
（按问卷**呈现顺序**而非编号顺序）。改动任一评分或时长，两条门禁判定立即重算——
正式采集时可直接在表内观察 Q10 启用判据与 AQ 缩减规则是否触发。

## 15. 合成数据边界（再次声明）

1. 本轮全部数据由语言模型生成，**只用于采集表与分析流程演练**；
   不得进入论文结果、效应量、功效或样本量推断，不得与真实参与者数据合并。
2. 人物设定与开放题原文读起来像真实反馈，但它们是模型的构造，
   **不得作为用户研究证据引用**，也不得写成真实参与者的话。
3. 400 次重抽固定人物层、只重抽人内随机成分，反映的是**同一批人重做一次实验**的可复现性，
   **不是换一批参与者的抽样分布**。因此检出率应视为**上界**。
4. 日常物体上没有同平台参考位姿，实验三不报绝对配准误差、也不提供任务表现证据；
   信任测量只覆盖态度与意愿，不含行为依赖终点；自制单项不合并总分、不报内部一致性。
5. **实验三工程侧（Unity 2-runtime 场景、头锁问卷 UI、独立日志/QC/分析模块）尚未实现**，
   本轮不构成「实验三已完成」的任何主张。
