## ✅ 论文中的准确描述

### 摘要
```
系统以 5--12 fps 感知输入，通过升采样机制升至 60 fps
```
（保持简洁，不详述具体方法）

### 第三层详细说明
```
系统支持两种升采样策略：
(i) 延迟插值主动牺牲 1-2 个观测周期的延迟，
    在已到达的控制点之间进行样条插值，
    保证无 overshoot 与轨迹平滑；
(ii) 误差融合零延迟外推到当前时刻，
     新观测到达时计算残差并在后续帧指数衰减，
     实现平滑收敛。
两种策略依赖运动模型提供控制点与预测接口，
在精度优先与响应优先间提供灵活选择。
```

## 🎯 两种策略对比（快速参考）

| 维度 | DelayedInterp | Blend |
|------|--------------|-------|
| **延迟** | +100-200 ms | 0 ms |
| **方法** | 样条插值 | 外推+残差融合 |
| **Overshoot** | 无 | 有限制 |
| **稳定性** | 极高 | 依赖模型 |
| **适用** | 精度优先 | 响应优先 |
