## 核心修改总结

### **一、贡献定位重构（最关键）**

#### **修改前（v1）**

```
贡献1: 端到端对象锚定系统
贡献2: 观测到锚点运行时
贡献3: 系统表征与分层评估
```

**问题**: 贡献层级不清晰，"端到端系统"过于宽泛

#### **修改后（v2）**

```
贡献1: 零样本动态物体锚定系统（主贡献明确）
贡献2: VCD位姿验证与运动状态感知锚定运行时（关键技术）
贡献3: 系统实现与分层评价（支撑证据）
```

**改进**: 建立清晰的三层层级：主贡献 > 关键技术 > 实证支撑

### **二、Abstract重写（核心叙事）**

#### **关键修改点**

**1. 开头强化应用价值**

```
【v1】透视混合现实应用需要将虚拟内容稳定地附着到动态真实物体上...
【v2】动态真实物体锚定使虚拟内容能够随日常物体的拿取、移动和遮挡持续保持空间附着...
```

✅ 更直接、更具体

**2. 现有方案对比清晰**

```
【v1】现有视觉方法输出图像采集时刻的相机系六自由度位姿...
【v2】现有方案通常依赖物理标记、专用追踪设备或受限的平台对象集合。
      零样本6DoF位姿估计扩大了可被视觉定位的物体范围，但其输出是异步、低频且质量波动...
```

✅ 明确三类局限：标记/专用设备/平台限制

**3. 系统描述层次清晰**

```
【v1】通过感知后端与锚定运行时的分层架构...锚定运行时采用帧标识恢复采集时刻世界变换，
      以可视度门控的颜色--深度一致性评分限制有害更新，并通过卡尔曼状态估计...
【v2】给定目标物体的三维模型，EgoAnchor无需物理标记或逐物体训练，通过开放词表初始化、
      时序分割、双目深度估计和模型驱动的6DoF位姿估计构建对象感知后端。系统进一步采用
      基于可视度、颜色和深度一致性的VCD机制验证位姿观测，并通过采集时刻世界配准、
      运动状态感知的时序合成、静止锚定和生命周期管理...
```

✅ 删除技术细节（卡尔曼等），强调系统特性（无标记、零样本）

**4. 结果表述精确化**

```
【v1】（未明确数值）
【v2】结果表明，采集时刻对齐将头动相关误差降低2.69倍，静止锚定将中心化静止误差降低17.06倍...
```

✅ 使用相对改善（2.69×、17.06×）而非绝对精度

### **四、系统章节叙事优化**

#### **§3.1 系统概览**

**修改前**:

```
EgoAnchor面向四个系统目标设计：【可扩展性】...【世界一致性】...【持续输出】...【鲁棒生命周期】...

为此，EgoAnchor将动态真实物体锚定解耦为感知与锚定两层架构。
```

**修改后**:

```
EgoAnchor将动态物体锚定解耦为对象感知与对象锚定两层架构。感知层从头显双目图像与
目标物体的可用三维模型中，持续生成相机坐标系下的6DoF位姿观测与即时可靠性评分；
锚定层将异步、低频的观测流转化为稳定、世界一致且可恢复的对象锚点。

系统面向四个目标设计：给定物体三维模型即可接入新的刚性目标，无需逐物体训练；
异步观测按照其采集时刻恢复世界坐标语义...
```

**改进**:

- ✅ 架构描述前置
- ✅ 删除加粗标签（可扩展性、世界一致性等）
- ✅ 直接陈述，无防御性语言

#### **§3.2 对象感知**

**新增开头段**:

```
EgoAnchor的感知层从头显双目图像与目标物体的可用三维模型中，持续生成相机坐标系下的
6DoF位姿观测与即时可靠性评分。为支持不受预定义类别限制的刚性物体，系统采用零样本
视觉推理架构。
```

**改进**:

- ✅ 明确感知层的目标
- ✅ 强调"零样本"（支撑系统特性）
- ✅ 强调"给定模型"（诚实边界）

#### **§3.3 对象锚定**

**修改前**:

```
对象锚定的核心任务是建立从相机坐标系异步位姿流到世界坐标系对象锚点的稳定映射。
这一过程需要同时解决一致性（...）、稳定性（...）、连续性（...）和可恢复性（...）四个挑战。
```

**修改后**:

```
锚定运行时将感知层输出的异步、低频位姿观测流转化为应用可持续消费的世界系对象锚点。
核心挑战包括异步观测的时间语义、候选可靠性判别、以及静止与运动期的不同输出策略。
```

**改进**:

- ✅ 删除冗长的括号解释
- ✅ 直接陈述核心挑战
- ✅ 更简洁
