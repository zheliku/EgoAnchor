**问题**:

- 直接进入组件描述
- 没有解释"为什么需要这四个模块"

#### 改进后（学术化重构）

```latex
EgoAnchor的感知层从头显双目图像I_f与目标物体的可用三维模型M中，持续生成相机坐标系下的
6DoF位姿观测T_o^c与即时可靠性评分R_f。该层需要满足两个相互制约的设计目标：\textbf{类别
泛化性}要求系统支持不受预定义标签集限制的刚性物体，而\textbf{米制尺度一致性}要求位姿估计
输出与混合现实世界坐标系保持物理尺度对应。

\subsubsection{零样本感知的设计挑战}

实现上述目标面临三个技术挑战。首先，开放场景中的目标对象无法依赖类别特定的检测器或
位姿回归网络；感知流水线必须在运行时动态关联语义、几何与模型约束。其次，单目图像无法
恢复米制尺度；双目几何虽然提供米制深度，但立体匹配在弱纹理与深度不连续处的噪声会直接
传递至下游位姿估计。最后，连续帧间的目标关联需要在遮挡、光照变化与运动模糊下保持稳定，
而单帧检测器无法提供时序一致性保证。

现有零样本6DoF位姿估计方法~\cite{foundationpose2023}通过模型驱动的几何对齐实现类别泛化，
但其输入假定\emph{已知}目标掩膜与米制深度图；如何在头显双目图像流中持续、稳定地为位姿
估计构造这些前置条件，本身是一个需要系统性设计的感知问题。

\subsubsection{多阶段视觉推理架构}

EgoAnchor通过解耦语义关联、时序传播、几何重建与位姿对齐四个职能，构建零样本感知流水线。
该设计遵循"先语义后几何"的分层策略：开放词表目标检测（YOLO-World~\cite{yoloworld2024}）
建立图像区域与用户指定语义之间的初始关联，生成语义掩膜M_0；半监督视频对象分割
（Cutie~\cite{cutie2024}）从初始掩膜出发，在连续帧间传播前景标识，隔离位姿估计所需的
目标像素集合；双目立体匹配（Fast-FoundationStereo）利用头显标定参数，将视差场转换为
米制深度图D_t；零样本6DoF位姿估计（FoundationPose~\cite{foundationpose2023}）接收
M_t、D_t与目标三维模型M，在初始化阶段执行全局注册，在追踪阶段以历史位姿为运动先验
进行迭代优化。

该架构的关键设计在于\textbf{职能解耦}与\textbf{约束传递}：语义模块不涉及米制尺度，几何
模块不涉及类别识别；位姿估计接收已对齐的语义与几何约束，专注于刚体变换的优化。这一设计
使各模块可独立替换，并利用视觉基础模型的零样本泛化能力，同时通过双目几何保持混合现实
所需的米制尺度一致性。
```

**改进要点**:

1. ✅ 增加"设计挑战"段落：形式化技术难点
2. ✅ 解释"为什么需要四个模块"：职能解耦+约束传递
3. ✅ 避免罗列：用设计原理串联组件
4. ✅ 删除过于细节的数据流描述（M_0→M_t→D_t）

### **§3.2.2 可靠性评分**

#### 改进前（当前v2，第113-123行）

```latex
单帧位姿估计的几何输出无法直接量化其对虚实配准的可用性。感知算法可能在弱纹理、遮挡
或光照变化下输出满足数学形式但物理错误的位姿。EgoAnchor提出VCD（Visibility-gated 
Color-Depth）可靠性评分模型...
```

**问题**:

- 直接给出公式
- 缺少"为什么现有方法不够"的论证

#### 改进后

```latex
\subsubsection{位姿观测的可靠性验证}

零样本位姿估计的几何优化目标（例如ICP或渲染匹配）可能收敛至数学上的局部最优解，但该解
在物理上并不对应真实物体位姿。这种"形式合法但物理错误"的位姿观测若被锚定运行时直接接纳，
将在虚拟内容中表现为可见的跳变或错配。锚定层需要一种\textbf{观测准入机制}，在位姿候选
到达时判别其对虚实配准的可用性。

该机制面临两个设计约束。首先，判别必须基于单次观测的即时证据，而非依赖多帧时序一致性——
因为追踪失败后的首次恢复观测无法获得历史支持。其次，判别标准应与混合现实的渲染目标对齐：
若当前位姿下的虚拟内容渲染结果与实际观测不一致，则该位姿不应被接纳。

EgoAnchor提出VCD（Visibility-gated Color-Depth）可靠性评分模型。该模型将目标三维模型
按当前候选位姿渲染回图像空间，通过比较渲染结果与实际观测的多模态一致性来验证位姿质量。
评分由可视度因子V与几何一致性核G_CD复合：

\begin{equation}
R = V \cdot G_{\mathrm{CD}}
\end{equation}

\textbf{可视度因子}$V = |M_{\mathrm{obs}} \cap M_{\mathrm{rnd}}| / |M_{\mathrm{rnd}}|$衡量
渲染投影掩膜M_rnd在观测掩膜M_obs中的覆盖率。当目标物体被严重遮挡或移出视野时，V接近零，
避免接纳基于不完整观测的位姿。\textbf{几何一致性核}G_CD通过加权对数几何均值融合颜色
投影相似度C与深度几何对齐度D：

\begin{equation}
G_{\mathrm{CD}} = \exp\!\left((w_C \ln \max(C, \epsilon) + w_D \ln \max(D, \epsilon)) / (w_C + w_D)\right)
\end{equation}

该设计的关键在于\textbf{几何均值}而非线性加权：只有当颜色与深度证据\emph{同时}支持当前
位姿时，G_CD才接近1；任一通道的严重不一致会将评分拉向epsilon下限（0.05）。这确保了
评分对多模态不一致的敏感性，使锚定层可通过单一阈值实施观测准入。深度权重w_D=0.8高于
颜色权重w_C=0.2，反映了几何对齐对刚体位姿的主导约束作用。
```

**改进要点**:

1. ✅ 增加"问题形式化"：为什么需要验证？
2. ✅ 设计约束分析：即时判别+渲染一致性
3. ✅ 解释设计选择：为什么几何均值？为什么w_D>w_C？
4. ✅ 删除过于细节的C/D计算公式（移至实现章节）

### **§3.3.3 运动状态感知的静止锚定**

#### 改进前（当前v2，第148-158行）

```latex
运动估计与平滑策略将低频观测转换为连续轨迹，但无法消除静止期的高频抖动。传统滤波器
通过增大平滑系数可抑制抖动，但代价是引入运动滞后。

EgoAnchor通过运动状态感知的静止锚定根据物体运动状态切换输出策略：在静止期冻结输出锚点，
在运动期交回平滑输出。当物体速度与可靠性评分在驻留窗口t_dwell（典型值350ms）内持续
满足锁定条件时...
```

**问题**:

- 直接给出解决方案
- 参数说明过多（t_dwell=350ms）
- 缺少"为什么不用传统方法"的设计空间分析

#### 改进后

```latex
\subsubsection{运动状态感知的静止锚定}

时序平滑策略在静止与运动期间采用统一的输出策略：滤波器或插值器的平滑参数在整个追踪
过程中保持不变。该设计隐含一个固有权衡：增大平滑系数可抑制静止期的高频抖动，但代价是
引入运动期的相位滞后；减小平滑系数可提升运动响应，但静止期的噪声直接传递至输出。
One-Euro滤波器~\cite{oneeuro2012}通过速度自适应调节截止频率，在该权衡空间内动态平衡，
但其输出仍是观测噪声的连续函数——即使物体完全静止，逐帧输出仍会因观测波动而产生微小抖动。

混合现实中虚实配准误差的感知阈值研究表明，静止物体上附着的虚拟内容若产生可见抖动，
用户对系统的信任会显著下降~\cite{azuma1994improving}。这提示了一个关键观察：对于
\emph{真实静止}的物体，理想的对象锚点输出应当\emph{完全冻结}，而非继续跟随观测噪声。
该策略要求运行时\textbf{显式识别物体的运动状态}，并在静止与运动期间切换输出模式。

EgoAnchor采用基于速度与可靠性的\textbf{驻留锁定机制}。当估计速度持续低于静止阈值、
且观测可靠性评分持续高于最低要求时，系统激活静止锁：

\begin{equation}
\lVert \mathbf{v} \rVert_2 \leq v_{\mathrm{th}}, \quad 
\lVert \boldsymbol{\omega} \rVert_2 \leq \omega_{\mathrm{th}}, \quad 
R \geq R_{\mathrm{min}}, \quad 
\forall t \in [t_{\mathrm{now}} - t_{\mathrm{dwell}}, t_{\mathrm{now}}]
\end{equation}

锁定后，输出冻结于锁定原点T_L（由锁定前观测的指数移动平均确定），完全隔离观测噪声。
该设计将静止期的稳定性从"受平滑参数约束的抖动抑制"提升为"完全冻结的零抖动输出"，
代价是引入额外的起停转换延迟。

\textbf{解锁机制}需要在保持稳定性的同时，及时响应物体的运动恢复。EgoAnchor设计四路
独立的解锁判定通道，任一通道触发即立即解锁：\emph{速度逃逸}通过观测速度的持续超阈值
识别拿取与挥动；\emph{漂移阻缰}通过观测共识相对锁定原点的位移累积识别缓慢但持续的运动；
\emph{低分释放}在感知质量持续下降时主动交回控制权；\emph{可靠性加权累积和}通过带遗忘项的
方向累积识别连续同向位移。四路机制共同实现对不同运动模式的覆盖，确保锁定状态不会成为
系统响应的阻塞点。
```

**改进要点**:

1. ✅ 增加"设计空间分析"：传统滤波器的权衡
2. ✅ 引入领域知识：感知阈值研究→设计动机
3. ✅ 删除具体参数值（350ms等）→移至实现章节
4. ✅ 解释四路解锁的"覆盖不同模式"原理，而非罗列
