\abstract{%
动态真实物体锚定是透视混合现实（Passthrough Mixed Reality, PMR）中以真实物体为中心进行空间叠加的关键能力。现有方案通常依赖物理标记、专用传感器、平台级受限接口，或针对单个物体的离线准备流程，难以扩展到开放消费级场景中的日常刚性物体。本文提出 EgoAnchor，一套面向开放消费级混合现实的动态真实物体锚定系统。EgoAnchor 仅依赖头戴显示器双目图像与目标物体的可用三维模型，无需物理标记、专用深度硬件或逐物体离线训练，即可为日常刚性物体提供连续 6DoF 动态锚定能力。系统采用分层架构：视觉感知后端持续生成异步物体位姿流，对象锚定运行时则将其转换为世界坐标系下稳定、连续且可恢复的对象锚点。我们在 Meta Quest 3 上实现 EgoAnchor，并通过定量实验与用户研究评估其锚定精度、稳定性、响应行为和应用可用性。结果表明，EgoAnchor 能够在开放消费级 PMR 场景中稳定支持动态真实物体锚定。
}

\firstsection{引言}\label{sec:introduction}
\maketitle

透视混合现实（Passthrough Mixed Reality, PMR）通过将虚拟内容实时叠加到真实环境，使用户能够直接围绕真实物体进行观察、操作与交互。近年来，随着 Meta Quest 3、Apple Vision Pro 等消费级头戴显示设备的普及，越来越多的混合现实应用开始围绕真实物体展开，例如虚拟说明书附着、物体高亮引导、桌面协同办公以及近物精细交互等。这类应用共同依赖一项基础能力：虚拟内容能够持续、稳定地附着于真实物体，并随物体运动保持一致的空间关系。

对于静态环境，这一目标通常可以通过空间锚点（Spatial Anchor）实现。然而，当用户拿起、移动、旋转或传递真实物体时，固定于环境中的空间锚点无法反映物体自身的运动，虚拟内容将随之产生明显偏移。因此，混合现实系统需要建立能够随真实物体运动持续更新的对象级空间参考，即动态对象锚定（Dynamic Object Anchoring）：无论用户自身运动、物体发生位姿变化，还是经历短暂遮挡，虚拟内容都应始终与真实物体保持稳定一致的六自由度（6DoF）对应关系。

现有系统已经从不同路径尝试支持对象级追踪与锚定。典型方案包括基于物理标签的跟踪、依赖深度或专用传感器的感知方法、平台提供的对象追踪接口，以及基于 CAD 或三维模型的商业对象识别框架。这些方法在受控环境中能够取得较好的效果，但仍难以同时满足开放消费级 PMR 场景的三个要求：第一，系统应具备开放性，能够在无需逐物体训练的前提下扩展到多类日常刚性物体；第二，系统应具备可部署性，能够在不依赖物理标签、专用深度硬件或受限平台接口的条件下运行于消费级头戴设备；第三，系统应提供稳定的动态对象锚定能力，即生成连续、世界一致且可恢复的 6DoF 对象锚点，而不仅仅是输出瞬时物体位姿。

实现这一目标需要同时解决两个问题。首先，系统必须将开放场景中的对象感知组织为可持续输出的异步物体位姿流，而不是一次性的检测或单帧位姿估计。其次，系统必须在设备持续运动、感知噪声、帧率不一致和短时目标丢失等实际运行条件下，将这些异步位姿估计转换为世界坐标系下稳定、连续且可恢复的对象锚点。前者决定系统能否面向开放日常物体进行感知，后者决定感知结果能否被 PMR 应用可靠地用于空间附着。

本文提出 EgoAnchor，一套面向开放消费级混合现实的动态真实物体锚定系统。EgoAnchor 采用对象感知与对象锚定解耦的分层架构，由视觉感知后端（Visual Perception Backend）和对象锚定运行时（Object Anchoring Runtime）组成。视觉感知后端基于头戴显示器双目图像与目标物体的可用三维模型，持续估计物体相对于设备的 6DoF 位姿，并输出异步物体位姿流。对象锚定运行时进一步将这些异步位姿转换到世界坐标系，并通过运行时转换策略生成可供 PMR 应用直接使用的对象锚点。整个系统无需物理标签、专用深度硬件或逐物体离线训练，可与现有三维模型资源以及近年来的 Image-to-3D 技术结合，为更多日常刚性物体提供部署潜力。

我们在 Meta Quest 3 上实现了 EgoAnchor，并通过定量实验和用户研究对系统进行了评估。定量实验利用官方控制器提供的高精度位姿作为参考，测量系统的锚定精度、稳定性与响应行为；用户研究围绕典型混合现实任务展开，评估系统在真实应用中的可用性。实验结果表明，EgoAnchor 能够在开放消费级 PMR 场景中稳定支持动态真实物体锚定。

本文的主要贡献如下：

\begin{enumerate}
  \item \textbf{EgoAnchor：} 一套面向开放消费级混合现实的动态真实物体锚定系统，仅依赖头戴显示器双目图像与目标物体的可用三维模型，即可为多类日常刚性物体提供连续 6DoF 动态锚定能力。
  \item \textbf{分层技术方案：} 一套由视觉感知后端与对象锚定运行时组成的分层技术方案。前者持续生成统一的异步物体位姿流；后者通过运行时转换策略，在设备持续运动、感知噪声和短时目标丢失等条件下，将异步物体位姿流持续转化为世界坐标系下稳定、连续且可恢复的对象锚点。
  \item \textbf{实现与评估：} 在 Meta Quest 3 上完成 EgoAnchor 系统实现，并通过定量实验与用户研究评估其在锚定精度、稳定性、响应行为和典型 PMR 应用任务中的可用性。
\end{enumerate}

\section{相关工作}\label{sec:related-work}


\subsection{平台级真实物体锚定}


真实物体锚定旨在为物理对象建立稳定的对象级空间参考，使虚拟内容能够持续附着于真实物体，是近年来混合现实平台的重要能力。随着消费级头戴显示设备的发展，主流 XR 平台逐步开始提供对象追踪或对象锚定能力，但在开放部署、对象泛化以及动态支持方面仍存在一定局限。

早期系统主要采用基于物理标记的方法，通过 AprilTag、ArUco 等人工标记获得稳定的位姿估计，ARToolKit、ARCore Augmented Images 等系统均属于这一范式。这类方法实现简单、鲁棒性较高，但需要预先在物体表面贴附标记，不仅改变真实物体外观，也难以适用于开放场景中的多类日常刚性物体。

近年来，消费级混合现实平台开始提供免标记对象追踪能力。HoloLens 2 的 Azure Object Anchors 利用设备感知与对象数字模型完成对象匹配，但公开资料显示其能力主要面向较大尺寸的静态对象；Apple Vision Pro 提供对象追踪能力，但依赖基于三维模型构建的参考对象以及离线训练流程；Vuforia Model Targets 基于对象形状以及三维模型实现真实物体识别与跟踪，但因其受约束的初始化与准备流程，常见于工业与设备场景；Meta Quest 近年来也开始支持动态对象追踪，但当前仍属于受系统支持对象集合与用户设置约束的受控能力。

总体而言，现有平台主要提供封装好的对象追踪能力，通常依赖专用硬件、受限的平台接口、模型准备或对象级离线流程，难以直接支持开放场景中的多类日常物体，也较少向开发者开放底层视觉感知结果。因此，开放消费级混合现实中的动态真实物体锚定仍然缺乏统一的系统支持。

\subsection{6DoF 物体位姿估计与跟踪}


6DoF 物体位姿估计旨在从图像中恢复刚性物体相对于相机的空间位姿，是动态真实物体锚定的感知基础。近年来，随着视觉基础模型的发展，相关研究不断降低对逐物体训练和专用硬件的依赖，使开放场景中的对象感知成为可能。

早期方法通常依赖局部几何特征与 PnP 求解，在弱纹理、遮挡以及复杂光照条件下鲁棒性有限。随后，大量深度学习方法针对特定物体学习位姿估计网络，如 PoseCNN、DenseFusion 等。进一步地，CosyPose、MegaPose 等方法结合渲染匹配提升了未知物体的泛化能力，FoundationPose 则实现了无需逐物体训练的零样本 6DoF 位姿估计。随着开放词表目标检测、视频对象分割、立体匹配等视觉基础模型的发展，开放场景中的对象感知能力得到进一步提升。然而，这些能力大多以独立视觉模块的形式存在，如何将其组织为面向混合现实应用的统一视觉感知流水线，仍然缺乏系统性的研究。

更重要的是，上述工作的目标始终是提升相机坐标系下 6DoF 位姿估计的准确性，而非混合现实中的对象锚定。视觉推理产生的异步时延、估计噪声以及跟踪波动，使高精度位姿流仍难以直接驱动稳定的虚实配准。换言之，现有研究主要关注对象感知，而如何将异步物体位姿流进一步转换为世界坐标系下稳定、连续且可恢复的对象锚点，仍然缺乏系统性的研究。

\subsection{XR 时延补偿与时间一致性}


配准误差（Registration Error）与端到端时延（End-to-end Latency）自增强现实诞生以来便被认为是影响用户体验的核心问题，也是导致虚实错位、视觉疲劳与沉浸感下降的重要原因。经典增强现实研究指出，时延与运动速度的乘积是动态配准误差的主要来源；后续系统分析进一步量化了不同误差源对配准精度的影响。对于依赖异步视觉感知的混合现实系统而言，图像采集、网络传输与模型推理通常会引入数十毫秒乃至更高的端到端时延；当物体或用户快速运动时，这种异步时延便会表现为虚拟内容相对于真实物体的明显漂移与打滑。

围绕时延补偿，学界与工业界发展出两类互补思路。其一是预测式跟踪：头部位姿外推可以降低动态配准误差，双指数平滑等方法提供了更轻量的预测替代。在交互输入侧，One Euro 滤波器以速度自适应的方式权衡抖动与延迟，是三维用户界面处理含噪输入的常用基线，但也揭示了卡尔曼滤波在快速运动下引入滞后的固有折衷。其二是后渲染对齐：后渲染三维 warp 将已渲染画面重投影到新视角，成为时间扭曲的概念源头；异步时间扭曲（ATW）在扫描输出前用最新头显位姿重投影画面，已成为消费级头显的标准时延补偿手段。

上述工作主要围绕头部运动预测、渲染重投影以及交互输入滤波展开，其目标是降低显示链路中的时延影响。相比之下，由异步视觉模块输出的对象位姿对应于历史采集时刻，其世界坐标关系需要结合设备历史位姿进行恢复。尽管 OpenXR 及各类平台运行时提供了设备级时空同步能力，这些机制主要面向设备自身位姿管理，尚未进一步支持由第三方异步视觉感知驱动的动态真实物体锚定。因此，如何面向异步物体位姿流建立统一的对象锚定运行时，仍然是消费级混合现实系统中的关键问题。

\section{系统流程}\label{sec:pipeline}


\subsection{概述}\label{sec:overview}


EgoAnchor 采用对象感知与对象锚定解耦的分层架构（见 \ref{fig:arch}），由视觉感知后端（Visual Perception Backend）与对象锚定运行时（Object Anchoring Runtime）组成。

\begin{itemize}
  \item \textbf{视觉感知后端。} 运行于配套计算设备，持续从头戴显示器双目图像中恢复相机坐标系下的 6DoF 物体位姿，并为每个位姿估计附加统一的可靠性评分，最后将异步物体位姿流输出给对象锚定运行时。
  \item \textbf{对象锚定运行时。} 运行于头戴设备，依据采集时刻的相机位姿将异步物体位姿流转换为世界坐标系下的对象锚点，并通过运行时转换策略生成可供 PMR 应用直接使用的稳定、连续且可恢复的对象锚点。
\end{itemize}

\subsection{对象感知}\label{sec:perception}


视觉感知后端把同步双目图像流转换为相机坐标系下的异步物体位姿流，并在末端附加统一的可靠性评分。后端只负责输出观测与诊断信号，不自行决定锚点恢复；目标重获取由对象锚定运行时通过命令面显式触发。感知流水线在每帧顺序经历目标分割、立体几何恢复与零样本 6DoF 位姿估计三个阶段。

\subsubsection{感知流水线}


\textbf{目标分割。} 系统以开放词表文本分割模型 YOLOE 依据文本提示完成目标发现与初始掩膜获取。为避免分割慢路径阻塞主链路，较重的分割仅在首次注册或显式重获取后的下一有效帧调用；注册建立后由视频对象分割模型 Cutie 在时序上传播掩膜，作为跟踪、渲染质量检测与可见区域估计的输入。

\textbf{立体几何恢复。} 系统以零样本立体匹配模型 Fast-FoundationStereo 从校正后的双目图像恢复米制深度。给定视差 $d$、水平焦距 $f_x$、基线 $b$ 与内部缩放系数 $s$，像素深度为

\begin{equation}
Z = (f_x s b) / d
\label{eq:depth}
\end{equation}


并将超出有效量程 $[0.1, 5.0]$ m 的深度置零，以抑制远处与无效区域的噪声。

\textbf{零样本 6DoF 位姿估计。} 系统以 FoundationPose 输出相机坐标系下的 $4 \times 4$ 齐次位姿 $T^c_o$。尚未注册时，以掩膜与深度执行注册，并要求掩膜内有效深度比例达到给定门限；注册成功后转入跟踪，以上一帧位姿为先验做少量迭代优化。系统记录逐帧平移与旋转增量

\begin{equation}
\Delta t = \lVert t_k - t_{k - 1} \rVert_2, \quad \Delta r = \arccos\!\left((\operatorname{tr}\!\left(R_{k - 1}^T R_k\right) - 1) / 2\right)
\label{eq:posejump}
\end{equation}


并在 $\Delta t > \tau_t$ 或 $\Delta r > \tau_r$ 时将该帧标记为异常观测并输出 no-pose。该判定不在感知侧触发重新注册；若运行时根据低可靠性或失锁状态认为需要重获取，则下发 reacquire/reset 命令，感知后端清空跟踪状态，并在下一有效帧重新执行分割与注册。

\subsubsection{可靠性评分}\label{sec:reliability}


孤立的位姿估计无法告知下游运行时该估计是否可信。为此，视觉感知后端为每个有效位姿观测计算取值于 $[0, 1]$ 的综合可靠性评分，供对象锚定运行时的质量评估与状态迁移使用。当前实现中，可用位姿只来自 REGISTER 与 TRACK 两类输出；等待、失败或异常阶段直接输出 no-pose。因此可靠性评分不再单独设置阶段门控，而采用质量与置信的乘性结构

\begin{equation}
R = Q \times C
\label{eq:reliability}
\end{equation}


其中质量项 $Q$ 建模几何一致性与可见面积，置信项 $C$ 建模连续高质量观测带来的时间一致性。质量项综合两类互补的几何证据。其一是颜色重投影一致性 $s_{\mathrm{rep}}$，在渲染掩膜与观测掩膜的交集区域上转换到 LAB 色彩空间并对亮度通道降权后，计算零均值归一化互相关 $\mathrm{ZNCC}$ 并映射到单位区间，

\begin{equation}
s_{\mathrm{rep}} = \min\!\left(1, \max\!\left(0, (\mathrm{ZNCC} + 1) / 2\right)\right)
\label{eq:reproj}
\end{equation}


其二是深度对齐一致性 $s_{\mathrm{dep}}$，在掩膜内以自适应阈值 $\tau_z = \max\!\left(\tau_{\mathrm{min}}, \rho \lVert t \rVert\right)$ 综合内点比例 $s_{\mathrm{in}}$ 与中位偏差 $s_{\mathrm{med}}$，

\begin{equation}
s_{\mathrm{dep}} = 1 / 2 s_{\mathrm{in}} + 1 / 2 s_{\mathrm{med}}
\label{eq:depthalign}
\end{equation}


两类证据以加权对数几何平均合成几何核，再经掩膜可见度做有界调制，

\begin{equation}
Q = \exp\!\left((\sum_i w_i \ln(\max\!\left(s_i, \epsilon\right))) / (\sum_i w_i)\right) \times (m_f + (1 - m_f) S_{\mathrm{mask}})
\label{eq:quality}
\end{equation}


其中 $i \in {\mathrm{rep}, \mathrm{dep}}$，$\epsilon$ 为几何下限；当某一类证据在弱纹理或低深度覆盖区域失效时被判为无效并从合成中排除，避免对正确位姿的误判；两类证据均无效时几何核取 $1$，不武断降分。置信层以连续高质量帧的离散计数 $n$ 提供迟滞，

\begin{equation}
C = 0.5 + 0.5 n / N
\label{eq:confidence}
\end{equation}


质量分达标时 $n$ 递增至上限 $N$、否则快速回落，使评分在持续稳定时升高、质量下降时迅速衰减，抑制单帧噪声。值得说明的是，早期设计曾包含一个基于逐帧位姿跳变幅度的子项，但离线分析表明错误位姿的逐帧跳变并不显著大于真实快速运动，二者难以区分；因此该子项被移除，对错误位姿的抑制改由几何证据与对象锚定运行时的质量评估共同负责。

\subsection{对象锚定}\label{sec:anchoring}


对象锚定运行时接收异步、低频且含噪的相机系位姿观测，将其转换为每帧稳定、连续且可恢复的世界系对象锚点。它承担两项核心职责：通过时空对齐把每个观测锚回其采集时刻的相机参考，消化采集与到达之间的设备运动；再经质量评估、锚定策略与静止优先先验，在低频含噪输入下维持每帧稳定的输出，并在目标短时丢失时给出合理的保持与恢复行为。

\subsubsection{时空对齐}\label{sec:alignment}


视觉感知后端返回的位姿基于一帧较早采集的图像计算得到，其采集时刻通常早于结果到达运行时约 $100$ ms。在这段时间内头显持续运动，若直接以结果到达时刻的相机位姿完成坐标变换，则物体相对相机的位姿与相机相对世界的位姿对应于不同时刻，由此引入系统性的动态配准误差，表现为虚拟内容在物体运动中的漂移与打滑。

EgoAnchor 通过基于采集时刻的帧对齐消除这一误差。采集端在发送每帧图像的同时，将该帧的帧标识与采集时刻的相机世界位姿写入一个有界环形缓存；帧标识由采集端单调分配，是连接两端的唯一对齐主键。当一个位姿结果到达时，运行时依据其携带的帧标识在缓存中精确回查对应的采集时刻相机世界位姿 $T^w_{c,f}$，并与该结果给出的相机系物体位姿 $T^c_o(f)$ 合成世界系锚点

\begin{equation}
T^w_o(f) = T^w_{c,f} T^c_o(f)
\label{eq:align}
\end{equation}


展开为位置与旋转分量，

\begin{equation}
p^w_o = p^w_{c,f} + R^w_{c,f} p^c_o, \quad R^w_o = R^w_{c,f} R^c_o
\label{eq:align-pr}
\end{equation}


该回查为按帧标识的精确匹配，不做时间插值、外推或最近邻回退：只有取得采集那一刻的相机位姿，\ref{eq:align} 才严格成立；若对应帧已被环形缓存淘汰或结果无效，则判定为对齐失败，交由锚定策略进入保持或失锁逻辑。由于视觉感知后端输出 OpenCV 相机坐标系（$x$ 右、$y$ 下、$z$ 前）下的位姿，而运行时采用左手相机坐标系（$x$ 右、$y$ 上、$z$ 前），合成前需对旋转做坐标轴翻转

\begin{equation}
R_u = S R_{\mathrm{cv}} S, \quad S = \begin{bmatrix}1 & 0 & 0 \\ 0 & -1 & 0 \\ 0 & 0 & 1\end{bmatrix}
\label{eq:axisflip}
\end{equation}


位置分量做对应的 $y$ 取反。这种将物体位姿始终锚回采集时刻、再链接到当前世界的设计，使系统能够消化采集与到达之间的全部头部运动，正是 EgoAnchor 区别于直接按到达时刻变换的基线的关键所在；为对照评估其收益，运行时另保留一条以到达时刻相机位姿对齐的诊断路径，但其输出仅用于分析，绝不作为正式锚点。

\subsubsection{质量评估与锚定策略}\label{sec:policy}


经时空对齐得到的世界系位姿仍然低频且含噪，无法直接逐帧渲染。锚定策略负责把该位姿序列转换为每帧稳定的输出，由生命周期状态机、质量评估门控、运动模型与平滑策略四个组件构成，统一以采集时刻为时间轴，以避免消息到达时刻与观测有效时刻不一致所带来的系统偏差；所有旋转量均在四元数切空间中通过对数与指数映射处理。

\textbf{生命周期状态机。} 依据可靠观测的到达与观测间隔的增大在若干状态间迁移：间隔较短时进入惯性预测状态并输出预测位姿，间隔增大时进入不确定保持状态并维持最后一个有效锚点，间隔超过失锁阈值时进入丢失状态并停止输出。重获取由运行时显式发起；Python 侧收到 reacquire/reset 命令后只清空跟踪状态，随后由下一有效图像帧建立新的 register 观测。

\textbf{质量评估门控。} 对每个观测给出接受、吸附、保持或拒绝的决定，其职责是拒绝坏观测而非平滑：可靠性低于阈值或测量与预测之差超过跳变阈值时拒绝，首帧则吸附以快速建立锚点。

\textbf{运动模型。} 对位姿做时间外推，包含三种实现。恒速模型以差分速度直接外推，作为不去噪的基线，

\begin{equation}
p(t) = p_n + v (t - t_n), \quad q(t) = q_n \otimes \exp\!\left(\omega (t - t_n)\right)
\label{eq:cv}
\end{equation}


其中 $v = (p_n - p_{n - 1}) / \Delta t$、$\omega = \log\!\left(q_{n - 1}^{-1} q_n\right) / \Delta t$。卡尔曼滤波在各轴以恒速状态 $x = [p, v]^T$ 做最优估计与去噪，

\begin{equation}
F = \begin{bmatrix}1 & \Delta t \\ 0 & 1\end{bmatrix}, \quad K = (P H^T) / (H P H^T + r), \quad x = x + K (z - p)
\label{eq:kalman}
\end{equation}


速度自适应的 One Euro 滤波则以随速度增大的截止频率在抖动与时延之间权衡，

\begin{equation}
f_c = f_{\mathrm{min}} + \beta \left\lvert \widehat{\dot{x}}\right \rvert, \quad \alpha = 1 / (1 + \tau / \Delta t), \quad \tau = 1 / (2 \pi f_c)
\label{eq:oneeuro}
\end{equation}


\textbf{平滑策略。} 决定如何把外推结果呈现为连续轨迹，包含三种实现。零阶保持直接维持最近输出；残差融合在外推到当前时刻的同时，把上一帧输出与当前预测之差作为残差逐帧指数衰减，实现零延迟对齐，

\begin{equation}
y_t = \mathrm{predict}(t) \oplus r_t, \quad r = r \times d^{\Delta t_{\mathrm{render}} \times 60}
\label{eq:blend}
\end{equation}


延迟插值则把渲染目标主动后移 $\Delta = \max\!\left(\widehat{\tau} s, \Delta_{\mathrm{min}}\right)$，使其落在两个已到控制点之间做插值而非外推，以牺牲少量时延换取精确过点。三种运动模型与三种平滑策略自由组合，构成九种锚定变体，为系统性对比研究提供统一的设计空间；运行时不对运动模型的外推设上限，而将外推边界交由平滑策略管理，以消除固定上限在快速运动下造成的平段加跳变伪影。

\subsubsection{静止优先的锚定先验}\label{sec:staticlock}


混合现实中的多数真实物体在大部分时间内保持静止，例如家具、面板与桌面工具；此时头部运动与观测噪声主导了锚点的表观抖动。基于这一观察，EgoAnchor 在运动模型与平滑策略之上叠加一个静止优先的锚定先验，其基本立场是静止即锚、默认锁定、证据解锁。当观测的线速度与角速度持续低于阈值、可靠性足够且维持一定停留时间时进入锁定，

\begin{equation}
\lVert v \rVert \leq v_{\mathrm{en}}, \quad \lVert \omega \rVert \leq \omega_{\mathrm{en}}, \quad R \geq R_{\mathrm{min}}, \quad \mathrm{duration} \geq t_{\mathrm{dwell}}
\label{eq:lockenter}
\end{equation}


并以观测共识的指数平均作为锚原点，从而把静止期的表观抖动抑制到最低。

锁定的解除由多路独立证据共同驱动，任一证据触发即解锁，以兼顾灵敏度与稳健性。基于评分加权的累积和统计量累积超过死区 $\delta$ 的位移并按半衰期衰减以捕捉持续运动，

\begin{equation}
U_k = \lambda U_{k - 1} + R_k \max\!\left(0, \lVert \Delta p_k \rVert - \delta\right), \quad U_k > \theta \Rightarrow \mathrm{unlock}
\label{eq:cusum}
\end{equation}


绝对漂移约束直接限制观测共识相对锚原点的偏移以应对累积和难以捕捉的缓慢漂移，速度逃逸在观测速度超过进入阈值若干倍时快速解锁，低分释放在可靠性持续偏低时主动放弃锁定以避免锚到错误旧位姿。锁定期内通过半衰期较长且受头动门控的漏积分将锚点缓慢精修到观测共识中心，解锁时以残差衰减平滑过渡到内层轨迹，并在重锁之间设置抑制窗以防抖振。

该先验的稳健性关键在于对头部运动与观测距离的感知。头部运动只放宽而不收紧解锁阈值，并在头部停止后的一段时间内冻结解锁证据，待观测共识消化头动残差，从而抑制头部扫过物体再停下造成的误解锁。观测距离自适应则随物体距离 $z$ 放大位置容差，以补偿立体深度噪声随距离增大的固有特性，

\begin{equation}
\theta_p(z) = \theta_p^0 \min\!\left(1 + \eta (z - z_{\mathrm{ref}}) / z_{\mathrm{ref}}, \theta_{\mathrm{max}}\right)
\label{eq:distadapt}
\end{equation}


且仅作用于位置通道而不影响旋转通道。

\section{系统实现}\label{sec:impl}


\subsection{平台与硬件}


我们在 Meta Quest 3 上实现 EgoAnchor，双目透视图像经其 Passthrough Camera API 获取，视觉感知后端运行于一台配备 GPU 的计算设备，与头戴设备通过本地网络连接。视觉模型在该后端上以零样本方式运行，无需针对目标物体进行训练；对象锚定运行时与渲染应用则以原生方式运行于头戴设备。

\subsection{双平面传输架构}


为兼顾带宽与可靠性，系统将跨端通信拆分为两条物理传输。数据面承载高带宽的双目视频流，采用发布订阅模式并配合激进的最新帧保留策略，仅保留最新一帧而丢弃过时帧，以匹配视频流中只有最新帧具有价值的特性。消息面承载对时序敏感的位姿结果、状态事件与控制命令，采用具备可靠订阅、请求应答与幂等支持的消息中间件，以保证结果的正确排序与命令的幂等执行。两条传输共享统一的消息头，其中帧标识作为帧对齐主键贯穿始终，而各类时间戳仅用于时序诊断，不参与位姿计算。

\subsection{多策略并行运行时}


为支持对锚定策略的系统性对比，运行时提供一个扇出机制，把同一份位姿结果分发给多个并行的锚定运行时实例，使不同策略变体在完全一致的输入下并行运行。这一设计保证了变体之间的比较不受输入差异干扰，是后续定量评估（见 \ref{sec:eval}）的实现基础。

\section{评估}\label{sec:eval}


\subsection{实验设置}


我们在 Meta Quest 3 上评估 EgoAnchor，采用两条互补的评估轨道。第一条为定量轨：以 Meta Quest 官方控制器作为评估目标，其六自由度位姿由平台软件开发工具包直接给出，可作为高精度真值，用于精确度量锚定精度、稳定性与响应行为；由于控制器与头显共享同一追踪系统，该真值能够隔离视觉位姿到锚点的转换栈，无需额外的物体到真值外参标定。第二条为应用轨：在多类日常刚性物体上开展用户研究，并辅以无需真值的客观代理指标，评估系统在真实任务中的可用性与对开放物体的泛化能力。两条轨道分别支撑下文的定量评估（RQ1、RQ2）与应用评估（RQ3）。评估全程记录视觉感知后端与对象锚定运行时两端的日志，并依据帧标识与共享会话标识自动配对，供离线分析使用。

\subsection{研究问题}


评估围绕三个研究问题展开，分别对应本文的三项技术贡献。第一，基于采集时刻的时空对齐相对于直接按到达时刻变换，能在多大程度上降低动态配准误差（RQ1）。第二，以静止优先先验为核心的稳定化策略，能否在不牺牲响应性的前提下提升锚定稳定性，其各组件分别贡献多少（RQ2）。第三，系统能否在多类日常刚性物体上支撑真实的以物体为中心的混合现实任务（RQ3）。运动模型与平滑策略的具体选择是可替换的实现细节，其设计空间对比置于补充材料，不作为研究问题。

\subsection{定量评估}


定量评估在控制器目标上进行，从录制日志中计算一组锚定体验质量指标。锚定误差以锚点与真值之间的相对位姿度量，分别报告平移与旋转分量。抖动以真值静止窗口内经高通滤波后的位置与旋转均方根度量，刻画静止期的高频抖动。滞后以锚点速度与真值速度的互相关峰值位置度量，反映锚点相对真实运动的时间滞后。时延以从图像采集到锚点渲染的端到端时间度量，并按感知各阶段分解。此外，我们以异常尖刺的抑制比例度量门控对坏观测的抑制有效性，以锚点与真值在像平面上的投影距离度量屏幕空间漂移，并以目标丢失后误差恢复并维持在阈值内的时刻度量恢复时间。为保证不同条件下的比较不受输入差异干扰，对象锚定运行时将同一份位姿结果扇出到多个并行实例，使各条件在完全一致的输入上运行。

针对 RQ1，我们在同一录制会话上分别以基于采集时刻对齐与基于到达时刻对齐两种方式合成锚点，在相同输入下直接对照二者的动态配准误差，从而隔离时空对齐这一项的收益。针对 RQ2，我们固定运动模型与平滑策略，沿一条消融阶梯逐步启用稳定化策略：从不含任何高阶策略的时序基线，到启用质量评估门控与平滑但关闭静止优先先验，再到完整方法；其中开关静止优先先验是最干净的单因素消融。阶梯的每一档同时报告稳定性指标（抖动、屏幕空间漂移）与响应性指标（滞后、时延、恢复），以验证静止优先先验在提升稳定性的同时并未牺牲响应性。

\subsection{应用评估}


针对 RQ3，我们在多类日常刚性物体上开展应用评估。为覆盖系统的工作范围，物体集在尺寸、表面纹理与几何对称性上取不同取值，而非局限于单一类别。围绕典型的以真实物体为中心的混合现实任务，例如虚拟说明书附着、物体高亮引导与近物精细交互，我们开展用户研究，记录任务完成情况与主观体验，并采用标准量表评估任务负荷等维度。由于日常物体缺乏高精度真值，我们同时报告一组无需真值的客观代理指标，包括静止期抖动、可靠性评分分布、跟踪丢失比例、运行时重获取命令频率，以及静止优先先验下的锚点位移，作为对开放物体泛化能力的客观佐证。具体的被试规模、任务设计与统计分析将在最终版本中给出。

\section{讨论与局限}\label{sec:discussion}


\subsection{设计启示}


EgoAnchor 的经验表明，在开放消费级混合现实中实现稳定的动态对象锚定，关键不在于进一步提升单帧位姿精度，而在于把异步视觉感知放在正确的时间轴上转换为世界一致的锚点。感知与锚定的解耦使两端能够独立演进，而基于采集时刻的帧对齐则可被理解为应用层的延迟锁定，把成熟的显示链路时延补偿思想推广到第三方异步视觉感知。这一思路并不依赖特定的感知模型，因而能够随视觉基础模型的进步而持续受益。

\subsection{局限与未来工作}


EgoAnchor 当前仍存在若干局限。系统依赖目标物体的可用三维模型，对于缺乏现成模型的物体，需要借助 Image-to-3D 技术在线或离线地重建模型，重建精度会进一步影响锚定质量。此外，在严重遮挡、极弱纹理或超出深度有效量程的条件下，感知质量会下降，进而影响锚定的连续性。未来工作将探索更广的物体覆盖、对非刚性物体的支持，以及与生成式三维重建的更紧密结合。

\section{结论}\label{sec:conclusion}


本文提出 EgoAnchor，一套面向开放消费级混合现实的动态真实物体锚定系统。EgoAnchor 仅依赖头戴显示器双目图像与目标物体的可用三维模型，通过视觉感知后端与对象锚定运行时解耦的分层架构，将开放场景中的异步物体位姿流转换为世界坐标系下稳定、连续且可恢复的对象锚点。系统的核心并非提升单帧位姿精度，而在于在正确的时间轴上把异步感知稳定地锚定到正确的世界参考，并在低频含噪输入下保持稳定连续。我们在 Meta Quest 3 上实现该系统，并通过定量实验与用户研究评估其锚定精度、稳定性、响应行为与应用可用性。我们相信，这种解耦架构与基于采集时刻的对齐思路，能够为开放消费级混合现实中的真实物体交互提供一条可扩展的实现路径。
