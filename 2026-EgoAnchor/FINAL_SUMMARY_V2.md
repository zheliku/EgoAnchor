## 📊 升采样机制总结（已更正）

### 两种策略

#### DelayedInterp（延迟插值）
- **延迟**: +100-200 ms
- **方法**: 样条插值（Hermite/Catmull-Rom）
- **特点**: 在已知点之间，无 overshoot
- **适用**: 精度优先、物体缓慢移动

#### Blend（误差融合）
- **延迟**: 0 ms
- **方法**: 外推 + 残差融合
- **特点**: 零跳变、平滑收敛
- **适用**: 响应优先、快速交互

### 论文中的描述

**摘要**（简洁版）:
```
时序平滑层结合运动模型（Kalman / One Euro）与升采样策略
（延迟插值或误差融合）实现从 5-12 fps 到 60 fps 的转换
```

**第三层详细说明**:
```
系统支持两种升采样策略：
(i) 延迟插值主动牺牲 1-2 个观测周期的延迟，
    在已到达的控制点之间进行样条插值，
    保证无 overshoot 与轨迹平滑；
(ii) 误差融合零延迟外推到当前时刻，
     新观测到达时计算残差并在后续帧指数衰减，
     实现平滑收敛。
```

## ⚠️ 需要注意的更正点

### 1. 升采样不是速度外推
❌ "卡尔曼滤波器在每个渲染帧通过预测步骤"  
✅ "两种升采样策略（延迟插值或误差融合）"

### 2. MotionModel 不等于升采样
- MotionModel（Kalman/OneEuro）: 提供控制点和预测接口
- SmoothingStrategy（DelayedInterp/Blend）: 执行升采样

### 3. 静止锁定的位置
- 在升采样之后
- 直接输出锁定位姿，不经过升采样处理
