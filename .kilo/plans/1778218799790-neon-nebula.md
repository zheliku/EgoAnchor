# SAM3 替换 YOLOE Quest Pipeline 实施计划

## 目标

在不新建主 pipeline 的前提下，将 `EgoAnchor_Python/src/pipeline/quest_pipeline.py` 的 stage 2 从 YOLOE-26 分割替换为 SAM3 分割，并保持后续 FFS、Cutie、FoundationPose、ZMQ pose 输出链路可运行。

核心约束：SAM3 约 1 FPS，不能像 YOLOE 一样阻塞每帧 pipeline。默认采用后台低频检测，SAM3 只负责产生目标 mask 种子；实时帧 mask 优先由 Cutie 传播，避免旧帧 mask 与当前 depth/register 错位。

## 已阅读到的现状

- `quest_pipeline.py` 当前 stage 2 强绑定 `Yoloe26Masker.infer(left_bgr)`，但下游实际只依赖通用字段：`overlay`、`mask_bw`、`det_count`、`infer_ms`、`selected_index`、`mask_area_ratio`。
- `PosePipelineOutput.timing.yolo_ms` 和 `PoseMsg.yolo_ms` 已进入 Python/Unity 协议。为避免协议改动，本次不改 MessagePack 字段名，内部可把它解释为 “2D segmentation 耗时”。
- `sam3/test.py` 的最小调用链是：`build_sam3_image_model(checkpoint_path=..., load_from_HF=False)` -> `Sam3Processor(model, confidence_threshold=...)` -> `set_image(PIL.Image)` -> `set_text_prompt(state, prompt)` -> 读取 `masks/boxes/scores`。
- 本地 SAM3 权重位于 `EgoAnchor_Python/sam3/assets/sam3_ckpt/sam3.pt`，SAM3 包资源包含 `sam3/sam3/assets/bpe_simple_vocab_16e6.txt.gz`。
- `pixi.toml` 已包含 SAM3 主要依赖中的 `timm/iopath/ftfy/regex/huggingface_hub`，但还没有将本地 `sam3` 注册为 editable pypi dependency；实现时需要验证 import 路径是否足够，优先用显式 `sys.path` 兼容本仓库布局，必要时再加 `sam3 = { path = "./sam3", editable = true }`。

## 设计方案

### 1. 新增 SAM3 module

新增 `EgoAnchor_Python/src/modules/sam3_masker.py`，风格仿照 `yoloe26.py`：

- `Sam3MaskResult` dataclass：
  - `overlay: np.ndarray`
  - `mask_bw: np.ndarray`
  - `det_count: int`
  - `infer_ms: float`
  - `prompt: str`
  - `selected_index: int = -1`
  - `mask_area_ratio: float = 0.0`
  - `score: float = 0.0`
  - `boxes_xyxy: np.ndarray | None = None`
  - `source_frame_id: int | None = None`
  - `source_timestamp_ms: float | None = None`
- `Sam3Masker`：同步推理封装。
  - 初始化参数：`checkpoint_path`、`prompt`、`confidence_threshold`、`mask_threshold`、`max_det`、`device`、`resolution`、`compile_model`、`sam3_root`。
  - 内部添加本地 `EgoAnchor_Python/sam3` 到 `sys.path`，使用本地 checkpoint 且 `load_from_HF=False`，避免联网。
  - 输入统一为 BGR/gray `np.ndarray`，转换为 RGB PIL 再调用 SAM3。
  - 选择结果策略：先按 score 取最高，再按 `max_det` 限制 det_count；输出单目标 `mask_bw` 给 FoundationPose。
  - overlay 使用 OpenCV 绘制半透明 mask、bbox、score，避免依赖 matplotlib。
  - 所有 tensor 转 CPU numpy 时使用 `torch.inference_mode()`/`detach()`，保证无梯度。

### 2. 新增异步 SAM3 包装器

在同一 module 中增加 `AsyncSam3Masker`，避免污染 pipeline 主逻辑：

- 单后台 worker 线程，内部持有一个 `Sam3Masker` 实例，避免跨线程共享 CUDA 模型。
- `start()` / `stop()` 控制线程生命周期。
- `submit(image_bgr, frame_id, timestamp_ms)`：
  - 非阻塞。
  - 若 worker 忙，丢弃本次提交，继续使用旧结果。
  - 只保留最新待处理帧，避免队列积压造成秒级延迟。
- `get_latest()`：返回最新完成的 `Sam3MaskResult` 和版本号。
- 统计接口：`get_stats()` 返回 submitted/completed/dropped/failed/busy/latest_age_ms/last_infer_ms。
- 可选提交节流：`min_interval_sec`，默认 1.0 秒。
- 错误处理：worker 异常限频 logging warning，不中断主 pipeline。

### 3. 抽象 stage 2 为通用 segmenter

在 `quest_pipeline.py` 内做小范围重命名和适配，不新建 pipeline：

- import 改为 `Sam3Masker`/`AsyncSam3Masker`，同时可保留 YOLOE import 作为显式 fallback 选项。
- pipeline 属性从 `yolo` 调整为 `segmenter`，但保留 `_yolo_acc`、`timing.yolo_ms` 字段名以兼容 `pose_server.py`、`PoseMsg`、Unity。
- 增加 `PIPELINE_STAGE_SPECS` 列表，清楚表达每个阶段调用模块：
  - stage 1：QuestReceiver input/preprocess
  - stage 2：SAM3 segmenter async/sync + optional Cutie mask propagation
  - stage 3：FastFoundationStereoRealtime
  - stage 4：FoundationPose register/track/re-register
- phase 从 `STAGE2_YOLO` 改为 `STAGE2_SEGMENT` 或 `STAGE2_SAM3`；统计日志中的 `avg(yolo/depth/...)` 可改成 `avg(seg/depth/...)`，但传输字段仍是 `yolo_ms`。

### 4. SAM3 后台检测与 Cutie 当前帧 mask 结合

默认异步模式流程：

1. 每帧 stage 2 调用 `async_sam3.submit(left_bgr, frame_id, timestamp_ms)`，满足间隔且 worker 空闲才真正提交。
2. 读取 `async_sam3.get_latest()`。
3. 如果出现新的 SAM3 result 且有 mask：
   - 用该 result 的 `overlay/mask_bw/det_count` 更新调试展示。
   - 若启用 Cutie，将 Cutie 初始化为 SAM3 mask 种子。
4. 对每个当前帧，如果 Cutie 已初始化，在 stage 2 或 stage 4 前先 `cutie_tracker.track(left_rgb)` 得到当前帧 mask。
5. FoundationPose 初次 `register` 和 `re-register` 优先使用当前帧 Cutie mask，而不是旧帧 SAM3 mask。
6. 如果 `--activate_2d_tracker 0`：
   - 默认不使用过期 SAM3 mask 进行 register，只用于调试展示。
   - 可提供 `--sam3_allow_stale_register 1` 和 `--sam3_max_result_age_ms` 作为显式 fallback，用户愿意承担 mask/depth 错位风险时才启用。

这一点是本次替换的关键：SAM3 慢，所以它适合做低频语义重新发现；实时 mask 应由 Cutie 或 FoundationPose track 维持。

### 5. 参数整理

在 `build_arg_parser()` 中新增 SAM3 参数，YOLO 参数可保留但默认 detector 切到 SAM3：

- `--segmenter`，choices `sam3/yoloe26`，default `sam3`。这样满足“替换为 SAM3”，同时保留调试回退。
- `--sam3_checkpoint_path`，默认 `PROJECT_DIR / "sam3" / "assets" / "sam3_ckpt" / "sam3.pt"`。
- `--sam3_prompt`，默认沿用 `--yolo_prompt` 的语义或直接默认 `white cube`。
- `--sam3_confidence_threshold`，默认 0.5 或 0.6。
- `--sam3_mask_threshold`，默认 0.5。
- `--sam3_resolution`，默认 1008。
- `--sam3_device`，默认 `cuda`。
- `--sam3_async`，choices 0/1，默认 1。
- `--sam3_interval_sec`，默认 1.0。
- `--sam3_max_result_age_ms`，默认 1500。
- `--sam3_allow_stale_register`，choices 0/1，默认 0。

构建函数逻辑：

- `segmenter=sam3` 时只校验 SAM3 checkpoint、FFS 权重、mesh，不再要求 YOLOE 权重/mobileclip2 存在。
- `segmenter=yoloe26` 时保留原 YOLOE 构建路径，方便性能对比。
- `QuestStereoPosePipeline.start()/stop()` 中启动/停止异步 segmenter。

### 6. 测试与验证

新增或更新测试，优先不依赖真实 CUDA/SAM3 权重的单元测试：

- `src/test/test_sam3_masker.py`
  - 用 monkeypatch/fake processor 测试 `Sam3Masker` 的 mask 选择、shape resize、空检测输出、overlay 类型。
  - 测试 `AsyncSam3Masker` 忙时丢帧、latest result 更新、stop 后线程退出。
- 更新现有 protocol 测试无需改协议字段。
- 如果环境可用，再跑一次真实 SAM3 smoke test：用 `sam3/assets/images/test_image.jpg` 或项目 cube 图执行一帧同步 infer，验证能加载本地 checkpoint 且无 HuggingFace 下载。

计划执行验证命令：

```powershell
pixi run python -m unittest src.test.test_sam3_masker src.test.test_protocol_contract
pixi run python -m compileall src/modules/sam3_masker.py src/pipeline/quest_pipeline.py src/pose_server.py
pixi run python .\src\pipeline\quest_pipeline.py --run_stage 2 --segmenter sam3 --sam3_async 0
pixi run python .\src\pose_server.py --run_stage 4 --segmenter sam3 --sam3_async 1 --local_debug 1
```

最后两个命令依赖 Quest 输入/模型/GPU，若本机当时没有设备或 CUDA 资源，记录无法完整运行的原因。

## 风险与取舍

- SAM3 结果是低频且可能滞后；默认禁止直接用过期 SAM3 mask 做 FoundationPose register，避免 mask/depth 错位。
- 若 Cutie 初始化在旧 SAM3 帧上再追踪到当前帧，快速运动时仍可能失败；但这比直接拿旧 mask 配当前 depth 更安全。
- 保留 `yolo_ms` 协议字段名是为了避免 Unity/Python MessagePack 协议级改动；UI/log 可显示为 `seg_ms`。
- `segmenter=yoloe26` fallback 会保留旧模块，不恢复旧协议，也不影响默认 SAM3 路径。

## 实施顺序

1. 写 `sam3_masker.py` 同步封装，先用 fake 单测覆盖结果转换逻辑。
2. 加 `AsyncSam3Masker` 并写线程/丢帧/latest-drain 单测。
3. 修改 `modules/__init__.py` 导出。
4. 修改 `quest_pipeline.py` 构建参数和 stage 2 逻辑，默认 SAM3 async。
5. 跑单元测试和 compileall。
6. 尝试真实 SAM3 单帧 smoke test。
7. 尝试 Quest pipeline/pose_server 运行验证；记录设备相关限制。
8. 如验证发现 SAM3 local import 不稳定，更新 `pixi.toml` 加 editable 本地依赖并重新验证。
9. 更新 `AGENTS.md` 记录 SAM3 detector、异步策略、参数与排查建议。
